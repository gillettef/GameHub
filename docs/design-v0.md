# 구현 룰 v0 (프로토타입)

pptx에 비어 있던 상세 규칙을 임시로 채운 **구현 기준 룰**. 수치는 `src/game/engine.ts`의 `CFG`와 `src/game/data/`에 있다. 확정되면 이 문서와 `docs/rules.md`를 갱신한다.

## 기본
- 1인 + AI 1~3명, **8라운드**, 시작 자금 **$10**, 부지 **6칸**, 시설 시장 4장.
- 승리: 최종 VP 최다 (동점이면 잔액 많은 쪽).

## 라운드 (건설 → 홍보 → 운영 → 관리)
라운드 시작 시 **운영카드(이벤트) 1장 공개**(`data/events.ts`, 12장).
1. **건설** — 선 플레이어부터 번갈아 한 번에 1행동: 시설 구매(부지 선택, 기존 시설은 철거) 또는 인력 고용. 더 안 하면 패스. 모두 패스하면 종료.
2. **홍보** — ① **관객 트랙(공개)**: 관객카드 (전원 수용량 합 + 2)장을 앞면으로 공개(종류 어린이/성인, 좋아하는 유형, 지불 한도 $1~$4). 선 플레이어부터 번갈아 1장씩 자기 입구로 가져온다. 수용량 = 2 + 마케팅 Lv + 이벤트. 일찍 멈추면 이후 차례를 건너뛴다. ② **입장료** $0~$4 결정(공개 카드이므로 입장 여부를 정확히 알 수 있음). 지불 한도가 입장료보다 낮은 관객은 입구에서 돌아간다. 입장료 수입 = 입장 인원 × 입장료.
3. **운영** — 입장한 관객이 (만족도 + 취향 일치 +3 + 수익×0.3) 순으로 시설을 최대 2곳 이용. 시설 수용은 기본 1명(안내 직원 Lv만큼 인기 시설이 2명). 이용당 수익 = ⌈원본 수익/2⌉ + 이벤트, 만족도 = 원본 + 취향 일치 +1 + 이벤트. 유지비 차감. 이용한 시설은 고장 확률 25%(엔지니어 Lv당 -8%, 최소 4%), 이용 1회당 50% 쓰레기 토큰.
4. **관리** — 엔지니어 Lv만큼 무료 수리, 환경 미화원 Lv×2 무료 청소(자동 적용). 남은 건 수리 $3 / 청소 $1. 라운드 종료 시 쓰레기 2개마다 VP -1.

## 공개 정보 (오프라인 보드게임 기준)
- 모든 플레이어의 개인 보드(시설·고장/쓰레기 토큰·인력 트랙·돈·VP)와 입구에 가져간 관객은 **공개**. UI는 상단 스코어보드에서 상대를 탭해 열람한다.
- 관객 트랙의 카드는 전부 앞면, 누가 가져갔는지 표시. 운영 결과(관객 동선·수익)도 전원 공개.
- 비공개 정보: 없음 (덱의 다음 카드만 모름).

## 점수
- 만족도는 누적 풀에 쌓이고 **4점마다 VP 1**. 돈이 마이너스가 되면 $2당 VP -1 하고 0으로 복구.

## 인력 (Lv 0~3, 고용비 $4/$6/$8)
마케팅=방문 관객 +1/Lv · 안내=인기 시설 수용 +1 · 엔지니어=고장 확률↓+무료 수리 · 미화원=무료 청소 · 연구원=건설비 -$1/Lv(최소 $1)

## 알려진 단순화 / 미구현
- 시설 카드의 개별 특수효과 텍스트는 표시만 한다(롤러코스터 악천후 유지비 +2만 구현). 이벤트가 유형별 효과를 대신한다.
- 한 기기 다인(핫시트)·온라인 대전 없음.
- 밸런스: `npm run sim` (AI 대전 시뮬레이션) — 3인 평균 VP ≈ 25, 좌석 승률 편차 있음(조정 필요).
