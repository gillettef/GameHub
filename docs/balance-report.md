# 밸런스 조정 리포트 (시뮬레이션 기반)

방법: AI끼리 수천 판을 돌려 지표를 측정하고, 룰 상수(`src/game/engine.ts`의 `CFG`)와 구현 규칙을 조정했다. **시설 카드 원본 수치(xlsx)는 바꾸지 않았다.** 룰 상수·규칙 추가·특수효과 재해석(`src/game/data/effects.ts`)으로만 조정한다. 규칙의 정의는 `docs/design-v0.md`에 있고, 이 문서는 수치 근거만 담는다.

## 재현 방법
| 명령 | 내용 |
|---|---|
| `npm run sim -- [판 수] [인원]` | AI 대전 요약(`scripts/simulate.ts`, 시드 i+1). 평균 VP·잔액, 1라운드 순서 기준 좌석 승률(공동 1위는 나눠 셈), 라운드별·유형별 건설, 축제, 못 쓴 관객 |
| `npx tsx scripts/balance.ts --n 1500 [--set key=값,...]` | 종합 리포트: 거울전(2~5인)·전략 라운드로빈·눈덩이·경제·인력 |
| `npx tsx scripts/sweep.ts [--fit]` | 좌석 공정성 스윕. `--fit`은 인원별 순서별 추가 자금 표(`seatMoneyByPlayers`)를 탐욕적으로 맞춤 |
| `npx tsx scripts/cardeval.ts [--base 3 --visitors 3]` | 시설별 한계 가치(AI 무관, 같은 조건에서 있을 때 vs 없을 때). `capTiers`·`minPrice` 반영 |
| `npx tsx scripts/econ.ts "설정1" "설정2"` | 경제/VP 규모 스윕(설정마다 핵심 지표 한 줄) |
| `npx tsx scripts/tune-ai.ts` | 기준 AI를 자가대전으로 최적화 |
| `npx tsx scripts/pipeline.ts "설정1" "설정2"` | 설정마다 AI 재최적화 → 지표 측정 (설정 비교는 이 방식이 공정) |

## 최종 룰 상수 (현재)
| 구분 | 값 |
|---|---|
| 인원·길이 | 전체 2~5인(`minPlayers`·`maxPlayers`, 사람 0~1) · `rounds` 8 · `slots` 6 |
| 시작 자금 | `startMoney` $10 + `seatMoneyByPlayers` 2인 [0,2] · 3인 [0,2,1] · 4인 [0,2,0,2] · 5인 [0,2,1,3,7] (1라운드 순서 기준) |
| 시장 | 인원 + `marketExtra` 2장, 팔리지 않은 카드는 라운드마다 버림 (옛 `marketSize` 상수는 삭제) |
| 건설 | `minPrice` $2 · `costMul` 1 · 수용 `capTiers` 건설비 10↑ 3명 / 5↑ 2명 / 그 외 1명 (옛 `bigCost` 8 → 2명 규칙 대체) |
| 관객 | `baseVisitors` 2 · `rowExtra` 2 · `maxFee` $4 · 놀이기구 `ridesPerVisitor` 2 + 상점·부대시설 `sideStopsPerVisitor` 1 · 못 쓴 관객 `unservedSat` 만족도 −2 |
| 수익·점수 | 이용 수익 ⌈원본 ÷ `incomeDiv` 2.5⌉ · `satPerVp` 8 · `moneyPerVp` 6 · 축제 `festivalCost` $4 → `festivalVp` 1 |
| 고장·쓰레기 | `breakBase` 20% · `breakPerEngineer` −6%p/Lv · `breakMin` 2% · `trashChance` 50% · `repairCost` $3 · `cleanCost` $1 · `trashPerVp` 2(매 라운드, 누적) · `debtPerVp` $2(올림) · VP 하한 없음 |
| 인력 | `hireCosts`(Lv1/2/3) 마케팅 전문가 4/6/8 · 안내 직원 4/6/8 · 엔지니어 3/5/7 · 환경 미화원 3/5/7 · 연구원 2/4/6 · `researchSat` 3/Lv |
| 순서 | `catchUpOrder` 0(시계 방향 순환) · `pickOrder` 0(선부터 고르기) |

## 2026-10 감사 후 재조정

### 문제 (재조정 전 측정)
| # | 문제 |
|---|---|
| 1 | **부대시설 0회 구매**: 수익 0, 처리량 1명이라 AI가 한 번도 짓지 않음. 관객이 2곳만 이용해 놀이기구와 자리를 다툼 |
| 2 | **후반 잔액 과다**: 최종 잔액 평균 약 $42. 6라운드 이후 돈 쓸 곳이 없음 |
| 3 | **5인 좌석 편향**: 1라운드 순서별 승률 13~27%(기대 20%). 선형 순서 보너스(+$2씩)로는 5인이 맞지 않음 |
| 4 | **비용 7 수용 절벽**: 건설비 8부터 수용 2명이라 비용 7 카드(산악 롤러코스터·해양 어드벤처·수중 미끄럼틀)가 비용 대비 손해 |
| 5 | **비용 대비 손해 카드**: 특수효과 미구현으로 같은 수치인데 비싼 카드가 일방적으로 불리 |
| 6 | **이벤트 유형 편중**: 12장 중 유형 전용 이벤트가 패밀리·공포·물놀이에만 있어 스릴·어드벤처·교육·놀이형은 보너스가 없음 |
| 7 | **$1 카드 과강**: 트램폴린·미니골프·차량 정비소·넓은 주차장 등 $1 카드의 회수가 지나치게 빠름 |

### 조치
| 문제 | 조치 |
|---|---|
| 3 | 1라운드 순서별 추가 자금을 인원별 표(`seatMoneyByPlayers`)로 바꾸고 `sweep.ts --fit`으로 맞춤 |
| 4 | 수용 구간 `capTiers`: 건설비 10↑ 3명, 5↑ 2명, 그 외 1명 |
| 7 | 최소 건설비 $2(`minPrice`), 연구원 할인 후에도 $2 미만 불가 |
| 2 | 이용 수익 ÷2 → **÷2.5**(올림)로 수입 축소, 새 행동 **축제 개최**($4 → VP +1, 라운드당 1회)로 후반 지출처 추가 |
| 1 | 관객이 놀이기구 최대 2곳 + **상점·부대시설 1곳을 별도로** 이용. 선택 점수에 취향 일치 +3·수익 ×0.3, 못 쓴 관객 만족도 −2, 라운드 만족도 0 하한 |
| 6 | 운영카드(이벤트) **16장**으로 재구성: 태그 체계, 신규 4장(불꽃놀이 야간 개장·탐험 주간·과학의 날·어린이날)으로 놀이기구 7유형마다 전용 이벤트, 눈 오는 날은 야외 −1만 |
| 5 | 시설 특수효과 원문 49장을 `effects.ts`로 재해석해 모두 구현. 같은 수치 카드는 비쌀수록 효과가 좋게 차별화 |

그 밖에 함께 바뀐 규칙: 엔지니어 −8%p/Lv·최소 4% → **−6%p/Lv·최소 2%**(Lv 3도 효과), 무료 수리는 가치 높은 시설부터 자동, 쓰레기 누적 감점, 적자 올림 감점, VP 음수 허용, 동점은 VP → 잔액 → 공동 1위, 시장 덱 다시 섞기 중복 버그 수정.

### 결과
**simulate 2000판 (시드 i+1, 균형 AI 거울전)**
| 인원 | 평균 VP | 평균 잔액 | 1라운드 순서별 승률(%) |
|---|---|---|---|
| 2인 | 42.2 | $25.6 | 54 / 46 |
| 3인 | 42.8 | $26.8 | 32 / 33 / 35 |
| 4인 | 42.5 | $26.5 | 25 / 27 / 24 / 25 |
| 5인 | 45.4 | $29.5 | 17 / 19 / 22 / 21 / 21 |

- 잔액: 약 $42 → **$26~30**. 5인 좌석: 13~27% → **17~22%**.
- 유형별 건설(인당) 0.44~0.77, **부대시설**(10장) 1.6 — 0회 → 가장 많이 짓는 유형.
- 라운드별 건설(인당, 3인): R1 1.66 / R2 1.32 / R3 1.22 / R4 0.84 / R5 0.52 / R6 0.25 / R7 0.01 / R8 0.
- 축제 인당 판당 0.9회. 못 쓴 관객 인당 판당 약 3.3명(이전 약 6.4명).

**balance.ts 전략 라운드로빈 (승률)**
| 전략 | 2인 | 3인 |
|---|---|---|
| 균형 | 60% (이전 70%) | 42% |
| 건설 중심 | 44% (이전 15%) | 23% |
| 인력 중심 | 52% | 41% |
| 관객 중심 | 50% | 35% |
| 절약 | 44% | 26% |

- 인력 1종을 Lv 2까지 우선 고용하는 AI vs 균형 AI: 41~48%. 한 인력이 지배적이지 않다.

**cardeval (기준 시설 3곳·관객 3명) 비용 구간별 평균 회수**
| 건설비 | 1-2 | 3-4 | 5-6 | 7+ |
|---|---|---|---|---|
| 현재 | 2.2R | 2.1R | 1.5R | 2.3R |
| 이전 | 1.5R | 1.9R | 3.5R | 2.8R |

- 싼 카드의 과강과 비용 5~7 카드의 손해가 해소되어 구간 간 회수가 2R 안팎으로 모였다.
- 한계: cardeval은 이벤트 태그 효과와 무료 수리·청소의 가치를 측정하지 않는다(해당 카드는 실제보다 낮게 나옴).

### 남은 과제
- **초반 리드 고착(눈덩이)**: 초반 건설에서 앞선 공원이 끝까지 유지하는 경향.
- **후반 선택지 부족**: 7~8라운드 건설이 거의 0이고 축제가 유일한 후반 선택지.
- **상점 5장 동일 수치**: 원본 수치가 모두 같아 이벤트 조건 효과로만 구분된다.
- **사람 플레이 로그로 재측정** 필요(AI는 휴리스틱).

## 이전 조정 기록 (v0 → 1차, 2026-10 재조정 전)
아래 상수 중 일부(`bigCost`, 엔지니어 −8%p, 선형 `seatBonus` 등)는 위 재조정으로 대체되었다.

| # | 문제 (측정값) | 조정 | 결과 |
|---|---|---|---|
| 1 | **좌석 편향**: 4인전 마지막 순서 승률 16%(기대 25%). 1라운드 시장·관객을 먼저 고르는 쪽이 눈덩이처럼 유리 | ① 시장 카드 = 플레이어 수 + 2장 ② 1라운드 선 플레이어를 **무작위**로 정하고, 순서가 늦을수록 **시작 자금 +$2씩** | 좌석 편차 2·3·4인 모두 **2.3~2.9%p** (RMS 기준 8.3 → 1.5~2.3). 시도했지만 폐기: "VP 최하위가 선"(오히려 악화), 관객 선택 순서 반전(효과 없음) |

| 3 | **후반 돈이 무의미**: 잔액 $13~19가 남고 6라운드부터 건설 없음. 점수는 VP뿐 | 게임 종료 시 **남은 돈 $6마다 VP +1** | 4라운드 선두가 이길 확률 69%→62%(순수 우연 기준선 약 70~75%) |

## 시설 카드 이상치 (제안만, 원본 미수정)
- 1차 보고의 "$1 카드 효율 과강"(트램폴린·미니골프·차량 정비소·넓은 주차장)은 최소 건설비 $2로 대응했다.
- 놀이형(어린이 만족도 7~8)은 관객 중 어린이 비율(50%)에 의존한다. 관객 덱 구성을 바꾸면 재측정 필요.
- 부대시설은 수익이 0~1이라 돈은 손해지만 만족도·패시브로 보상한다. 별도 이용 자리를 얻은 뒤 가장 많이 짓는 유형이 되었으므로, 과해지면 패시브 수치부터 조정한다.
- 상점 5장(31~35)은 원본 수치가 모두 같다. 원본 수치를 다르게 할지 사용자 확인 필요.

## 한계
- AI는 휴리스틱이라 "최적 플레이"와 다르다. 사람이 하면 지표가 달라질 수 있으니 **실제 플레이 후 재측정** 필요.
- "전략 변형" 비교는 기준 AI가 자가대전으로 최적화된 값이라 변형이 불리하게 나오는 경향이 있다. 참고용이며 합격선이 아니다.
