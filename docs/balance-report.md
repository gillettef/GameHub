# 밸런스 조정 리포트 (시뮬레이션 기반)

방법: AI끼리 수천 판을 돌려 지표를 측정하고, 룰 상수(`src/game/engine.ts`의 `CFG`)를 조정했다. **시설 카드 원본 수치(xlsx)는 바꾸지 않았다.** 룰 상수 + 규칙 추가로만 조정하고, 카드 이상치는 아래에 제안만 남긴다.

## 재현 방법
| 명령 | 내용 |
|---|---|
| `npm run sim` | 간단 AI 대전 요약 |
| `npx tsx scripts/balance.ts --n 1500 [--set key=값,...]` | 종합 리포트(좌석·전략·눈덩이·경제·인력) |
| `npx tsx scripts/sweep.ts` | 좌석 공정성 파라미터 스윕 |
| `npx tsx scripts/cardeval.ts [--base 3 --visitors 3]` | 시설별 한계 가치(AI 무관, 같은 조건에서 있을 때 vs 없을 때) |
| `npx tsx scripts/tune-ai.ts` | 기준 AI를 자가대전으로 최적화 |
| `npx tsx scripts/pipeline.ts "설정1" "설정2"` | 설정마다 AI 재최적화 → 지표 측정 (설정 비교는 이 방식이 공정) |

## 발견한 문제와 조정 (v0 → 현재)
| # | 문제 (측정값) | 조정 | 결과 |
|---|---|---|---|
| 1 | **좌석 편향**: 4인전 마지막 순서 승률 16%(기대 25%). 1라운드 시장·관객을 먼저 고르는 쪽이 눈덩이처럼 유리 | ① 시장 카드 = 플레이어 수 + 2장 ② 1라운드 선 플레이어를 **무작위**로 정하고, 순서가 늦을수록 **시작 자금 +$2씩** | 좌석 편차 2·3·4인 모두 **2.3~2.9%p** (RMS 기준 8.3 → 1.5~2.3). 시도했지만 폐기: "VP 최하위가 선"(오히려 악화), 관객 선택 순서 반전(효과 없음) |
| 2 | **시설 처리량 한계**: 시설이 라운드당 1명만 받아 비용 $10 롤러코스터(가치 1.66/R)가 $1~4 시설(최대 2.13/R)보다 약함. 비용-가치 상관 0.23 | 건설비 **8 이상** 대형 시설(롤러코스터·자이로드롭·정글 탐험·워터 슬라이드·래프팅)은 **수용 2명** | 비용-가치 상관 **0.75**. 대형 시설 회수 4.7R→3~4R |

## 최종 룰 상수
`rounds 8 · startMoney 10 · seatBonus +2/순서 · marketSize = 인원+2 · satPerVp 8 · moneyPerVp 6 · bigCost 8(수용 2) · breakBase 20% · 엔지니어 -8%p/Lv · researchSat 3 · 인력 고용비(Lv1/2/3) 마케팅 4/6/8, 안내 4/6/8, 엔지니어 3/5/7, 미화원 3/5/7, 연구원 2/4/6 · 쓰레기 2개/VP -1 · 적자 $2/VP -1`

## 최종 지표 (AI 균형 대전, n=1500)
| 항목 | 2인 | 3인 | 4인 |
|---|---|---|---|
| 평균 VP (σ) | 38 (9.5) | 39 (9.2) | 40 (8.7) |
| 1라운드 순서별 승률 | 48 / 52 | 32 / 32 / 36 | 26 / 23 / 25 / 27 |
| 1·2위 평균 격차 | 11.5 | 9.1 | 7.7 |

- 경제(3인): 적자 게임 1%, 최종 시설 평균 5.0/6, 인력 평균 10.7레벨, 라운드별 건설 R1 1.3 / R2 1.1 / R3 1.1 / R4 1.0 / R5 0.4 / R6 이후 ≈0
- 눈덩이: 라운드별 선두의 최종 우승률 R3 52% · R4 62% · R5 71% · R6 78% (점수 누적 게임의 무작위 기준선과 비슷, 추가 눈덩이 요인은 없음)

## 시설 카드 이상치 (제안만, 원본 미수정)
- **과약(▼)**: 없음.
- **효율 과강(▲)**: 트램폴린(26)·미니골프(7)·차량 정비소(42)·넓은 주차장(47) — 모두 **건설비 $1**이라 비용 대비 효율이 높게 나오지만 슬롯당 절대 가치는 낮은 편(가치 1.0~1.4/R, 대형 시설 2.2). 현재로선 문제 없음. 후반 슬롯이 부족해지면 비용 $2로 올리는 것을 검토.
- 놀이형(어린이 만족도 8)이 슬롯당 가치가 높은 소형 카드군. 관객 중 어린이 비율(50%)에 의존하므로 관객 덱 구성을 바꾸면 재측정 필요.
- 부대시설은 수익이 0이라 돈은 손해(Δ$ -1~-2/R)지만 만족도로 보상. 의도한 역할이면 유지.

## 한계 / 후속 과제
- AI는 휴리스틱이라 "최적 플레이"와 다르다. 사람이 하면 지표가 달라질 수 있으니 **실제 플레이 후 재측정** 필요.
- 최종 잔액이 $40 안팎으로 남는다(약 7VP로 환산). 돈이 후반에 여전히 남아도는 구조 — 인건비(인력 유지비)나 공원 확장 같은 후반 지출처 추가를 검토할 수 있다.
- "전략 변형"(시설 중심 vs 인력 중심 등) 비교는 기준 AI가 자가대전으로 최적화된 값이라 변형이 항상 불리하게 나온다. 참고용이며 합격선이 아니다.
- 시설 특수효과 텍스트는 대부분 미구현(룰북·이벤트가 대신함).
