# 밸런스 리포트 (v1)

규칙은 `docs/design-v1.md`. AI끼리 수천 판을 돌려 룰 상수(`CFG`)와 카드 인쇄값 변환(`PRINT`)을 조정했다. **원본 xlsx 수치는 바꾸지 않는다.** v0 기록은 `docs/archive/balance-report-v0.md`.

## 재현 방법
| 명령 | 내용 |
|---|---|
| `npm run sim -- [판 수] [인원]` | AI 대전 요약: 평균 만족도·잔액, 1라운드 순서별 승률, 인력 Lv, 라운드당 입장 그룹·미배치·입찰·수리/쓰레기 토큰, 건설 분포 |
| `npx tsx scripts/balance.ts --n 1500 [--exp mirror,profiles,cards,staff] [--set key=값,...]` | 거울전(2~5인 좌석 승률), 성향 혼합전, 카드별 구매율·구매자 승률, 인력 레벨별 고용자 승률. `--set`은 `CFG`·`PRINT` 키(예: `shopIncome=2`, `capTiers=7:4/3:3`, `hireCosts=3/5/7`) |
| `npx tsx scripts/cards-md.ts > docs/cards.md` | 카드 목록 문서 재생성 |

## 조정 기록 (v1 도입 시)
| 문제 | 조치 |
|---|---|
| 상점이 거의 지어지지 않음(인당 0.27장): 그룹당 $1이면 유지비·쓰레기를 빼고 남는 것이 없음 | 상점 수익 **그룹당 $2**(`shopIncome`) → 인당 1.1장 |
| 정원 2 어린이 놀이기구가 그룹을 거의 받지 못함 | 정원 구간을 7↑ 4명 / **3↑ 3명** / 그 외 2명으로(`capTiers`) |
| 돈만 주는 부대시설 5장(화장실·응급 처치·정비소·게임 센터·자전거)을 0회 구매 | 모두 "매 라운드 만족도 +1"을 기본으로 주고 보조 효과를 붙임 |
| 연구원 "건설비 −$1"은 돈이 남는 경제에서 의미 없음 → 매 라운드 만족도 +2는 선 플레이어 쏠림(5인 1번 자리 30%) | **매 라운드 만족도 +1** |
| 5인 마지막 자리 승률 12% | 입찰 동점을 **선에서 먼 쪽 먼저**로 + 좌석당 +$1 → 최대 편차 3.3%p |

## 남은 과제
- 건설 중심 AI가 약하다(25%). 돈이 남는 후반에 입찰 경쟁을 하지 않는 성향이라 생기는 차이로 보이며, 규칙 문제인지 AI 문제인지 추가 확인이 필요하다.
- 연구원 고용률이 낮다(판당 0.3명, 고용자 승률 15%). 효과를 키울지 사람 플레이테스트 후 결정한다.
- 최약 카드(트램폴린·레이저 태그·클라이밍 벽·유령의 집, 승률 19~22%)는 효과 보강 후보다.
- 최종 잔액이 $25~30 남는다. 입찰이 주된 지출처인데, AI는 상한을 두고 입찰한다. 사람끼리 하면 입찰이 더 치열해질 것으로 보여 사람 플레이테스트로 확인한다.
