## 1차 제출물

- [ ] 공모전 신청서 (첨부 양식, 자필 서명 — 사용자 직접)
- [ ] 게임 기획안 (첨부 양식, **A4 2페이지 이내**, 2페이지에 **게임 진행 사진 1~2장** 필수. 프로토타입이 없으면 손그림이나 구성물 그림도 가능)
- [ ] 규칙서 (양식·분량 제한 없음, `.pdf` `.doc` `.ppt` `.hwp`)

1차 심사는 기획안과 규칙서만으로 한다. 공지는 "규칙서로 규칙을 이해할 수 없으면 심사가 불가하다"고 경고하고, 게임을 모르는 사람에게 규칙서를 읽혀 보라고 권한다.

## 선정 기준 (배점 없음)

1. 순수 창작물
2. 지나치게 복잡하지 않고 재미있는 게임
3. 규칙에 허점이 없고 균형이 잘 맞춰진 게임
4. 반복해서 할 만큼 매력적인 게임

## 수상과 계약

- 우수작: 상금 100만 원 + 계약금 200만 원. 코리아보드게임즈와 **독점 제품화 계약이 가능해야** 한다(불가하면 수상 취소).
- 가작: 상금 30만 원. 계약 제안을 받을 수 있다.
- 게임의 권리는 작가에게 남는다.

## 기준별 대응 전략

| 기준 | 위험 요소 | 대응 |
|---|---|---|
| 지나치게 복잡하지 않음 | 왼쪽 최근 사실 규칙, 연쇄 정리, 금지 배치가 겹쳐 처음 보는 사람에게 무거울 수 있다 | 대상 수와 아이콘 종류를 최소화한다. 연쇄 정리가 실제로 얼마나 자주 일어나는지 시뮬레이션으로 확인한다. 판정 보조 장치(대상별 상태 표시 등)를 검토한다 |
| 규칙에 허점 없음 | 미정의 상황 | `rules-reviewer` 반복 검수, 판정이 기계적이므로 코드 시뮬레이터로 전수 검증한다 |
| 균형 | 차례 순서, 비밀 목표 난이도 | `balance-analyst` + 시뮬레이터로 대량 자동 플레이 |
| 반복 플레이 | 결말 조합이 적으면 금방 질린다 | 결말 카드·비밀 목표 조합 수를 설계 단계에서 계산한다 |
| 규칙서 이해 | 처음 읽는 사람이 이해하지 못함 | 예시 그림, 첫 판 가이드, 블라인드 읽기 테스트 |
