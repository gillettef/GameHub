# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 정원 보드 | Garden Board | 칸으로 나뉜 정사각형 보드. 네 변에 좌석이 있다. |
| 좌석 | Seat | 정원 보드의 한 변. 플레이어는 자기 좌석에서 보이는 것만 정보로 쓸 수 있다. |
| 시야 | Sightline | 좌석에 앉은 채 눈높이 규칙을 지켜서 실제로 보이는 범위. |
| 눈높이 규칙 | Eye-Level Rule | 시야를 볼 때 지키는 자세 규칙. 일어서기, 고개 숙이기, 몸 기울이기는 반칙이다. |
| 생울타리 | Hedge | 칸 경계에 세우는 입체 가림벽. 낮은 생울타리와 높은 생울타리가 있다. |
| 낮은 생울타리 | Low Hedge | 바로 뒤 칸의 가면 면만 가리는 생울타리(가안). |
| 높은 생울타리 | High Hedge | 그 뒤에 있는 모든 칸의 가면 면을 가리는 생울타리(가안). |
| 정자 | Pavilion | 칸 하나를 차지하는 가장 높은 구조물. 모든 방향의 시야를 가리며 손님 말이 들어갈 수 없다(가안). |
| 손님 말 | Guest Piece | 정원 보드 위를 움직이는 말. 윗면에 공개 번호가 있고 가면 면은 한 곳뿐이다. |
| 가면 면 | Mask Face | 손님 말의 옆면 중 문양이 있는 한 면. |
| 문양 | Crest | 가면 면에 있는 소속 표시. 플레이어 색 또는 중립이다. |
| 방향 | Facing | 손님 말의 가면 면이 향하는 정원 보드의 변. |
| 첩자 | Agent | 문양이 플레이어 색인 손님 말. 그 색의 플레이어 소속이다. |
| 중립 손님 | Bystander | 문양이 중립인 손님 말. 어느 플레이어에도 속하지 않는다. |
| 비밀 명부 | Secret Roster | 자기 첩자의 번호가 적힌 비공개 카드. |
| 정찰 | Scout | 정찰 지점으로 자리를 옮겨 잠깐 보고 돌아오는 행동. |
| 정찰 지점 | Scout Post | 정찰할 때 서는 정원 보드 모서리 위치. |
| 지목 | Accusation | 손님 말 하나와 플레이어 색 하나를 선언하고 그 말의 가면 면을 공개하는 행동. |
| 오인 토큰 | Mistake Token | 틀린 지목을 한 플레이어가 받는 벌점 토큰. |
| 접선 지점 | Rendezvous | 첩자를 들여보내 접선할 수 있는 칸. |
| 접선 | Contact | 접선 지점에 있는 자기 첩자를 비밀 명부로 증명하고 점수를 얻는 행동. |
| 후원자 | Patron | 플레이어를 가리키는 테마상의 이름. |
