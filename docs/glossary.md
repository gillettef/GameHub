# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 이야기꾼 | Teller | 플레이어를 가리키는 테마상의 이름. 각자 한 집안을 대표한다. |
| 집안 색 | House Color | 각 플레이어를 나타내는 색. 땅 타일 앞면과 증언 토큰에 표시된다. |
| 섬 보드 | Island Board | 구역들이 그려진 공용 보드. |
| 구역 | Plot | 섬 보드의 이름 붙은 칸. 계절마다 한 집안이 주인이 될 수 있다. |
| 계절 | Season | 게임의 한 라운드. |
| 계절 표시줄 | Season Track | 아직 망각되지 않은 계절들의 땅 타일을 계절별 줄로 놓는 곳. |
| 땅 타일 | Land Tile | 앞면에 집안 색과 구역이 표시된 타일. 뒷면은 모두 같다. |
| 망각 | Forgetting | 가장 오래된 계절 줄의 땅 타일을 뒷면으로 뒤집어 망각 더미에 섞는 절차. |
| 망각 더미 | Oblivion Pile | 망각된 땅 타일이 뒷면으로 섞여 쌓인 더미. 누구도 내용을 확인할 수 없다. |
| 회상 카드 | Recall Card | 지난 계절에 대한 질문 하나가 적힌 카드. |
| 속삭임 시간 | Whisper Time | 회상 카드 공개 뒤 증언 전에 자유롭게 협상하고 주장하는 시간. |
| 증언 토큰 | Testimony Token | 증언에 쓰는 집안 색 토큰. 각 플레이어가 모든 집안 색을 한 세트씩 가진다. |
| 증언 | Testimony | 회상 카드의 질문에 대해 증언 토큰 하나를 동시에 공개하는 행동, 또는 그 답. |
| 공식 역사 | Official History | 가장 많은 증언을 받아 연대기 보드에 고정된 답. 득점의 기준이 된다. |
| 연대기 보드 | Chronicle Board | 공식 역사를 기록해 두는 보드. 한번 놓인 기록은 바뀌지 않는다. |
| 평판 | Reputation | 증언이 공식 역사와 일치했는지에 따라 오르내리는 점수 (가안). |
