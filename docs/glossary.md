# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 이야기꾼 | Teller | 플레이어를 가리키는 테마상의 이름. 각자 한 집안을 대표한다. |
| 집안 색 | House Color | 각 플레이어를 나타내는 색. 땅 타일, 증언 토큰, 기록 표지, 점수 표지에 표시된다. |
| 섬 보드 | Island Board | 구역을 행으로, 계절을 열로 하는 칸이 그려진 공용 보드. 점수 트랙이 둘레에 있다. |
| 구역 | Plot | 섬 보드의 이름 붙은 땅. 섬 보드의 한 행이다. 구역마다 구역 값이 인쇄되어 있다. |
| 구역 값 | Plot Value | 구역에 인쇄된 1~4의 수. 공식 역사에 그 칸의 주인으로 기록된 집안이 얻는 점수다. |
| 계절 | Season | 게임의 한 라운드. 게임은 8계절 동안 진행한다. 섬 보드의 한 열이다. |
| 칸 | Cell | 한 구역과 한 계절이 만나는 자리. 땅 타일이나 기록 표지를 놓는다. |
| 선 플레이어 | Start Player | 그 계절의 점유 단계에서 가장 먼저 땅 타일을 놓는 플레이어. 선 플레이어 표지를 가진다. |
| 점유 단계 | Claim Phase | 각 플레이어가 이번 계절 열에 땅 타일 한 장을 놓는 단계. |
| 땅 타일 | Land Tile | 앞면에 집안 색만 표시된 타일. 뒷면은 모두 같다. |
| 망각 | Forgetting | 정해진 계절 열의 땅 타일을 모두 섬 보드에서 치워 뒷면으로 망각 주머니에 넣고 섞는 절차. |
| 망각된 계절 | Forgotten Season | 망각 절차로 땅 타일이 모두 치워진 계절. |
| 망각 주머니 | Oblivion Bag | 망각된 땅 타일을 넣는 불투명 주머니. 누구도 안을 보거나 내용물을 꺼낼 수 없다. |
| 회의 | Council | 망각 뒤에 질문과 증언으로 공식 역사를 정하는 단계. |
| 질문자 | Questioner | 질문자 표지를 가진 플레이어. 회상 카드를 뽑아 질문 칸을 고른다. |
| 회상 카드 | Recall Card | 구역 하나가 그려진 카드. 질문자가 물을 구역의 후보가 된다. |
| 질문 가능 칸 | Askable Cell | 망각된 계절에 속하고 기록 표지가 없는 칸. |
| 질문 칸 | Questioned Cell | 질문자가 이번 질문의 대상으로 고른 질문 가능 칸. |
| 속삭임 시간 | Whisper Time | 질문 칸이 정해진 뒤 증언 전까지 모래시계 한 번 동안 자유롭게 협상하고 주장하는 시간. |
| 증언 토큰 | Testimony Token | 증언에 쓰는 토큰. 각 플레이어가 게임에 참여한 모든 집안 색 한 개씩과 회색 한 개를 가진다. |
| 회색 증언 토큰 | Grey Testimony Token | "그 칸에는 아무 집안도 없었다"를 뜻하는 증언 토큰. |
| 증언 | Testimony | 질문 칸에 대해 증언 토큰 하나를 동시에 공개하는 행동, 또는 그 토큰이 가리키는 답. |
| 공식 역사 | Official History | 질문 칸에 대해 단독으로 가장 많은 증언을 받은 답. 기록 표지로 섬 보드에 고정되며 득점의 기준이 된다. |
| 공백 | Blank | 가장 많은 증언을 받은 답이 둘 이상이어서 공식 역사가 정해지지 않은 칸. 회색 기록 표지로 표시한다. |
| 기록 표지 | Chronicle Marker | 공식 역사나 공백을 표시하려고 칸에 놓는 표지. 집안 색 표지와 회색 표지가 있다. 한번 놓이면 게임 끝까지 옮기지 않는다. |
| 평판 | Reputation | 증언이 공식 역사와 일치한 플레이어가 받는 1점. |
| 점수 트랙 | Score Track | 섬 보드 둘레의 점수 칸. 각 플레이어의 점수 표지로 점수를 표시한다. |
