# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 결말 카드 | Ending Card | 게임 시작 시 공개되는 카드. 하나의 사실을 게임 끝까지 고정한다. |
| 사실 | Fact | 어떤 대상의 상태(예: 성 = 불탐). 결말 카드와 원인 카드의 결과 아이콘이 사실을 만든다. |
| 시간선 | Timeline | 원인 카드를 놓는 칸의 줄. 결말 카드에 가까울수록 나중 시점이다. |
| 원인 카드 | Cause Card | 플레이어가 시간선에 놓는 카드. 조건 아이콘과 결과 아이콘을 가진다. |
| 조건 아이콘 | Condition Icon | 원인 카드가 성립하려면 그보다 앞선 시점에 참이어야 하는 사실. |
| 결과 아이콘 | Effect Icon | 원인 카드가 그 시점 이후에 참으로 만드는 사실. |
| 인과 사슬 | Causal Chain | 조건 아이콘과 결과 아이콘으로 연결된 원인 카드들의 연속. |
| 모순 | Contradiction | 시간선의 사실이 결말 카드의 사실이나 다른 원인 카드의 조건과 맞지 않는 상태. |
| 패러독스 토큰 | Paradox Token | 모순을 만든 플레이어가 받는 벌점 토큰. |
| 비밀 목표 | Secret Motive | 각 플레이어가 비공개로 가지는 득점 조건 카드. |
| 시간 기록관 | Chronicler | 플레이어를 가리키는 테마상의 이름. |
