# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 모래술사 | Sandbinder | 플레이어를 가리키는 테마상의 이름. |
| 모래병 | Sandling | 보드 위에서 움직이는 플레이어의 말. 모래 받침과 모래시계로 이루어진다. |
| 모래 받침 | Base | 모래시계를 꽂는 말 받침. 플레이어 색과 모래병 종류를 표시한다. |
| 모래시계 | Hourglass | 모래병에 꽂힌 작은 실물 모래시계. 모래병의 수명과 체력을 나타낸다. |
| 잔량 | Remaining Sand | 모래시계 윗칸에 남은 모래. 모래병의 남은 수명이자 체력이다. |
| 윗칸 | Top Bulb | 세운 모래시계에서는 위쪽 칸. 눕힌 모래시계에서는 주인 쪽을 향한 칸. |
| 아랫칸 | Bottom Bulb | 윗칸의 반대쪽 칸. 지난 시간이 쌓인다. |
| 흐름 멈춤 | Run Out | 세운 모래시계의 윗칸이 비어 모래가 더 이상 떨어지지 않는 상태. |
| 세우기 | Stand | 모래시계를 똑바로 세워 모래가 흐르게 하는 조작. |
| 눕히기 | Lay Down | 모래시계를 옆으로 눕혀 모래 흐름을 멈추는 조작. |
| 뒤집기 | Flip | 모래시계의 위아래를 바꾸는 조작. 역전을 일으킨다. |
| 역전 | Reversal | 뒤집기로 남은 시간과 지난 시간이 서로 바뀌는 효과. |
| 강제 뒤집기 | Forced Flip | 공격으로 적 모래병의 모래시계를 뒤집는 것. |
| 소멸 | Crumble | 잔량이 0이 된 모래병이 보드에서 제거되는 것. |
| 샘 | Spring | 모래병이 자기 모래시계를 뒤집기할 수 있는 보드 칸. |
| 유적 | Ruin | 점령하면 점수를 주는 보드 칸. |
| 대모래시계 | Great Glass | 게임 전체 길이를 재는 큰 모래시계. 차례와 상관없이 계속 흐른다. |
| 활성 플레이어 | Active Player | 지금 차례를 진행하는 플레이어. |
| 선 플레이어 | First Player | 첫 차례를 진행하는 플레이어. |
| 후 플레이어 | Second Player | 선 플레이어 다음에 차례를 진행하는 플레이어. |
| 사구 보드 | Dune Board | 가로 5칸, 세로 5칸의 게임 보드. |
| 인접 | Adjacent | 변을 맞댄 칸. 대각선 칸은 인접하지 않는다. |
| 소환 줄 | Home Row | 각 플레이어 쪽 맨 끝 가로줄 5칸. 모래병을 소환하는 칸이다. |
| 비축 | Reserve | 보드에 없는 자기 모래병을 두는 곳. 소멸한 모래병도 비축으로 돌아온다. |
| 소환 | Summon | 비축의 모래병 하나를 자기 소환 줄의 빈 칸에 놓는 것. |
| 행동 | Action | 보드 위 모래병 하나가 자기 차례에 한 번 하는 이동 또는 공격. |
| 이동 | Move | 모래병이 인접한 빈 칸으로 옮겨 가는 행동. |
| 공격 | Attack | 모래병이 인접한 적 모래병에게 강제 뒤집기를 하는 행동. |
| 정찰병 | Scout | 1분 모래시계를 꽂은 모래병. 한 번 이동할 때 2칸까지 간다. |
| 전사 | Warrior | 2분 모래시계를 꽂은 모래병. |
| 거병 | Giant | 3분 모래시계를 꽂은 모래병. 샘에서 뒤집기를 할 수 없다. |
| 점수 트랙 | Score Track | 점수를 표시하는 0~15칸의 트랙. |
| 마지막 점수 계산 | Final Scoring | 대모래시계로 게임이 끝날 때 두 플레이어가 함께 하는 점수 계산. |
