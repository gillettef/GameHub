# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 접기 보드 | Fold Board | 경첩으로 이어진 패널들로 이루어진 게임 보드. 실제로 접고 펼 수 있다. |
| 패널 | Panel | 접기 보드를 이루는 한 장의 판. 여러 칸을 가진다. |
| 칸 | Cell | 말과 토큰이 놓이는 최소 단위. 좌표로 부른다. |
| 접기 선 | Crease Line | 보드를 접을 수 있는 선. 각 접기 선은 고유한 이름을 가진다. |
| 접기 | Fold | 접기 선 하나를 기준으로 보드의 한쪽 면을 다른 쪽 위에 포개는 행동. |
| 펼치기 | Unfold | 접힌 접기 선 하나를 원래대로 펴는 행동. |
| 접힘 상태 | Fold State | 현재 어떤 접기 선이 어느 방향으로 접혀 있는지를 나타내는 상태. |
| 겹친 칸 | Paired Cells | 접기로 서로 포개진 두 칸. 접기 선에서 같은 거리에 있는 거울 대칭 칸이다. |
| 웜홀 이동 | Wormhole Step | 겹친 칸 한 쌍 사이를 한 걸음으로 건너뛰는 이동. |
| 가려진 칸 | Covered Cell | 접힌 면 아래에 깔려 보이지 않는 칸. |
| 부재 | Absent | 가려진 칸 위의 말과 토큰이 놓이는 상태. 펼치면 풀린다. |
| 길잡이 | Pathfinder | 플레이어를 가리키는 테마상의 이름. 또는 플레이어의 말. |
| 별빛 조각 | Starshard | 칸에 놓이는 득점용 토큰. 닻 칸으로 가져오면 점수가 된다. |
| 닻 칸 | Anchor Cell | 각 플레이어가 조각을 가져와 득점하는 자기 전용 칸. |
