# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 결말 카드 | Ending Card | 게임 시작 시 공개되는 카드. 하나의 사실을 게임 끝까지 고정한다. |
| 대상 | Subject | 게임이 상태를 추적하는 사건 요소(예: 성, 왕, 금고). 게임마다 정해진 수만 쓴다. |
| 시작 상태 | Initial State | 시간선 맨 왼쪽 이전에 각 대상이 가지는 상태. |
| 사실 | Fact | 어떤 대상의 상태(예: 성 = 불탐). 결말 카드와 원인 카드의 결과 아이콘이 사실을 만든다. |
| 시간선 | Timeline | 원인 카드를 놓는 칸의 줄. 결말 카드에 가까울수록 나중 시점이다. |
| 원인 카드 | Cause Card | 플레이어가 시간선에 놓는 카드. 조건 아이콘과 결과 아이콘을 가진다. |
| 조건 아이콘 | Condition Icon | 원인 카드가 성립하려면 그보다 앞선 시점에 참이어야 하는 사실. |
| 결과 아이콘 | Effect Icon | 원인 카드가 그 시점 이후에 참으로 만드는 사실. |
| 인과 사슬 | Causal Chain | 조건 아이콘과 결과 아이콘으로 연결된 원인 카드들의 연속. |
| 모순 | Contradiction | 원인 카드의 조건 아이콘이 그 칸에서 참이 아니거나, 결말 카드가 고정하는 대상에 대해 시간선에서 가장 오른쪽 결과 아이콘이 결말 카드의 사실과 다른 상태. 판정은 왼쪽 최근 사실 규칙을 따른다. |
| 왼쪽 최근 사실 규칙 | Nearest-Left Rule | 어느 칸에서 한 대상의 상태는 그 칸 왼쪽에서 가장 가까운, 그 대상에 대한 결과 아이콘을 따른다는 판정 규칙. 그런 결과가 없으면 시작 상태다. |
| 패러독스 토큰 | Paradox Token | 모순을 만든 플레이어가 받는 벌점 토큰. |
| 비밀 목표 | Secret Motive | 각 플레이어가 비공개로 가지는 카드. 플레이어가 몰래 밀어주는 인물 하나를 가리킨다. |
| 시간 기록관 | Chronicler | 플레이어를 가리키는 테마상의 이름. |
| 모순 카드 | Contradicted Card | 시간선에 놓인 원인 카드 중 모순 상태에 있는 카드. 연쇄 정리로 버려진다. |
| 연쇄 정리 | Cascade | 가장 왼쪽 모순 카드부터 하나씩 버리고 다시 판정하기를 모순이 없어질 때까지 반복하는 절차. |
| 금지 배치 | Illegal Placement | 놓는 카드 자체가 모순이 되는 배치. 허용되지 않는다. |
| 놓기 | Place | 원인 카드 1장을 시간선의 빈 칸에 놓는 차례 행동. 차례 끝에 1장을 보충한다. |
| 교체 | Exchange | 원인 카드 1장을 버리고 덱에서 1장을 가져오는 차례 행동. |
| 미해결 결말 | Unresolved Ending | 게임 종료 시 결과 아이콘이 하나도 없고 시작 상태가 결말 카드의 사실과 다른 대상. |
| 시작 플레이어 | Start Player | 첫 차례를 하는 플레이어. 종료 라운드의 끝을 정하는 기준이다. |
| 라운드 | Round | 모든 플레이어가 차례를 한 번씩 하는 단위. |
| 인물 아이콘 | Figure Icon | 원인 카드마다 1개씩 있는, 그 원인을 일으킨 인물 표시. |
| 결정 원인 | Decisive Cause | 결말 카드가 고정하는 대상에 대한 결과 아이콘을 가진 카드 중 시간선에서 가장 오른쪽 카드. |
| 추리 | Deduction | 게임 종료 후 다른 플레이어의 비밀 목표 인물을 몰래 적어 맞히는 절차. |
| 시작 상태 카드 | Initial State Card | 대상들의 시작 상태를 표시하는 참조 카드. 시간선 맨 왼쪽에 둔다. |
| 인물 | Figure | 사건에 등장하는 6명(하인, 왕비, 대신, 경비대장, 궁정 의사, 광대). 인물 아이콘과 비밀 목표가 가리킨다. |
| 칸 | Slot | 시간선에서 원인 카드 1장을 놓는 자리. |
| 활성 플레이어 | Active Player | 지금 차례를 진행하는 플레이어. |
| 원인 카드 덱 | Cause Deck | 뒷면이 위로 쌓인 원인 카드 더미. 보충과 교체 때 여기서 가져온다. |
| 버림 더미 | Discard Pile | 교체나 연쇄 정리로 버린 원인 카드를 앞면이 위로 쌓는 더미. 다시 섞지 않는다. |
| 종료 라운드 | Final Round | 종료 조건이 처음 만족된 라운드. 이 라운드가 끝나면 게임이 끝난다. |
