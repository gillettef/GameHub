# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

## 판과 구조물

| 용어 | 영문 | 정의 |
|---|---|---|
| 정원 보드 | Garden Board | 7×7 칸으로 나뉜 정사각형 보드. 네 변에 좌석이 있다. 열은 서→동 a~g, 행은 북→남 1~7. |
| 좌석 | Seat | 정원 보드의 한 변. 그 변 앞에 앉은 플레이어의 자리다. |
| 빈 발코니 | Empty Balcony | 3인 게임에서 아무도 앉지 않은 변. |
| 생울타리 | Hedge | 칸 경계에 세우는 입체 벽. 손님 말보다 높고, 손님 말이 넘을 수 없다. |
| 정자 | Pavilion | d4 칸에 세우는 기둥과 지붕만 있는 구조물. 손님 말이 들어가거나 지나갈 수 없다. |
| 접선 지점 | Rendezvous | 첩자를 들여보내 접선할 수 있는 칸. 기본 정원 설계도에서는 c3, e3, e5, c5. |
| 시작 칸 | Start Space | 게임 시작 시 손님 말을 놓는 칸. 칸에 그려진 화살표는 맞닿은 생울타리를 향한다. |
| 정원 설계도 | Garden Plan | 생울타리, 시작 칸, 접선 지점의 배치. 기본은 설계도 A다. |
| 시계 트랙 | Clock Track | 정원 보드 가장자리에 인쇄된 1~8 라운드 칸. |
| 시계 말 | Clock Marker | 현재 라운드를 표시하는 말. |

## 손님 말

| 용어 | 영문 | 정의 |
|---|---|---|
| 손님 말 | Guest Piece | 정원 보드 위를 움직이는 말. 윗면에 번호와 방향 화살표가 있고, 옆면 한 곳에만 가면 면이 있다. |
| 가면 면 | Mask Face | 손님 말의 옆면 중 가면 홈이 있는 한 면. |
| 가면 홈 | Mask Niche | 가면 면에 깊게 판 홈. 안쪽에 문양 타일이 들어간다. 정면 쪽에서만 안이 보인다. |
| 문양 타일 | Crest Tile | 가면 홈에 끼우는 작은 타일. 플레이어 색 문양 또는 중립 문양이 그려져 있다. |
| 문양 | Crest | 문양 타일의 그림. 그 손님 말의 소속을 나타낸다. |
| 방향 | Facing | 손님 말의 가면 면이 향하는 정원 보드의 변(북, 동, 남, 서). |
| 방향 화살표 | Facing Arrow | 손님 말 윗면에서 가면 면 쪽을 가리키는 표시. 방향은 모두에게 공개된다. |
| 가려짐 | Covered | 가면 면이 생울타리나 정자에 맞닿은 상태. 가려진 가면 면은 어느 좌석에서도 보이지 않는다. |
| 첩자 | Agent | 문양이 플레이어 색인 손님 말. 그 색의 플레이어 소속이다. |
| 중립 손님 | Bystander | 문양이 중립(달)인 손님 말. 어느 플레이어에도 속하지 않는다. |
| 떠난 손님 | Departed Guest | 지목되어 정원에서 나간 손님 말. 문양이 보이게 보드 옆에 둔다. |

## 플레이어와 행동

| 용어 | 영문 | 정의 |
|---|---|---|
| 후원자 | Patron | 플레이어를 가리키는 테마상의 이름. |
| 활성 플레이어 | Active Player | 지금 차례를 진행하는 플레이어. |
| 첫 플레이어 | First Player | 매 라운드 가장 먼저 차례를 진행하는 플레이어. 게임 내내 바뀌지 않는다. |
| 비밀 명부 | Secret Roster | 자기 첩자 3개와 자기가 아는 중립 손님 1개의 번호를 적는 비공개 카드. |
| 시야 | Sightline | 자기 좌석에서 볼 수 있는 범위. 자기 변을 향하고 가려지지 않은 가면 면이 보인다. |
| 눈높이 규칙 | Eye-Level Rule | 정원을 보는 위치에 대한 규칙. 눈은 자기 변의 두 모서리 사이, 정원 보드 가장자리 바깥에 있어야 한다. |
| 이동 | Move | 손님 말 하나를 가로나 세로로 1~2칸 옮기는 행동. 자기 좌석 쪽으로는 옮길 수 없다. |
| 지목 | Accusation | 지목 카드 한 장을 내고 손님 말 하나를 골라 가면 면을 모두에게 공개하는 행동. |
| 지목 카드 | Accusation Card | 다른 플레이어 색 하나가 그려진 카드. 각 플레이어는 상대 색마다 한 장씩 가진다. |
| 포획 | Capture | 지목이 맞아서 그 첩자를 자기 앞에 가져오는 것. |
| 오인 토큰 | Mistake Token | 틀린 지목을 한 플레이어가 받는 벌점 토큰. |
| 접선 | Contact | 접선 지점에 있는 자기 첩자를 공개하고 자기 앞에 가져와 점수를 얻는 행동. |
| 정찰 | Scout | 오페라 글라스 토큰을 버리고 다른 좌석 뒤에서 잠깐 보는 행동. |
| 오페라 글라스 토큰 | Opera Glass Token | 정찰할 때 버리는 토큰. 각 플레이어는 2개로 시작한다. |

## 폐기된 용어

| 용어 | 폐기 이유 |
|---|---|
| 낮은 생울타리 / 높은 생울타리 | 생울타리를 한 종류로 통합 (D-007) |
| 정찰 지점 | 정찰은 다른 좌석 뒤에서 한다 (D-013) |
