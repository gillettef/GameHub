# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 로봇 | Bot | 각 플레이어가 소유하는 아레나 위의 말. 두뇌에 꽂힌 규칙 타일대로 움직인다. |
| 조종사 | Pilot | 로봇의 소유자. 규칙을 고칠 수 없고 개입으로만 대응한다. |
| 설계자 | Designer | 어떤 로봇의 두뇌에 규칙 타일을 꽂는 플레이어. 항상 그 로봇 조종사의 왼쪽 플레이어다. |
| 두뇌 | Brain | 로봇마다 있는 슬롯 3칸짜리 규칙 거치대. |
| 슬롯 | Slot | 두뇌의 칸 하나. 번호(1~3)가 검사 우선순위다. |
| 규칙 타일 | Rule Tile | "조건 → 행동" 한 줄이 적힌 타일. 설계자가 슬롯에 뒷면으로 놓은 뒤 모두 동시에 앞면으로 뒤집는다. |
| 조건 | Condition | 규칙 타일의 앞부분. 보드 상태만으로 참·거짓을 판정할 수 있어야 한다. |
| 보드 상태 | Board State | 아레나 위의 모든 것과 각 플레이어 앞에 공개된 토큰. |
| 검사 | Check | 로봇이 슬롯 순서대로 규칙 타일의 조건이 참인지 판정하는 것. |
| 행동 | Action | 규칙 타일의 뒷부분. 조건이 참일 때 로봇이 수행하는 일. |
| 발동 | Trigger | 실행 단계에서 어떤 규칙 타일의 조건이 처음으로 참이 되어 그 행동이 실행되는 것. |
| 기본 행동 | Default Action | 어떤 규칙도 발동하지 않을 때 로봇이 하는 행동. |
| 개입 | Override | 조종사가 규칙 대신 상황을 바꾸는 제한된 행동. |
| 아레나 | Arena | 로봇이 움직이는 공용 보드. |
| 코어 | Core | 아레나에 놓인 회수 대상. 승리 조건의 기준이다. |
| 선 플레이어 | First Player | 그 라운드 실행 단계에서 가장 먼저 로봇을 실행하는 플레이어. 라운드가 끝나면 왼쪽 플레이어에게 넘어간다. |
| 설계자 점수 | Designer Point | 설계자가 설계한 로봇이 실행 차례에 규칙 타일의 행동이나 기본 행동 때문에 충돌했을 때 설계자가 얻는 점수 토큰. |
| 에너지 | Energy | 조종사가 개입에 쓰는 자원. 1개로 시작해 매 라운드 1개를 받고 최대 3개까지 가진다. |
| 회전 | Turn | 조종사가 자기 로봇을 좌회전 또는 우회전시키는 개입. |
| 차단 | Block | 자기 로봇 두뇌의 슬롯 하나를 이번 라운드 동안 검사하지 않게 하는 개입. |
| 추진 | Thrust | 조종사가 자기 로봇을 1칸 전진시키는 개입. |
| 주머니 | Bag | 규칙 타일을 넣어 두고 무작위로 뽑는 공용 주머니. |
| 칸 | Space | 아레나의 격자 한 칸. 열은 A~G, 행은 1~7로 부른다(예: D4). |
| 가장자리 칸 | Edge Space | 아레나 바깥 테두리에 붙은 칸. A열·G열·1행·7행의 칸이다. |
| 기둥 | Pillar | 아레나에 인쇄된 고정 장애물. 로봇이 들어갈 수 없다. |
| 코어 생성 지점 | Core Spot | 코어가 놓이는 칸. 아레나에 표시되어 있다. |
| 시작 칸 | Start Space | 게임 준비 때 로봇을 놓는 칸. 방향 화살표가 인쇄되어 있다. |
| 방향 | Facing | 로봇이 바라보는 쪽. 위·아래·왼쪽·오른쪽 중 하나다. |
| 앞 칸 | Front Space | 로봇이 바라보는 방향으로 맞닿은 칸 하나. |
| 앞줄 | Line | 로봇의 앞 칸부터 바라보는 방향으로 곧게 이어진 칸들. 아레나 끝, 기둥, 로봇에서 끊긴다. |
| 막힌 칸 | Blocked Space | 아레나 밖, 기둥이 있는 칸, 로봇이 있는 칸. |
| 비어 있다 | Empty | 막힌 칸이 아닌 칸의 상태. 코어가 있는 칸도 비어 있다. |
| 인접 | Adjacent | 상하좌우로 맞닿은 관계. 대각선은 인접하지 않는다. |
| 거리 | Distance | 두 칸 사이를 상하좌우로만 셀 때의 칸 수. 기둥과 로봇은 무시하고 센다. |
| 충돌 | Bump | 로봇이 막힌 칸으로 이동하려다 멈추는 것. |
| 실행 차례 | Execution Turn | 실행 단계에서 로봇 한 대의 조종사가 개입할 수 있고, 그 로봇이 규칙을 검사·실행하는 차례. |
| 차단 토큰 | Block Token | 차단한 슬롯 위에 올려 두는 토큰. |
| 공급처 | Supply | 플레이어가 아직 갖지 않은 토큰을 모아 두는 곳. |
| 충전 단계 | Charge Phase | 라운드의 1단계. 조종사가 에너지를 받는다. |
| 설계 단계 | Design Phase | 라운드의 2단계. 설계자가 규칙 타일을 뽑아 꽂는다. |
| 실행 단계 | Execution Phase | 라운드의 3단계. 로봇들이 차례대로 실행 차례를 갖는다. |
| 정리 단계 | Cleanup Phase | 라운드의 4단계. 타일을 거두고 코어를 보충한다. |
| 전진 | Forward | 로봇이 바라보는 방향으로 1칸씩 이동하는 행동. |
| 후퇴 | Back Up | 로봇이 방향을 바꾸지 않고 바라보는 방향의 반대쪽으로 1칸씩 이동하는 행동. |
| 멈출 때까지 전진 | Advance to Stop | 로봇이 앞 칸이 막힌 칸이 될 때까지 1칸씩 전진하는 행동. |
| 좌회전 | Turn Left | 로봇을 위에서 내려다볼 때 반시계 방향으로 90° 돌리는 것. 로봇이 바라보는 방향을 기준으로 한다. |
| 우회전 | Turn Right | 로봇을 위에서 내려다볼 때 시계 방향으로 90° 돌리는 것. 로봇이 바라보는 방향을 기준으로 한다. |
| 뒤로 돌기 | About Face | 로봇을 제자리에서 180° 돌리는 행동. |
| 대기 | Wait | 로봇이 아무것도 하지 않는 행동. |
