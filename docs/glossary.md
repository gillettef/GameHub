# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 함대 | Fleet | 플레이어가 운용하는 부대 단위. 실체 하나와 잔상 하나로 이루어지며 번호 1·2·3을 가진다. |
| 실체 | Real | 함대의 실제 위치. 소유자만 안다. 그 함대의 광선 컨베이어 앞 칸 카드가 나타낸다. |
| 잔상 | Echo | 메인 보드에 공개된 함대 말. 실체를 일정 라운드 늦게 따라간다. |
| 파문 | Ripple | 행동이 공개·확정되기까지의 지연. 파문 컨베이어 위에 엎어진 행성 카드와 위장 카드로 표현한다. |
| 모항성 | Home Star | 각 플레이어의 본거지. 지연 거리를 재는 기준점이다. |
| 지연 | Lag | 실체와 잔상 사이, 또는 행동과 공개 사이의 라운드 차이. |
| 도달 | Arrival | 행성 카드나 위장 카드가 파문 진행 때 파문 컨베이어의 1번 칸에서 옮겨지는 것. 도달 시점에 카드가 공개되고 점령이 확정된다. |
| 행성 | Planet | 점령 대상. 승리 조건의 기준이다. |
| 메인 보드 | Main Board | 두 플레이어가 공유하는 공개 보드. |
| 성계 | System | 메인 보드의 노드. 함대가 머무는 위치 단위다. |
| 항로 | Lane | 두 성계를 잇는 선. 함대는 항로를 따라 이동한다. |
| 항로 거리 | Lane Distance | 두 성계 사이 최단 경로에 있는 항로의 수. |
| 지연 구간 | Lag Band | 상대 모항성까지의 항로 거리로 나눈 구역. 성계에 색 띠로 인쇄되며 지연을 정한다. |
| 광선 컨베이어 | Light Conveyor | 함대마다 성계 카드와 머무름 카드를 엎어 두는 줄. 줄의 길이가 그 함대의 지연이다. |
| 따라잡기 | Catch-up | 잔상이 더 가까운 지연 구간에 들어설 때 카드를 추가로 공개하는 것. |
| 정체 | Stall | 잔상이 더 먼 지연 구간에 들어설 때 그 라운드에 카드를 공개하지 않는 것. |
| 계획 단계 | Plan Phase | 두 플레이어가 동시에 비밀로 각 함대의 이동을 정하는 단계. |
| 처리 단계 | Resolution Phase | 정한 계획을 동시에 처리하는 단계. |
| 파문 컨베이어 | Ripple Conveyor | 플레이어마다 행성 카드와 위장 카드를 엎어 두는 1~5번 칸 판. 행성 카드는 그 행성의 파문 거리 번호 칸에 놓는다. |
| 파문 거리 | Ripple Distance | 한 성계에서 두 모항성까지의 항로 거리 중 큰 값. 점령이 확정되기까지 걸리는 라운드 수다. |
| 위장 | Decoy | 위장 카드를 파문 컨베이어의 3~5번 칸에 놓는 것. |
| 공격 선언 | Strike | 공격 함대의 실체가 있는 성계를 밝히고 상대 실체가 있는지 묻는 것. |
| 교전 | Engagement | 같은 성계에 있는 양쪽 함대가 전력을 비교해 승패를 가리는 것. |
| 전력 | Strength | 교전에서 비교하는 함대의 힘 수치. |
| 귀환 | Recall | 교전에서 지거나 동률이 된 함대를 자기 모항성으로 되돌리는 것. |
| 확정 점령 | Confirmed Hold | 행성 카드가 도달하여 점령 마커가 놓인 행성 점령. |
| 승리 점령 수 | Victory Threshold | 즉시 승리에 필요한 확정 점령 행성의 수. |
| 마지막 빛 | Last Light | 마지막 라운드가 끝난 뒤 파문 컨베이어 1·2번 칸의 카드만 공개·반영하는 절차. |
| 단순판 | Basic Mode | 모든 함대의 지연을 2로 고정한 규칙. 현재 룰북의 기준이다. |
| 점령 마커 | Hold Marker | 확정 점령을 표시하는 플레이어 색 마커. |
| 성계 카드 | System Card | 함대마다 성계 19곳이 하나씩 인쇄된 카드. 이동할 성계를 비밀로 정한다. |
| 머무름 카드 | Stay Card | 실체가 제자리에 머문다는 것을 나타내는 카드. |
| 공격 카드 | Strike Card | 함대마다 1장. 공개하면 그 함대가 공격을 선언한다. |
| 행성 카드 | Planet Card | 점령한 행성을 나타내는 카드. 파문 컨베이어에 엎어 놓는다. |
| 위장 카드 | Decoy Card | 행성 카드와 뒷면이 같고 아무 효과가 없는 카드. |
| 공격 표식 | Strike Marker | "없다"는 답변을 2라운드 뒤 공개 카드로 확인하기 위해 대상 성계에 놓는 표식. |
