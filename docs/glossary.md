# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 이야기꾼 | Teller | 플레이어를 가리키는 테마상의 이름. 각자 한 집안을 대표한다. |
| 집안 색 | House Color | 각 플레이어를 나타내는 색. 빨강, 파랑, 노랑, 초록, 보라, 검정의 6가지. 땅 타일, 구역 카드 뒷면, 증언 토큰, 기록 표지, 점수 표지에 표시된다. |
| 섬 보드 | Island Board | 구역을 행으로, 계절을 열로 하는 칸이 그려진 공용 보드. 점수 트랙이 둘레에 있다. |
| 구역 | Plot | 섬 보드의 이름 붙은 땅. 섬 보드의 한 행이다. 구역마다 구역 값이 인쇄되어 있다. |
| 구역 값 | Plot Value | 구역에 인쇄된 2~4의 수. 공식 역사에 그 칸의 주인으로 기록된 집안이 얻는 점수다. |
| 계절 | Season | 게임의 한 라운드. 게임은 7계절과 마지막 회의로 진행한다. 섬 보드의 한 열이다. |
| 칸 | Cell | 한 구역과 한 계절이 만나는 자리. 땅 타일이나 기록 표지를 놓는다. |
| 점유 단계 | Claim Phase | 각 플레이어가 구역 카드를 몰래 골라 동시에 공개하고, 겹치지 않으면 땅 타일을 놓는 단계. |
| 구역 카드 | Plot Card | 뒷면에 집안 색, 앞면에 구역이 그려진 카드. 점유 단계에서 갈 구역을 몰래 고르는 데 쓴다. |
| 다툼 | Feud | 점유 단계에서 두 명 이상이 같은 구역을 공개한 상황. 그들은 땅 타일을 놓지 못하고 바로 망각 주머니에 넣는다. |
| 주인 없는 칸 | Unowned Cell | 그 계절이 끝났을 때 땅 타일이 없는 칸. 회색 증언이 진실인 칸이다. |
| 땅 타일 | Land Tile | 앞면에 집안 색만 표시된 타일. 뒷면은 모두 같다. |
| 망각 단계 | Forgetting Phase | 2계절부터 매 계절 점유 단계 뒤에 직전 계절 열을 망각하는 단계. |
| 망각 | Forgetting | 정해진 계절 열의 땅 타일을 모두 섬 보드에서 치워 바로 망각 주머니에 넣고 섞는 절차. |
| 망각된 계절 | Forgotten Season | 망각 절차를 마친 열의 계절. |
| 망각 주머니 | Oblivion Bag | 망각된 땅 타일을 넣는 불투명 주머니. 누구도 안을 보거나 내용물을 꺼낼 수 없다. |
| 회의 | Council | 망각 뒤에 질문과 증언으로 공식 역사를 정하는 단계. 2~7계절에는 4·5인 질문 2개, 6인 질문 1개를 진행한다. |
| 마지막 회의 | Final Council | 7계절 회의 뒤에 7계절 열을 망각하고 인원별로 정해진 수의 질문을 진행하는 회의. |
| 질문자 | Questioner | 질문자 표지를 가진 플레이어. 회상 카드를 뽑아 질문 칸을 고르고, 점유 공개·망각·집계를 진행한다. 최다 동점일 때 질문자의 유효한 증언이 동점 답 중 하나이면 그 답이 공식 역사가 된다. |
| 질문자 표지 | Questioner Marker | 질문자를 표시하는 표지. 질문이 끝날 때마다 왼쪽 플레이어에게 넘어간다. |
| 질문 표지 | Question Marker | 질문 칸을 가리키는 표지. |
| 회상 카드 | Recall Card | 구역 하나가 그려진 카드. 질문자가 물을 구역의 후보가 된다. |
| 질문 가능 칸 | Askable Cell | 망각된 계절에 속하고 기록 표지가 없는 칸. |
| 질문 칸 | Questioned Cell | 질문자가 이번 질문의 대상으로 고른 질문 가능 칸. |
| 속삭임 시간 | Whisper Time | 질문 칸 선언부터 모래시계가 다 떨어지거나 모두 주먹을 내밀 때까지 자유롭게 협상하고 주장하는 시간. |
| 증언 토큰 | Testimony Token | 증언에 쓰는 토큰. 각 플레이어는 자기 집안을 뺀 참여 집안 색 한 개씩과 회색 한 개를 가진다. 그래서 누구도 자기 집안을 증언할 수 없다. |
| 회색 증언 토큰 | Grey Testimony Token | "그 칸에는 아무 집안도 없었다"를 뜻하는 증언 토큰. |
| 무효 증언 | Void Testimony | 속삭임 시간 안에 내밀지 않았거나, 토큰이 없거나 둘 이상이거나, 위반 판정을 받은 증언. 집계하지 않는다. |
| 증언 | Testimony | 질문 칸에 대해 증언 토큰 하나를 동시에 공개하는 행동, 또는 그 토큰이 가리키는 답. |
| 공식 역사 | Official History | 질문 칸에 대해 유효한 증언 중 단독으로 가장 많은 답, 또는 최다 동점일 때 동점 답 중 질문자가 유효하게 증언한 답. 기록 표지로 섬 보드에 고정되며 득점의 기준이 된다. |
| 공백 | Blank | 최다 동점인데 질문자의 유효한 증언이 동점 답에 없거나, 유효한 증언이 하나도 없어 공식 역사가 정해지지 않은 칸. 회색 기록 표지로 표시한다. |
| 기록 표지 | Chronicle Marker | 공식 역사나 공백을 표시하려고 칸에 놓는 표지. 집안 색 표지와 회색 표지가 있다. 한번 놓이면 게임 끝까지 옮기지 않는다. |
| 평판 | Reputation | 공식 역사(집안 색 또는 회색)와 같은 증언을 낸 플레이어가 받는 1점. 점수 1점과 같다. |
| 점수 트랙 | Score Track | 섬 보드 둘레의 점수 칸. 각 플레이어의 점수 표지로 점수를 표시한다. |
| 점수 표지 | Score Marker | 점수 트랙에서 각 플레이어의 점수를 표시하는 집안 색 표지. |
| 메모 금지 | No-Notes Rule | 메모·사진·녹음과 물건·몸의 배치로 지난 일을 표시하는 행위를 금지하는 규칙. |
| 위반 판정 | Violation Ruling | "~할 수 없다" 규칙 위반을 나머지 플레이어의 동시 거수 과반으로 정하는 절차. 위반이면 3점 감점(질문 중 위반은 그 증언도 무효), 아니면 지적한 사람이 1점 감점. 점수는 음수가 될 수 있다. |
