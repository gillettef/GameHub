# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 실체 | Fleet | 함대의 실제 위치. 소유자만 안다. 가림막 뒤 개인 미니 보드에 둔다. |
| 잔상 | Echo | 메인 보드에 공개된 함대 말. 실체를 일정 라운드 늦게 따라간다. |
| 파문 | Ripple | 행동이 일어난 지점에 놓이고 매 라운드 퍼져 나가는 토큰. 상대에게 닿으면 행동이 공개된다. |
| 모항성 | Home Star | 각 플레이어의 본거지. 지연 거리를 재는 기준점이다. |
| 지연 | Lag | 실체와 잔상 사이, 또는 행동과 공개 사이의 라운드 차이. |
| 도달 | Arrival | 파문이 상대 함대나 모항성에 닿는 것. 도달 시점에 행동 내용이 공개된다. |
| 행성 | Planet | 점령 대상. 승리 조건의 기준이다. |
| 메인 보드 | Main Board | 두 플레이어가 공유하는 공개 보드. |
| 미니 보드 | Command Board | 가림막 뒤에서 자기 실체 위치를 관리하는 개인 보드. |
