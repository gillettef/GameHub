# SIGHTLINE 컨셉

## 한 줄 소개

> 건너편 자리의 그 사람에게는 분명히 보였을 것이다. 당신 눈앞에는 생울타리뿐이다.

## 기본 정보

- **인원:** 3~4인
- **시간:** 30~40분
- **연령:** 10세 이상 (가안)
- **장르:** 숨은 정보, 블러핑, 공간 추리
- **테마 (가안):** 달빛 아래 귀족 저택의 정원에서 열리는 가면무도회. 플레이어는 정원 바깥 네 방향의 발코니에서 무도회를 내려다보는 후원자이며, 각자 가면 쓴 첩자들을 손님 사이에 숨겨 들여보냈다.

## 핵심 경험

1. **내 자리에서만 보이는 것이 있다.** 동쪽을 향한 가면은 동쪽 발코니에서만 보인다. 모두 같은 판을 보지만 사실상 다른 게임을 한다.
2. **내 손으로는 나에게 보여 줄 수 없다.** 내 좌석에 가면이 드러나는 이동은 할 수 없다. 내가 손님을 움직이면 그 가면은 다른 누군가에게 보이거나 생울타리 뒤에 숨는다. 내 정보는 남의 손에서 온다.
3. **누가 무엇을 봤는지는 모두가 안다. 무엇을 봤는지는 그 사람만 안다.** 방향 화살표는 공개라서 "저 사람은 7번 가면을 봤다"는 사실은 모두가 안다. 그런데 왜 지목하지 않을까? 자기 첩자라서? 중립이라서? 지목 카드를 아끼는 중이라서?

## 핵심 시스템 (v2.2 기준, 상세는 `rules/rulebook.md`)

- **정원 보드:** 7×7, 가운데 정자(막힌 난간), 생울타리 12개, 접선 지점 4곳. 배치는 90도 회전 대칭이라 좌석 유불리가 없다.
- **손님 말:** 옆면 한 곳에 차양 달린 가면 홈이 있고 그 안에 문양 타일이 들어간다. 홈은 정면 쪽에서만 들여다보인다. 윗면에는 번호와 방향 화살표가 있다.
- **가림:** 가면 바로 앞에 생울타리, 정자, 다른 손님 말이 있으면 가려진다. 막던 것이 치워지면 다시 드러난다.
- **정체 정하기:** 각자 빈 손님 말 4개를 몰래 꺼내 자기 첩자 문양 3장과 중립 1장을 끼우고, 다시 섞어 번호가 같은 시작 칸에 놓는다. 시작할 때 모든 가면은 가려져 있다.
- **차례:** 행동 하나만 한다.
  - 이동: 아무 말이나 1~2칸 옮긴다. 이동 방향이 곧 가면 방향이다. 내 좌석에 가면이 새로 드러나는 이동은 금지다.
  - 지목: 왼쪽 플레이어 색 카드로, 지금 앉은 좌석을 향한 말에만 한다. 맞으면 카드를 돌려받는다.
  - 접선: 접선 지점에 있는 자기 첩자를 공개한다. 3점이다.
  - 정찰: 게임당 1회, 남의 좌석에 앉아 열까지 보고 그 자리에서 지목할 수 있다.
- **초대장 토큰:** 접선 지점에 들인 말은 들인 사람의 다음 차례까지 잠긴다.
- **종료:** 8라운드. 접선 3점, 포획 2점, 오인 −1점.

## 열린 질문

- [x] 정보를 담는 방식 → 옆면 가면 홈 (D-004, D-005)
- [x] 눈높이 규칙을 어떻게 고정할까? → 말 형태(가면 홈)와 맞닿음 가림으로 자세 단속을 없앴다. 남은 규칙은 "눈은 자기 변 앞" 하나 (D-005, D-007)
- [x] 정찰의 비용과 시간 제한 → 오페라 글라스 2개, 열까지 세기 (D-013)
- [x] 이동한 말의 방향 규칙 → 이동 방향 고정, 자기 쪽 이동 금지 (D-008)
- [x] 자기 첩자를 남이 옮기는 것을 허용할까? → 허용. 번호가 공개라서 추적은 비밀 명부로 한다 (D-008, D-010)
- [x] 3인일 때 비는 한 변 → 빈 발코니 (D-016)
- [x] 배치 고정 또는 배치 카드? → 기본 설계도 A, 회전 대칭 (D-015). 추가 설계도는 플레이테스트 후
- [ ] 2인 변형을 둘 것인가? (보류. 1차 제출 범위 밖)
- [ ] 수치 검증: 시뮬레이션으로 1차 조정 완료(D-019~D-032). 실물 플레이테스트로 확인 필요
- [ ] 3인 오페라 글라스 1개 검증, 3인 마지막 차례 편차 확인
- [ ] 가면 홈과 생울타리의 실제 치수 검증 → 3D 프린트 시제품으로 확인
