# CREASE 컨셉

## 한 줄 소개

> 지도 끝에 있는 별빛 조각까지는 열두 칸. 지도를 반으로 접으면, 한 칸.

## 기본 정보

- **인원:** 2~4인
- **시간:** 30~45분
- **장르:** 경주, 수집, 공간 퍼즐, 촉각형(덱스터리티 요소 최소)
- **테마 (가안):** 종이로 지어진 세계 "접지 군도". 플레이어는 지도를 접어 먼 섬 사이를 건너는 **길잡이**들이며, 군도 곳곳에 흩어진 **별빛 조각**을 모아 자기 **닻 칸**으로 가져온다.

## 핵심 경험

1. **손으로 공간을 구부린다.** 보드를 직접 접는 순간 멀리 있던 두 칸이 맞닿는다. "여기랑 저기가 붙는다고?" 하는 촉각적인 놀라움.
2. **한 번의 접기로 판이 뒤집힌다.** 상대가 노리던 조각이 접힌 면 아래로 사라지고, 내 말 앞에 지름길이 열린다.
3. **접힌 판을 읽는다.** 지금 어느 선이 접혀 있고, 펼치면 누가 어디로 돌아오는지 계산하는 공간 퍼즐.

## 핵심 시스템 (현재: 룰북 v1.2)

> 규칙의 기준은 `rules/rulebook.md`다. 아래는 요약이다.

- **띠 보드:** 9열 × 5행. 날개 패널 6장(A·B·C·G·H·I) + 중앙 패널(D~F), 경첩 6개. 양 끝을 접기 폭 1~3으로 안쪽 위에 접는다. 양쪽 폭의 합은 4 이하(D-005).
- **이음:** 접힌 날개의 끝(A열·I열)이 드러난 열과 맞닿아 새로 이웃한다. 별도 웜홀 규칙은 없다.
- **차례:** 최대 3걸음 + 접기나 펼치기 1번(걸음 사이에 끼워 넣기)(D-007). 차례 끝에 별똥별 카드 1장(D-008).
- **부재:** 가려진 칸의 말은 눕히고 조각은 빈 면으로 날개 위에 둔다. 펼치면 돌아온다(D-006).
- **날개 터뜨리기:** 별똥별이 가려진 칸을 가리키면 그 날개가 펼쳐진다(D-011).
- **승리:** 들고 다니는 조각 최대 2개를 닻 칸에서 득점. 목표 점수(2인 10, 3인 9, 4인 7) 도달 시 그 라운드 끝까지(D-010, D-013). 동점이면 결승 라운드(D-012).

## 열린 질문

- [x] 접기 선의 수와 위치 → D-005 (패널 경계 6개, 양 끝에서만)
- [x] 동시에 접혀 있을 수 있는 선의 수 → D-005 (한쪽에 날개 하나, 폭 합 4 이하, 날개끼리 포개지지 않음)
- [x] 접기 지속 → D-007, D-011 (누군가 펼치거나 날개 터뜨리기가 일어날 때까지 유지)
- [x] 접는 방향 → D-005 (항상 끝을 안쪽 위로. 고르는 것은 쪽과 폭)
- [x] 패널 뒷면 → D-005 (날개 패널 뒷면에 같은 좌표 인쇄, 뒷면 칸에서 이동 가능)
- [x] 부재 중 들고 있던 조각, 펼칠 때 같은 칸의 다른 말 → 룰북 7.2, 6장 (그대로 들고 있음, 한 칸에 여러 말 가능)
- [x] 접기 행동의 비용 → D-007 (차례에 1번, 무료)
- [ ] **내구성:** 경첩 6개 보드의 반복 접기 내구성과 생산 단가 (출판사 협의 사항)
- [x] **말 미끄러짐** → D-006 (접기 전에 들었다가 다시 놓는 절차)
- [x] **두꺼운 패널** → D-005, 룰북 6.1 (좌표로만 판정, 행 색 띠 인쇄)
- [x] 패널 수, 칸 수, 조각 수, 목표 점수, 종료 조건 → D-005, D-009~D-013
- [ ] 실물 시제품으로 접는 절차 시간, 한 칸 수용량, 3폭 날개 처짐 확인
