# AI 카드 순서 보정 — 2026-10-19 (v6 규칙 그대로)

v6 리포트(`2026-10-18-v6.md`) 조정안 1번의 적용 결과. 규칙·데이터 변경 없음, `src/core/ai.ts`만 바뀐다.

## 1. 변경
- `cardCost(state, hand, stage, demand, style)`: 기존 '낼지 말지' 비용(희소성 × cardValue + 데드라인 예약)에
  **카드 종류 항** `(그 카드 수수료 − 손패 평균 수수료) × cardRel × style`을 더한다. 마지막 라운드 2차에는 0
  - 카드는 결국 8장을 다 쓰므로 지금 높은 카드를 내면 그 수수료는 '나중에 받을 수 있던 돈'이다 → 경쟁이 없을 때 높은 카드, 경쟁할 때 낮은 카드
- `cardStyle(state, agentIdx)`: 게임마다 에이전트별 배율 `1 ± cardMix`를 구단 구성·자리의 해시로 정한다 (rng 상태를 건드리지 않아 기존 시드 흐름 유지, 재현 가능)
  - 모든 AI가 같은 순서로 쓰면 반대 순서 고정 전략이 이기므로(v6 3-1) 혼합 전략처럼 섞는다
- `AI_MODEL`: `cardRel 0.5`, `cardMix 1` 추가

## 2. ③-5 퇴화 전략 (3인, `league.ts --depths 1/4 --only degen`, 1000판)
| 설정 (cardRel / cardMix) | 최저 카드 s42 · s7 | 최고 카드 s42 · s7 | 최악 |
|---|---|---|---|
| 0 / 0 (기존) | 40.0 · 38.5% | 37.3 · 36.5% | 40.0% |
| **0.5 / 1 (채택)** | **34.1 · 31.2%** | **37.6 · 36.5%** | **37.6%** |
| 0.25 / 1 | 35.8 · 37.8% | 33.4 · 36.2% | 37.8% |
| 1 / 1 | 31.1% | 40.4% | 40.4% |
| 0.5 / 0.5 | 33.7% | 36.5% | 36.5% (s42만) |
| 0.5 / 2 | 30.5% | 37.7% | 37.7% |
| 1 / 0.5 | 30.6% | 41.2% | 41.2% |
| 0.25 / 2 | 37.3% | 36.6% | 37.3% |
| 0.5 / 1, cardValue 8 | 33.9% | 35.9% | 35.9% (s42만) |

- cardRel이 시소의 받침점이다. 0.5 근처에서 두 고정 순서가 비슷해지고, 그 위로 가면 최고 카드, 아래로 가면 최저 카드가 이긴다
- 어느 설정에서도 최악 전략이 35~38%로 공정값(33.3%)을 넘는다 → **③-5는 여전히 실패**. 다만 균형형 복제 상대 참고값은 44.5 → 36.6%(최저)로 크게 줄었다
- s42만 잰 0.5/0.5와 cardValue 8은 차이가 표본 오차(±1.5%p) 안이라 채택하지 않았다
