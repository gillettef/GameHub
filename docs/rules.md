# 룰 정리 (개정 pptx 기준, 최신)

> 출처: `notes/놀이공원.pptx`. **슬라이드 9~14(준비/진행/종료)에는 단계 이름만 있고 상세 규칙 텍스트가 없다.** 아래 "미정" 항목은 사용자 확인 필요.

## 1. 개요
- 2~5인 경영 보드게임, 가장 높은 만족도(VP) 획득이 목표 (v1: 60~90분).

## 2. 구성요소 (슬라이드 4~8)
- 메인 보드, 개인 보드(관객·시설·운영 3구역)
- 관객카드(덱), 시설카드, 운영카드
- 토큰: 수리 토큰, 쓰레기 토큰
- 돈: $1 / $2 / $5, VP: 1 / 5
- **관객 트랙**: 입구 → $0 $1 $2 $3 $4 칸, 관객카드가 칸에 배치됨(덱에서 보충)
- **인력 트랙**: 엔지니어 / 마케팅 전문가 / 환경 미화원 / 안내 직원 / 연구원 (메인보드에도 존재)
- 시설카드 예시: 롤러코스터 — 건설 10, 유지 3, 수익 3/7(어린이/성인), 만족도 1/7, 특수효과 "날씨 나쁠 때 유지비 +2"

## 3. 진행
- 턴: **건설 → 홍보 → 운영 → 관리** (상세 미정)
- 종료/준비/승리 조건 상세 미정

## 미정 (확인 필요)
1. 각 인력의 효과(추정: 엔지니어=수리토큰, 환경미화원=쓰레기토큰, 마케팅=관객 유치, 안내직원=관객 만족/수용, 연구원=?)
2. 인력 트랙 사용법(승급? 비용? 칸 수?)
3. 수리/쓰레기 토큰 발생 조건과 패널티
4. 운영카드의 역할, 이벤트 카드(v1)의 존속 여부
5. 관객 트랙 $0~$4의 의미(입장료? 관객카드 가격?)
6. 턴 4단계 각각의 구체적 행동, 라운드 수, 종료 조건, 시작 자금
7. VP 획득 방식(v1은 만족도 트랙)
