# 룰 정리 (개정 pptx 기준, 최신)

> 출처: `notes/놀이공원.pptx`. **슬라이드 9~14(준비/진행/종료)에는 단계 이름만 있고 상세 규칙 텍스트가 없다.**
> 빈 부분은 현재 구현 룰 `docs/design-v0.md`가 임시로 채웠다. 이 문서는 pptx 원문 정리와 "pptx 항목 → 현재 구현" 대응만 담고, 규칙의 정의는 design-v0.md 한 곳에 둔다.

## 1. 개요
- **2~5인** 경영 보드게임. 가장 많은 VP를 얻는 것이 목표 (v1: 60~90분).
- 디지털 구현: 사람 0~1명 + AI, 전체 2~5인. 한 기기 다인(핫시트) 미지원 → design-v0.md 1절.

## 2. 구성요소 (슬라이드 4~8)
- 메인 보드, 개인 보드(관객·시설·운영 3구역)
- 관객카드(덱), 시설카드, 운영카드
- 토큰: 수리 토큰, 쓰레기 토큰
- 돈: $1 / $2 / $5, VP: 1 / 5
- **관객 트랙**: 입구 → $0 $1 $2 $3 $4 칸, 관객카드가 칸에 배치됨(덱에서 보충)
- **인력 트랙**: 엔지니어 / 마케팅 전문가 / 환경 미화원 / 안내 직원 / 연구원 (메인보드에도 존재)
- 시설카드 예시: 롤러코스터 — 건설비 10, 유지비 3, 수익 3/7(어린이/성인), 만족도 1/7, 특수효과 "날씨 나쁠 때 유지비 +2"

디지털 구현에서의 재해석(관객 트랙 → 지불 한도·입장료, 운영카드 → 공용 이벤트 16장, 개인 보드 → 부지 6칸, 인력 트랙 → Lv 0~3 개인 트랙, 토큰 → 숫자)은 design-v0.md 11.1절.

## 3. 진행
- 턴: **건설 → 홍보 → 운영 → 관리** (pptx는 단계 이름만 있음)
- 준비·각 단계의 행동·종료·승리의 현재 구현값은 design-v0.md 3~7절.

## 4. 이전 "미정" 항목의 현재 구현값
pptx만으로는 정해지지 않아 임시로 구현한 값이다. **모두 사용자 확정 필요**(design-v0.md 11절).

| # | 이전 미정 항목 | 현재 구현 (design-v0.md) |
|---|---|---|
| 1 | 각 인력의 효과 | 5절 표: 마케팅 전문가=관객 +1, 안내 직원=시설 수용 +1, 엔지니어=고장 확률↓·무료 수리, 환경 미화원=무료 청소, 연구원=건설비 할인·만족도 (모두 Lv당) |
