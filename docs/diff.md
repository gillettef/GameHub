# v1(xlsx) vs 개정(pptx) 차이

충돌 시 pptx를 우선한다. "현재 구현" 열은 pptx의 빈 부분을 채운 `docs/design-v1.md` 기준(확정 필요).

| 항목 | v1 (xlsx) | 개정 (pptx, 우선) | 현재 구현 (design-v1) |
|---|---|---|---|
| 게임명 | Fantasy Park Tycoon | (미표기) | SmilePark |
| 인원 | 2~5인 | 2~5인 | 사람 0~1 + AI, 전체 2~5인 |
| 라운드 | 경영→이벤트→건설→관람객 입장→수익→평가 | 건설→홍보→운영→관리 | pptx 4단계, 8라운드 |
| 경영 | 경영포인트 5를 재무/홍보/관리/연구에 배분 | 인력 트랙(엔지니어·마케팅 전문가·환경 미화원·안내 직원·연구원) | 인력별 Lv 0~3 개인 트랙, 관리 단계에 라운드당 1명 |

## 이벤트: v1 20장 → 구현 16장
카드별 내용은 `docs/cards.md`.

| 구분 | 카드 |
|---|---|
| v1에서 이어받음(수치·대상 정리) | 맑은 날씨, 비 오는 날, 가족의 날 이벤트→가족의 날, 할로윈 축제, 여름 물놀이 축제, 봄 축제, 할인 쿠폰 배포→할인 쿠폰, 눈 오는 날, 인플루언서 방문, 정전 발생, 가수 공연 (11장) |
| 비슷한 개념으로 대체 | 야경 축제 → 불꽃놀이 야간 개장(스릴형), 해피 아워 → 어린이날(놀이형) |
| 구현에서 새로 만듦 | 쓰레기 대란, 탐험 주간(어드벤처형), 과학의 날(교육형) |
| 뺌 | 공포 이벤트(할로윈 축제와 중복), 기념일 이벤트, 응급 상황 발생, 차량 문제, 피로 누적, 무료 음료 제공, 미니 퍼레이드 (7장) |

주요 변화
- **유형 편중 해소**: 놀이기구 7유형마다 전용 이벤트(배치마다 만족도 +2)가 1장씩 있고, 상점은 가수 공연·눈 오는 날이 담당한다.
- **효과는 아이콘 하나 + 숫자 하나**: 배치당 만족도 보정, 모집 수 보정, 상점 수익 보정, 추가 쓰레기, 정전(수리 토큰). 무작위 판정은 없다.
- **아이콘 체계**: 맑음·악천후·야간·축제·가족·할로윈·여름·탐험·학습·어린이날. 시설 특수효과가 반응한다(`docs/design-v1.md` 7절).
