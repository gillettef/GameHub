# LIGHTCONE 플레이테스트 피드백 시트

플레이가 끝나면 바로 플레이어 한 명당 한 장씩 적는다. 진행자는 맨 아래 "진행자 기록"을 적는다.
작성한 시트는 사진을 찍거나 내용을 그대로 전달하면 `/playtest-report`로 `playtests/`에 정리한다.

- 날짜:            룰북 버전:           성운 카드:
- 플레이어(이름 또는 별칭):              보드게임 경험: 처음 / 가끔 / 자주
- 맡은 쪽: A / B        결과: 승 / 패 / 무 (확정 점령    :    , 즉시 승리 / 마지막 빛)

## 1. 점수 (1 = 전혀 아니다, 5 = 매우 그렇다)

| 질문 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 규칙을 빨리 이해했다 | | | | | |
| 한 라운드 절차가 번거롭지 않았다 | | | | | |
| 상대가 내 **과거(잔상)**를 본다는 점을 이용해 속였다 | | | | | |

| 끝까지 긴장감이 있었다(지고 있어도 할 일이 있었다) | | | | | |
| 다시 하고 싶다 | | | | | |

## 2. 짧은 답

1. 가장 기억에 남는 장면은?
2. 가장 헷갈렸던 규칙이나 순간은? (예: 잔상과 실체, 관성, 파문 칸, 봉쇄, 위장, 마지막 빛)
3. 쓸모없다고 느낀 규칙이나 부품은?
4. 지루했던 구간이 있었다면 언제인가? (몇 라운드쯤)
5. 하나만 바꿀 수 있다면 무엇을 바꾸겠는가?

## 3. 진행자 기록

- 규칙 설명 시간:    분 / 플레이 시간:    분 / 종료 라운드:
- 준비(카드 분류) 시간:    분
- 공격 선언 횟수 (A /B):     /     · 봉쇄 횟수:     · 위장 사용 (A /B):     /
- 규칙 질문이 나온 곳 (절 번호와 질문 내용):
- 규칙을 잘못 적용한 곳:
- 손이 바빴던 절차 (카드 고르기, 컨베이어 밀기, 위치 증명, 공격 표식 등):
- 플레이어 표정·반응이 컸던 순간:

> 공모전 심사 기준 확인: ① 순수 창작 ② 지나치게 복잡하지 않고 재미있음 ③ 규칙 허점 없고 균형 ④ 반복 플레이 매력.
> 1번 표의 1·2행은 ②, 6행은 ③, 8행은 ④에 대응한다.
