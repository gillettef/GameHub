# 실물 플레이테스트 가이드 (룰북 v0.4)

공모전 기획안에는 **게임 진행 사진 1~2장이 필수**다. 첫 실물 테스트에서 사진을 함께 찍는다.
결과는 이 시트를 채워 들려주면 `/playtest-report`로 `playtests/`에 기록한다.

## 준비
- `components/print-and-play.html` 인쇄(A4, 실제 크기, 배경 그래픽 켜기), 불투명 주머니 1개, 60초 모래시계(또는 휴대폰 타이머)
- 진행자 1명(가능하면 플레이하지 않는 사람)이 **진실 기록지**를 쓴다. 매 계절 점유 결과를 적어 두고, 게임이 끝날 때까지 아무에게도 보여 주지 않는다. 게임 뒤 공식 역사와 대조한다.
  - 진행자가 없으면 진실 대조는 건너뛴다(기둥 1상 플레이어는 진실을 확인할 수 없다).

## 사진 (기획안용)
- [ ] ① 섬 보드 전경: 이번 계절 땅 타일 + 망각된 칸의 기록 표지가 함께 보이는 장면
- [ ] ② 증언 공개 순간: 주먹을 동시에 펼치는 손들
- [ ] (선택) 망각 주머니에 땅 타일을 쓸어 넣는 장면

### 시뮬레이션끼리 결론이 엇갈린 항목 (가장 중요)
| 항목 | 측정 방법 | 판단 기준 |
|---|---|---|
| 기억이 승패에 영향을 주는가 | 게임 전 30초 동안 4×4 색 배치를 외우는 간단한 기억 테스트 → 최종 순위와 비교 | 기억 상위권이 평균 순위 상위 절반이면 통과 |
| 회색 막기 | 주인이 있는 칸이 회색이나 공백이 된 횟수, 그때 선두의 칸이었는지 | 주인 있는 칸의 40% 이상이 지워지면 문제 |
| 이긴 쪽 편승 | 플레이어별 평판 횟수와 구역 값 점수 | 구역 값이 하위권인데 평판만으로 이기면 문제 |
| 2인 고정 연합 (특히 4인) | 한 판은 두 사람에게 몰래 "끝까지 서로 밀어 주기"를 지시 | 마지막 회의 전에 연합이 깨지거나 바깥 사람이 맞연합하면 통과 |
| 자기 칸 질문의 주인 행동 | 주인이 빈 주먹, 편승, 아무 답 중 무엇을 냈는지 | 참고용 |

## 결과가 나쁠 때 시험할 변형 (한 번에 하나만)
| 문제 | 변형 |
|---|---|
| 회색 막기가 너무 많다 | 회색 공식 역사에는 평판을 주지 않는다 (단, 주인 없는 칸 도둑질이 늘 수 있다) |
| 평판 편승으로 이긴다 | 구역 값을 2배로 (강가 8, 포구·우물터 6, 나머지 4) |
| 2인 연합이 끝까지 이긴다 | 5~6인을 권장 인원으로 하고 4인은 변형 규칙으로 (기둥 ④ 변경이므로 결정 필요) |
| 6인이 60분을 넘는다 | 6인 속삭임 시간을 45초로 |
