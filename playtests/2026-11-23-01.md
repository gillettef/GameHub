# 플레이테스트 2026-11-23-01

- **종류:** 가상 시뮬레이션 (`playtest-simulator` 에이전트)
- **룰북 버전:** v1.0
- **플레이어:** 2인(설계형 빨강, 방해형 파랑) 1판 전체 / 4인(직진형, 방해형, 초보, 편승형) 4라운드
- **소요 시간 / 라운드 수:** 2인 14라운드 28차례 (추정 30~35분)
- **승자 / 승리 방식:** 2인 10:10, 들고 있는 조각 0:0으로 공동 승리

## 진행 요약
- 2인 R5: 빨강이 왼쪽 3선 한 번으로 파랑을 가리고, A↔G 이음을 열고, 자기는 2점 득점. "한 번의 접기로 판이 뒤집힌다"가 그대로 나왔다.
- 2인 R8: 파랑의 오른쪽 3선으로 보이는 열이 5줄로 줄어 시각적 놀라움이 가장 컸다.
- 2인 R10~R14: 파랑의 오른쪽 2선 날개 아래 F·G열에 조각 8개가 묻힌 채 게임이 끝났다.
- 2인 R13: 파랑이 동점 판정용 줍기를 막으려고 빨강을 가렸다. 접기가 상대의 다음 행동을 빼앗는 수 읽기가 되었다.
- 4인 R2: 초보가 펼치기로 묻힌 조각을 되찾으면서 동시에 빨강의 이음을 끊었다.

## 재미 신호
- 접는 순간 먼 칸이 붙는 놀라움, 판이 반으로 줄어드는 장면
- 남이 만든 이음에 편승하는 플레이(4인 노랑)
- 펼치기로 상대 계획을 무너뜨리는 반격

## 문제 신호
- 접기 한 번에 말·조각을 평균 4~5개, 최대 9개 옮김. 닻 표지 2개가 매번 추가
- 자기 쪽 날개를 접어 두면 그 아래 조각이 오래 묻힘(4인에서 보이는 조각 0개인 순간)
- 득점이 강제라 동점 판정(들고 있는 조각)이 사실상 공동 승리
- 상대가 A·I열에 있으면 가릴 방법이 없음(안전지대). 가리기는 상대가 그 차례에 접기를 써야 할 때만 효과
- 초보가 "발밑 조각을 왜 못 줍나"(7.3)에서 막힘

## 룰 공백 / 혼동
| 상황 | 임시 처리 | 제안 |
|---|---|---|
| 닻 표지를 접을 때 처리 없음 | 들어서 뒷면 같은 좌표로 | 닻 칸 앞뒷면 인쇄 → **D-009/D-013 반영** |
| 가려진 칸에 떨어진 별똥별의 날개 쪽 칸 대응표 없음 | 거울 대응 계산 | 대응표 + 날개 터뜨리기 → **룰북 5.1, D-011 반영** |
| 카드 더미가 라운드 중간에 빔 | 단계 건너뜀 | 카드 다시 섞기 + 공급처 → **D-010 반영** |
| 용어집 "마지막 차례"와 9장 모순 | 룰북 따름 | 용어 삭제 → **반영** |
| 동점 처리가 사실상 공동 승리 | 공동 승리 | 동점 결승 라운드 → **D-012 반영** |
| 펼칠 때 서 있던 말의 방향 문장 누락(5.4) | 세움 | **룰북 5.5 반영** |
