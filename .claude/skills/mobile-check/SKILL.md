# /mobile-check — 모바일 검증

## 1. 자동 검사 (순서대로, 실패하면 멈추고 원인 보고)
```
npm run typecheck
npm test
npm run build
```
- 스크립트가 없으면 CLAUDE.md "명령어" 절대로 추가하자고 알리고, 임의 명령을 만들지 않는다.
- 빌드 후 `dist/` JS gzip 크기를 보고한다(목표 150KB 이하).

## 2. 화면 확인 (가능한 경우)
- `/dev` 로 띄운다.
- 브라우저 도구가 있으면 뷰포트 **360×640**, **390×844** 로 홈 → AI 대전 설정 → 게임(식민지·테크 웹·카드 줄·현황 탭) → 결과 화면을 확인한다.
- 브라우저 도구가 없으면 3번 코드 점검만 하고 "실기기 확인 필요"라고 적는다.

## 3. 체크리스트 (변경된 화면 대상)
- [ ] 가로 스크롤 없음(고정 폭, 긴 단어, `min-width`)
- [ ] 터치 타깃 ≥ 44×44px, 인접 버튼 간격 ≥ 8px
- [ ] 주요 행동이 하단 고정 바, `env(safe-area-inset-bottom)` 반영, 높이 `100dvh`
- [ ] hover 전용 정보 없음, `touch-action: manipulation`
- [ ] 테크 웹: 360px 폭에서 노드 구분 가능, 상태(연구됨/가능/불가)가 색 외에 모양·아이콘으로도 구분, 노드 탭 → 상세 시트
- [ ] 카드 줄: 위치별 비용 표시, 넘칠 때 가로 스크롤 아님
- [ ] 남은 지휘/방위 행동 수 항상 표시, 불가 행동은 이유 문구
- [ ] 색·간격 값이 `tokens.css` 변수로만
- [ ] 비공개 정보: 다른 사람의 임무·시야 밖 미래 퀘스트 노출 없음
- [ ] 새로고침 시 진행 중 게임 `localStorage` 복구
- [ ] 사용자 입력은 `textContent`

## 4. 보고
- 자동 검사 결과(통과/실패 + 실패 출력 요약)
- 위반 항목만 `파일:줄` 과 함께
- 확인 못 한 항목은 "미확인"
- 깊은 UX 검토는 `mobile-ui-reviewer` 에이전트에 맡긴다.
