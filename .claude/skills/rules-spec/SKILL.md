# 스토브리그 규칙 명세

원본: `notes/stoveleague_source.html` (계산 방식은 2026-10-15 B안으로 재설계되어 원본과 다름). 이 문서와 코드가 다르면 **이 문서가 기준**이다. 규칙을 바꿀 때는 이 문서를 먼저 수정하고, 변경 이유를 "변경 이력"에 남긴다.

## 1. 개요
- 테마: **축구** 이적시장 (포지션 FW/MF/DF/GK, 아이콘 ⚽)
- 인원: 2~4명 (사람 + AI). 5라운드.
- 목표: 계약 성사로 얻는 수수료(억 원, **정수**) 합계 최다. 동점이면 공동 우승.
- 설계 원칙 (실물 보드게임 대응): 테이블에서 하는 계산은 **한 자리 정수의 덧셈·뺄셈만**. 퍼센트·소수점·숨은 연봉 선택 없음

## 2. 게임 준비
- 각 에이전트 지급:
  - **요구 수수료 카드**: 1 / 2 / 3 / 4 각 **3장 (총 12장)** — 최대 10회 협상(5라운드 × 2)을 감당
  - 전략 카드: 4종(관계 구축, 이적설 흘리기, 신속한 결단, 실속 협상) 중 **중복 없이 무작위 3장**
  - **하이재킹 카드 1장** (전원 공통 지급, 전략 카드의 일종)
- 점수 0, 계약 건수 0, 판매된 선수 목록 비움

## 3. 라운드 진행
1. **시장 공개** (N = 참가 에이전트 수)
   - 이벤트 1개 무작위 (5종 균등, 라운드 간 중복 허용)
   - 선수 시장: 아직 계약되지 않은 선수 중 무작위 **2N + 1명** (남은 선수가 적으면 전부)
   - 구단: 12개 중 무작위 **N + 2곳** (매 라운드 새로 뽑음, 구단은 소모되지 않음)
   - 인원별: 2명 → 선수 5·구단 4 / 3명 → 7·5 / 4명 → 9·6
   - **대어**: 시장 선수 중 몸값 상위 **K = max(2, N − 1)명** (몸값이 같으면 카드 번호가 작은 쪽). 2명 → 2 / 3명 → 2 / 4명 → 3. 실물에서는 시장 카드를 몸값 순으로 깔고 앞의 K장에 대어 표시
2. **제출**: 각 에이전트는 **1차 협상과 2차 협상을 한꺼번에 비공개로** 제출한다. 각 협상은 독립적으로 **패스** 가능
   - 협상 1건 = 선수 1명(시장 내), 구단 1곳(이번 라운드 구단 중), **요구 수수료 카드 1장**, 전략 카드 0~1장
   - **1차 협상(대어 쟁탈전)은 대어만** 노릴 수 있다. 2차 협상은 시장 전체(하이재킹 포함)
   - 같은 에이전트의 1차와 2차는 **선수도 구단도 서로 달라야** 한다 (중복 시 2차가 무효, 카드 미소모)
   - 1차와 2차에 같은 카드를 낼 수는 없다 (보유 장수 안에서만)
3. **동시 공개 및 정산**: 1차를 모두 정산한 뒤 2차를 정산한다 (6장)
4. 5라운드 종료 후 최종 결과

## 4. 유효성
- **제시액** = 구단 예산 (구단 긴축 이벤트 시 −1). 연봉은 따로 정하지 않는다. 제시액은 **계약 조건에만** 쓰이고 매력도에는 들어가지 않는다 (부자 구단이 항상 유리하지 않도록)
- 계약 조건: `제시액 ≥ 선수 몸값 + 전략카드 몸값 보정` (실속 협상 −2). 미달이면 무효(**몸값 미달**)
- 보유하지 않은 카드를 낸 제출은 무효. 2차의 보유 여부는 **1차에서 낸 카드를 뺀 뒤** 판정
- **하이재킹 카드는 2차 협상에서만** 낼 수 있다 (1차에 내면 무효, 카드 미소모)
- **카드 소모: 공개된 카드는 모두 버린다** — 계약 성공·패배·몸값 미달·협상 무산 모두 소모. 패스는 소모 없음
  - 엔진 전용 예외(실물에서는 구성물·규칙으로 막히는 경우): 시장 밖 선수·구단, 1차에 대어가 아닌 선수, 미보유 카드, 1차 하이재킹, 1·2차 중복은 무효 처리하고 카드를 소모하지 않는다
  - 12장 중 최대 10장만 쓰므로 카드가 부족해지는 일은 없다

### 4-1. 협상 무산
- 2차에서 제시한 선수가 **이번 라운드 1차에서 이미 계약**되었다면, 하이재킹 카드를 쓰지 않은 2차 제안은 **협상 무산**(기회 소멸)이다. 카드는 버린다

## 5. 계산식 (모두 정수)
```
매력도 = (선수 포지션 == 구단 필요 포지션 ? 2 : 0)
       + (선수 특성 == 구단 선호 특성 ? 1 : 0)
       + 전략카드 매력도
       − 요구 수수료

수수료 = max(0,
         선수 기본 수수료
       + 요구 수수료
       + 전략카드 수수료 보정 (이적설 −1, 신속한 결단 +1)
       + 이벤트 보정 (공격수 품귀: FW +1 / 유망주 열풍: 유망주 +1))
```
- **핵심 갈등**: 요구 수수료를 높이면 수수료는 오르지만 매력도가 떨어져 경쟁에서 진다
- 수수료는 해당 제안이 **계약에 성공했을 때만** 지급

## 6. 경쟁 판정
- 1차, 2차 각각 같은 선수에 대한 유효 제안끼리 비교: 매력도 높은 쪽 → 동률이면 요구 수수료 낮은 쪽
- **동률 상쇄**: 매력도와 요구 수수료가 모두 같은 최고 제안들은 **서로 상쇄되어 모두 탈락**하고, 그다음 순위 제안이 계약한다 (다음 순위도 동률이면 같은 방식 반복, 남는 제안이 없으면 계약 없음). 무작위·좌석 우선 없음
- 서로 다른 선수 제안은 독립적으로 모두 성사 (같은 구단에 여러 계약 가능)
- 승자: 점수 += 수수료, 계약 건수 +1, 선수는 이후 시장에서 제외 (1차 계약 선수는 같은 라운드 2차에서 하이재킹으로만 노릴 수 있음)

### 6-1. 하이재킹 (2차)
- 2차에서 **1차에 계약된 선수**를 하이재킹 카드로 노린 제안끼리 먼저 위 규칙으로 경쟁해 대표 1명을 정한다
- 대표의 매력도가 **1차 계약의 매력도 이상이면** 하이재킹 성공 (같아도 성공)
  - 1차 계약은 파기: 원래 에이전트는 그 계약의 수수료·계약 건수를 받지 못한다 (카드는 이미 소모)
  - 하이재커가 그 선수와 계약: 자신의 제안 기준 수수료를 받는다
- 낮으면 실패: 1차 계약 유지, 하이재커 제안은 패배(카드 소모)
- 1차에 계약되지 않은 선수에게 하이재킹 카드를 쓰면 일반 2차 제안과 똑같이 경쟁한다 (매력도 보정만 적용)

### 6-2. 점수 반영
- 라운드의 **최종 계약**(1차 계약 중 하이재킹되지 않은 것 + 2차 계약)에 대해 수수료를 지급한다
- **빅딜 시즌**: 이번 라운드 최종 계약 중 수수료가 가장 큰 계약(동률이면 모두)에 **+2억**

## 8. AI
- 1차·2차 모두 라운드 시작 상태 기준으로 만든다. **1차 후보는 대어만**. 2차는 1차에서 고른 선수·구단을 제외하고, 1차에서 낸 카드를 뺀 상태로 같은 로직을 한 번 더 적용한다
- 하이재킹 카드는 2차에서만 고려한다
- 유효 제안을 못 만들면 제안 없음(카드 소모 없음)
- AI 자리마다 난이도 `easy`(쉬움) / `normal`(보통)을 지정한다. 지정이 없으면 `easy`

### 8-1. 쉬움
- 시장에서 무작위 선수 1명 → 이번 라운드 구단 중 제시액 ≥ 몸값인 곳을 적합도(포지션 +2, 선호 +1) 내림차순 정렬 후 상위 3곳 중 무작위
- 요구 수수료: 남은 카드 중 무작위. 전략 카드: 45% 확률로 보유 카드(1차는 하이재킹 제외) 중 무작위 사용

### 8-2. 보통
- 가능한 모든 제안(시장 선수 × 이번 라운드 구단 × 남은 요구 수수료 × 전략 카드 없음/보유 카드)을 평가해 **기대 수수료**가 높은 제안을 고른다
  - 위협치 `T(선수) = max(계약 가능한 이번 라운드 구단의 적합도) + 1 − 2 + 0.5 × (N − 2)` — 다른 에이전트가 무난하게 낼 법한 매력도 추정 (전략 +1, 요구 수수료 2 가정, 인원이 많을수록 경쟁 치열)
  - 승률 추정 `w = clamp(0.5 + 0.15 × (매력도 − T), 0.05, 1)`
  - 가치 `= 수수료 × w − (전략 카드 사용 시 0.75)` (카드 아끼기 비용. 마지막 라운드는 0)
  - 2차는 무산 위험을 반영: 하이재킹을 쓰지 않으면 가치에 `(1 − q)`를 곱한다. `q = min(0.9, 1.5 × (N − 1) / 시장 선수 수)`
  - 선수별 가치 최고 제안을 모아 상위 **N + 1명** 중 가치에 비례한 확률로 하나 선택 (여러 보통 AI가 같은 선수에 몰려 동률 상쇄되지 않도록)
  - 고른 선수에 대한 상위 3개 안(구단·요구 수수료·전략 조합) 중 다시 가치 비례로 선택 (같은 AI끼리 똑같은 제안을 내 동률 상쇄되는 일을 줄임)

## 9. 프로토타입에서 확인된 불일치 (결정 필요 시 사용자에게 확인)
- 프로토타입 AI는 같은 라운드의 정산 전 상태로 판단 → 로컬 엔진에서도 동일하게 "라운드 시작 상태" 기준으로 AI 제안 생성

## 변경 이력

- 2026-10-15: AI 난이도 쉬움/보통 추가 (8-1). 쉬움 = 기존 프로토타입 로직
- 2026-10-15: **라운드당 협상 2회(1차·2차, 동시 비공개 제출)** 도입. 1차·2차 선수·구단 중복 금지, 1차 계약 선수에 대한 2차 제안은 무산(카드 반환). **하이재킹 카드** 추가(전원 1장, 2차 전용, 1차 계약 매력도 초과 시 계약 탈취). 협상 횟수 증가에 맞춰 시장 크기를 선수 2N+1·구단 N+2로, 선수 풀을 20→36명, 구단을 8→12개, 수수료율 카드를 종류별 2→3장으로 늘림
  - 근거 시뮬레이션 (`scripts/simulate.ts --games 1000 --ai mixed`, seed 42): 라운드당 계약 2인 3.1 / 3인 4.4 / 4인 5.3건, 시장 부족 라운드 0% (4인 기준 선수 풀 36명 충분), 2차 무산 8~13%, 1차 계약 대상 하이재킹 성공률 52% / 49% / 39%, 좌석별 승률 편차 ±1.3%p 이내
- 2026-10-15: **실물 보드게임 대응 계산 재설계 (B안)**. 공모전(코리아보드게임즈 2027) 대비
  - 연봉 선택 삭제 → 구단 예산을 "제시액"으로 그대로 사용 (보통 AI 측정 시 연봉을 상한으로 낸 비율 100% — 가짜 결정이었음)
  - 수수료율(5/10/15/20%) 카드 → **요구 수수료 카드 1~4 (정수)**. 매력도에서 빼고 수수료에 더해 "욕심 vs 승률" 갈등 생성 (기존: 5% 카드 사장, 숙련자 경쟁 동점 83%)
  - 선수 계약 보너스(0.3/0.5/1) 삭제 → 몸값 비례 **기본 수수료(정수)**. 저가 유망주 지배 전략 해소 목적
  - 동점 최종 판정을 무작위 → **동률 상쇄**(같은 최고 제안끼리 모두 탈락, 다음 순위 계약). 실물에서 도구 불필요, 좌석 편향 없음. (처음 시도한 "선 플레이어 우선"은 숙련자 간 동률 80%에서 좌석 편향이 커서 폐기: 2인 62/38, 4인 37~15%)
  - 매력도에서 제시액 제외 → 구단 선택이 "가장 부자 구단" 고정이던 문제 해소 (4인 보통 AI 기준 구단 선택 편차 썬더 울브스 16회 vs 화이트 샤크스 4,995회 → 1,403 vs 2,215)
  - 하이재킹은 1차 계약과 **같아도 성공**: 엄격 초과일 때 숙련자 간 성공률 0% (대부분 정확히 동률)
  - 카드 소모를 "공개된 카드는 모두 버린다"로 단일화 (협상 무산도 소모)
  - 실속 협상: 연봉 −1 → 몸값 조건 −2. 하이재킹 매력도 +1 → +2. 이벤트·빅딜 보정을 정수로
  - 기본 수수료 몸값 2 선수 1 → 2 (숙련자 입찰이 선수당 79회로 사장 → 284회)
  - 보통 AI: 위협치에 인원 보정, 후보 상위 3 → N+1명 (4인 혼합전에서 보통이 쉬움에 지던 문제: 22% vs 28% → 29% vs 21%)
  - 근거 시뮬레이션 (`scripts/simulate.ts --games 1000`, seed 42). 숙련자(보통 AI끼리) 3인 기준 이전 → 이후:
    | 지표 | 이전 | B안 |
    |---|---|---|
    | 연봉 상한 제출 비율 (가짜 결정) | 100% | 연봉 삭제 |
    | 경쟁 시 최고 매력도 동률 | 82.7% (무작위로 결정) | 42.3% (상쇄 → 다음 순위) |
    | 가장 적게 쓰인 수수료 카드 | 5%: 612회 (사장) | 요구 4: 3,337회 |
    | 1차 계약 대상 하이재킹 성공률 | 12.8% | 49.5% |
    | 구단 선택 최다/최소 (4인) | 6.4배 | 1.7배 |
    | 좌석별 승률 | — | 33.0 / 34.4 / 32.7% |
    | 수수료 값 종류 / 소수점 | 53종, 17%가 소수 둘째 자리 | 정수만 |
  - 남은 과제: 숙련자 3인 경쟁률 24.4%(이전 33.3%)로 상호작용은 늘지 않음. 전략 카드 1회당 수익 2.9~4.4억으로 실속 협상이 가장 강하고 하이재킹이 가장 약함
- 2026-10-15: **상호작용 개선 — 1차는 대어 쟁탈전**. 1차 협상은 시장 몸값 상위 K = max(2, N − 1)명(대어)만 노릴 수 있다. 2차는 그대로 시장 전체
  - 문제: 시장(2N+1명)이 협상 수보다 넉넉해 서로 피해 갈 수 있었음. 숙련자 3인 기준 경쟁자와 맞붙는 제안 비율 40%
  - 시도했으나 채택하지 않은 안 (각 500~800판 시뮬레이션):
    - 시장 축소(선수 2N / N+2 / N+1): 경쟁 제안 비율 41 / 43 / 46%로 소폭 상승, 무산 증가 (3인 숙련자)
    - 경쟁 프리미엄(이긴 쪽이 경쟁 제안 1건당 +1억): 변화 없음 (58.1% vs 프리미엄 없음 57.9%) → 규칙만 늘어 폐기
    - 스타 기본 수수료 강화(max(2, 몸값 − 2)): 경쟁 효과 동일, 점수 분산·하이재킹 실패만 증가 → 폐기
  - 결과 (`scripts/simulate.ts --games 1000`, seed 42, "경쟁 제안 비율" = 같은 차수·같은 선수에 다른 유효 제안이 있었던 제안의 비율):
    | 구성 | 이전 | 대어 쟁탈전 |
    |---|---|---|
    | 숙련자 2인 | 31.0% | 40.1% |
    | 숙련자 3인 | 41.1% | **57.7%** |
    | 숙련자 4인 | 46.5% | **58.0%** |
    | 혼합 2 / 3 / 4인 | 21.1 / 27.9 / 33.0% | 38.2 / 53.6 / 52.8% |
    - 부수 효과: 2차 무산 10.7 → 6.4% (3인 숙련자), 좌석 편향 없음(3,000판 기준 ±1.7%p 이내), 보통 AI 우위 유지(혼합 3인 61% vs 19%). 하이재킹 성공률 51 → 41% (1차 계약이 치열한 경쟁의 승자라 더 강함)
  - 대어 수 K = N − 1은 2인에서 대어 1명 → 1차가 강제 1:1 대결이고, 1차 패자가 같은 선수를 2차에 못 내므로(중복 금지) 하이재킹이 불가능해 최소 2명으로 함
