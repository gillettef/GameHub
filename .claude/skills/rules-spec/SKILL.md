# 스토브리그 규칙 명세

원본: `notes/stoveleague_source.html`. 이 문서와 코드가 다르면 **이 문서가 기준**이다. 규칙을 바꿀 때는 이 문서를 먼저 수정하고, 변경 이유를 "변경 이력"에 남긴다.

## 1. 개요
- 테마: **축구** 이적시장 (포지션 FW/MF/DF/GK, 아이콘 ⚽)
- 인원: 2~4명 (사람 + AI). 5라운드.
- 목표: 계약 성사로 얻는 수수료(억 원) 합계 최다. 동점이면 공동 우승.

## 2. 게임 준비
- 각 에이전트 지급:
  - 수수료율 카드: 5% / 10% / 15% / 20% 각 **3장 (총 12장)** — 최대 10회 협상(5라운드 × 2)을 감당
  - 전략 카드: 4종(관계 구축, 이적설 흘리기, 신속한 결단, 실속 협상) 중 **중복 없이 무작위 3장**
  - **하이재킹 카드 1장** (전원 공통 지급, 전략 카드의 일종)
- 점수 0, 계약 건수 0, 판매된 선수 목록 비움

## 3. 라운드 진행
1. **시장 공개** (N = 참가 에이전트 수)
   - 이벤트 1개 무작위 (5종 균등, 라운드 간 중복 허용)
   - 선수 시장: 아직 계약되지 않은 선수 중 무작위 **2N + 1명** (남은 선수가 적으면 전부)
   - 구단: 12개 중 무작위 **N + 2곳** (매 라운드 새로 뽑음, 구단은 소모되지 않음)
   - 인원별: 2명 → 선수 5·구단 4 / 3명 → 7·5 / 4명 → 9·6
2. **제출**: 각 에이전트는 **1차 협상과 2차 협상을 한꺼번에 비공개로** 제출한다. 각 협상은 독립적으로 **패스** 가능
   - 협상 1건 = 선수 1명(시장 내), 구단 1곳(이번 라운드 구단 중), 연봉(정수, 억), 수수료율 카드 1장, 전략 카드 0~1장
   - 같은 에이전트의 1차와 2차는 **선수도 구단도 서로 달라야** 한다 (중복 시 2차가 무효, 카드 미소모)
   - 1차와 2차에 같은 카드를 낼 수는 없다 (보유 장수 안에서만. 예: 10% 카드가 1장 남았으면 둘 중 하나만)
3. **동시 공개 및 정산**: 1차를 모두 정산한 뒤 2차를 정산한다 (4장, 6장)
4. 5라운드 종료 후 최종 결과

## 4. 유효성
- 유효 연봉 `s = 제시 연봉 + 전략카드 연봉 보정` (실속 협상 -1)
- `s ≥ 선수 최소 연봉` 이고 `s ≤ 구단 유효 예산` (구단 긴축 이벤트 시 예산 -1)
- UI의 제시 연봉 선택 범위: 최소 연봉 ~ 10억
- 보유하지 않은 수수료율/전략 카드를 낸 제출은 무효. 2차의 보유 여부는 **1차에서 낸 카드를 뺀 뒤** 판정
- **하이재킹 카드는 2차 협상에서만** 낼 수 있다 (1차에 내면 무효, 카드 미소모)
- **카드 소모**: 수수료율 카드와 전략 카드는 제출하면 계약 성사 여부와 관계없이 소모(조건 불충족으로 무효여도 소모). 패스는 소모 없음.
  - 예외: **협상 무산**(4-1)된 2차 제안과 1차·2차 중복으로 무효인 2차 제안은 카드를 소모하지 않는다
  - 주의: 12장 중 최대 10장만 쓰므로 카드가 부족해지는 일은 없다

### 4-1. 협상 무산
- 2차에서 제시한 선수가 **이번 라운드 1차에서 이미 계약**되었다면, 하이재킹 카드를 쓰지 않은 2차 제안은 **협상 무산**(기회 소멸)이다. 카드는 돌려받는다

## 5. 계산식
```
매력도 = s
       + (선수 포지션 == 구단 필요 포지션 ? 2 : 0)
       + (선수 특성 == 구단 선호 특성 ? 1 : 0)
       + 전략카드 매력도
       + (이벤트 "공격수 품귀" && 포지션 FW ? 1 : 0)

수수료 = max(0,
         s × 수수료율/100
       + 선수 계약 보너스
       + 전략카드 수수료 보정 (이적설 -0.2)
       + 전략카드 성공 보너스 (신속한 결단 +0.3)
       + (이벤트 "유망주 열풍" && 특성 유망주 ? 0.3 : 0))
```
- 수수료는 해당 제안이 **계약에 성공했을 때만** 지급

## 6. 경쟁 판정
- 1차, 2차 각각 같은 선수에 대한 유효 제안끼리 비교: 매력도 높은 쪽 → 동률이면 수수료율 낮은 쪽 → 그래도 같으면 무작위(rng)
- 서로 다른 선수 제안은 독립적으로 모두 성사 (같은 구단에 여러 계약 가능)
- 승자: 점수 += 수수료, 계약 건수 +1, 선수는 이후 시장에서 제외 (1차 계약 선수는 같은 라운드 2차에서 하이재킹으로만 노릴 수 있음)

### 6-1. 하이재킹 (2차)
- 2차에서 **1차에 계약된 선수**를 하이재킹 카드로 노린 제안끼리 먼저 위 규칙으로 경쟁해 대표 1명을 정한다
- 대표의 매력도가 **1차 계약의 매력도보다 엄격히 높으면** 하이재킹 성공
  - 1차 계약은 파기: 원래 에이전트는 그 계약의 수수료·계약 건수를 받지 못한다 (카드는 이미 소모)
  - 하이재커가 그 선수와 계약: 자신의 제안 기준 수수료를 받는다
- 같거나 낮으면 실패: 1차 계약 유지, 하이재커 제안은 패배(카드 소모)
- 1차에 계약되지 않은 선수에게 하이재킹 카드를 쓰면 일반 2차 제안과 똑같이 경쟁한다 (매력도 +1만 적용)
- 하이재킹 수치: 매력도 +1, 수수료 보정 0

### 6-2. 점수 반영
- 라운드의 **최종 계약**(1차 계약 중 하이재킹되지 않은 것 + 2차 계약)에 대해 수수료를 지급한다
- **빅딜 시즌**: 이번 라운드 최종 계약 중 유효 연봉 s가 가장 높은 계약(동률이면 모두)에 +0.5억

## 8. AI (프로토타입 기준, 개선 가능)
- 1차·2차 모두 라운드 시작 상태 기준으로 만든다. 2차는 1차에서 고른 선수·구단을 제외하고, 1차에서 낸 카드를 뺀 상태로 같은 로직을 한 번 더 적용한다
- 하이재킹 카드는 2차에서만 고려한다
- 시장에서 무작위 선수 1명 → 이번 라운드 구단 중 유효 예산 ≥ 최소 연봉인 곳을 적합도(포지션 +2, 선호 +1) 내림차순 정렬 후 상위 3곳 중 무작위
- 연봉: `min(유효 예산, 최소 연봉 + rand(0..2))`
- 수수료율: 남은 카드 중 무작위. 전략 카드: 45% 확률로 보유 카드(1차는 하이재킹 제외) 중 무작위 사용
- 유효 제안을 못 만들면 제안 없음(카드 소모 없음)
- AI 개선 시 난이도(쉬움/보통) 옵션으로 분리하고, 기존 로직은 "쉬움"으로 보존

### 8-1. 난이도
- AI 자리마다 난이도 `easy`(쉬움, 위 프로토타입 로직) / `normal`(보통)을 지정한다. 지정이 없으면 `easy` (구버전 저장 데이터 호환)
- **보통 AI**: 라운드 시작 상태 기준으로 가능한 모든 제안(시장 선수 × 이번 라운드 구단 × 연봉 최소~유효 예산 × 남은 수수료율 × 전략 카드 없음/보유 카드)을 평가해 **기대 수수료**가 높은 제안을 고른다
  - 위협치 `T(선수) = 최소 연봉 + 1 + max(이번 라운드 구단 적합도(포지션 +2, 선호 +1))` — 다른 에이전트가 무난하게 낼 법한 매력도 추정
  - 승률 추정 `w = clamp(0.5 + 0.15 × (매력도 − T), 0.05, 1)`
  - 가치 `= 수수료 × w − (전략 카드 사용 시 0.25)` (카드 아끼기 비용. 마지막 라운드는 0)
  - 2차는 무산 위험을 반영: 하이재킹을 쓰지 않으면 가치에 `(1 − q)`를 곱한다. `q = min(0.9, 1.5 × (N − 1) / 시장 선수 수)` (다른 에이전트가 1차에 그 선수를 가져갈 확률 추정)
  - 선수별 가치 최고 제안을 모아 상위 3명 중 가치에 비례한 확률로 하나 선택 (여러 보통 AI가 같은 선수에 몰리지 않도록)
  - 유효 제안이 없으면 제안 없음

## 9. 프로토타입에서 확인된 불일치 (결정 필요 시 사용자에게 확인)
- 프로토타입 AI는 같은 라운드의 정산 전 상태로 판단 → 로컬 엔진에서도 동일하게 "라운드 시작 상태" 기준으로 AI 제안 생성
