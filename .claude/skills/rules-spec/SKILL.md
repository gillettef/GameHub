# 더블 에이전트 규칙 명세 (v3 — 비밀 구단, 3~4인)

이 문서와 코드가 다르면 **이 문서가 기준**이다. 규칙을 바꿀 때는 이 문서를 먼저 수정하고, 변경 이유를 "변경 이력"에 남긴다.
수치는 `src/core/data.ts`의 `RULES`가 공식 기본값이다 (시뮬레이션에서만 `--rules k=v`로 바꾼다).
v1(1·2차 협상·하이재킹·전략 카드·의뢰 선수) 전문은 커밋 `721f6b2`, v2(카드 순환·누가 계약했든 보너스 2억) 전문은 커밋 `5f37aba`의 이 파일에 있다.

## 1. 개요
- 한 줄: **모두가 선수 에이전트이면서, 몰래 한 구단의 이중 첩자다.** 계약 수수료를 벌면서 비밀 구단에 직접 선수를 몰아 주되, 공개 기록 때문에 들키지 않게 해야 한다
- 테마: **축구** 이적시장 (포지션 FW/MF/DF/GK, 아이콘 ⚽)
- 인원 **3~4명** (사람 + AI). 2인은 지원하지 않는다 (2026-10-16 사용자 결정). **8라운드**, 약 20~30분
- 목표: 최종 점수(억 원, **정수**) 최다. 동점이면 공동 우승
- 설계 원칙: 테이블 계산은 **한 자리 정수의 덧셈·뺄셈만**. 예외 규칙은 동률 상쇄 하나

## 2. 구성물 (실물)
- 선수 카드 36, 구단 카드 12, **비밀 구단 카드** 12(구단과 1:1)
- 이벤트 카드 8 + 데드라인 데이 1
- 에이전트별(4색): 요구 수수료 카드 4장(**+1억/매력도 −1, +2/−2, +3/−3, +4/−4**), 색 큐브 16개, 비공개 제출용 **선수 지목 카드**(시장 칸 1~8)·**구단 지목 카드**(A~F)
- 지목 기록지

## 3. 게임 준비
- 구단 12곳 중 **6곳**을 무작위로 펼친다 (게임 내내 고정)
- 펼친 6곳에 해당하는 비밀 구단 카드를 섞어 **각자 1장씩 비공개**로 받는다
- 이벤트 8장을 섞어 7장을 뽑고, 그 아래에 **데드라인 데이**를 놓는다 (8장 = 8라운드)
- 시장에 선수를 N + 1명 깐다

## 4. 라운드 진행
1. **이벤트**: 맨 위 이벤트를 적용하고, 그다음 카드를 **예고**로 공개한다
2. **시장 채우기**: 시장 선수가 **N + 1명**이 되도록 덱에서 채운다 (계약되지 않은 선수는 남는다). 해외파 귀국이면 2명 더
3. **비공개 제출**: 각자 **선수 1명, 구단 1곳, 요구 수수료 카드 1장**을 몰래 정해 동시에 공개한다. **패스**해도 된다
4. **정산** (5장): 계약한 선수 카드는 그 **구단 카드 아래**에 계약한 에이전트의 큐브와 함께 놓는다
5. **공개 기록**: 패스가 아닌 모든 제안에 대해, 고른 구단 위에 자기 색 큐브 1개를 올린다 (계약 실패·몸값 미달도 포함)
6. 요구 수수료 카드는 다시 손으로 가져온다 (매 라운드 4장 중 자유)

## 5. 계약과 경쟁
- 계약 조건: `구단 제시액 ≥ 선수 몸값` (구단 긴축은 제시액 −2). 미달이면 실패
```
매력도 = (선수 포지션 == 구단 필요 포지션 ? 2 : 0)
       + (선수 특성 == 구단 선호 특성 ? 1 : 0)
       − 카드의 매력도 감점 (RULES.penalty = [1, 2, 3, 4])

수수료 = 선수 기본 수수료 + 요구 수수료 + 이벤트 보너스(해당 시 +2, 데드라인 데이 +4)
```
- 같은 선수에 대한 제안끼리 비교: **매력도가 가장 높은 제안이 계약**
- **동률 상쇄**(유일한 예외 규칙): 최고 매력도가 같은 제안들은 서로 상쇄되어 모두 탈락하고, 그다음 매력도의 제안이 계약한다. 무작위·좌석 우선 없음
- 서로 다른 선수 제안은 모두 독립적으로 성사 (같은 구단에 여러 계약 가능)

## 6. 게임 종료 — 비밀 구단 지목
8라운드가 끝나면 모두 동시에 다른 에이전트의 비밀 구단을 지목한다 (**지목은 선택**, 상대마다 구단 하나 또는 지목 안 함).
- 맞히면 **+3억**, 틀리면 **−2억** (RULES.guessBonus / wrongGuess)
- **한 명에게라도 들킨** 에이전트는 비밀 구단 보너스를 받지 못한다
- 들키지 않은 에이전트는 **자기가 직접** 비밀 구단에 계약시킨 선수 **1명당 +10억** (RULES.clubBonus). 스폰서 데이에 계약한 선수는 2명으로 센다
- 최종 점수 = 계약 수수료 + 비밀 구단 보너스 + 지목 점수

전략 구조: 비밀 구단으로 계약하면 큰 보너스지만 적합도가 낮으면 계약 경쟁에서 지고, 큐브가 쌓이면 들킨다. 미끼 구단에 큐브를 쌓아 위장할 수 있고, 지목은 틀리면 감점이라 확신이 있을 때만 한다.

## 8. AI
- AI 자리마다 `easy`(쉬움 = 무작위 페르소나) / `normal`(보통). 지정이 없으면 `easy`
- 보통 AI는 게임 생성 때 자리 순서대로 균형형 → 위장형 → 신중형을 돌려 받는다 (`NORMAL_FIELD`). 같은 AI 복제끼리는 같은 수로 몰려 '항상 최저 카드'에 공략당하므로 (복제 상대 40~48%) 한 판의 보통 AI들을 서로 다른 성향으로 둔다
- 시뮬레이션용 페르소나(`PERSONAS`, src/core/ai.ts): 무작위 · 균형형 · 욕심형 · 신중형 · 노골형 · 위장형 · 무시형 · 추리형 · 방해형 · 항상 패스 · 항상 최저 카드 · 항상 최고 카드
- 가치형 AI: 모든 (선수, 구단, 카드) 조합의 가치 = `수수료 × 승률^risk + greed × 요구 × 승률 + 비밀 구단 가치`
  - 승률: 상대마다 노릴 선수와 매력도 분포를 예측해 '모든 상대가 안 노리거나 더 낮은 매력도'일 확률로 구한다
    - 균형형(depth 4, 믿음 기반 정책 모방): 상대의 비밀 구단을 공개 기록 의심 확률(내 비밀 구단 제외)로 가중하고, 구단마다 '그 구단이 비밀이라면 상대가 실제로 고를 수'(1단계 균형형의 후보 상위 5개, 가치^1.5 비례)를 흉내 낸다. 1단계 상대들 사이에서 예측이 실제 계약률과 맞음 (예측 96% → 실제 96%)
    - 나머지 가치형 페르소나(depth 1): '수수료 × 단순 승률'의 softmax (`AI_MODEL.beta1`)
    - depth 3(상대 비밀 구단을 직접 읽음)은 진단용으로만 둔다
  - 비밀 구단: 위장(공개 기록에서 비밀 구단이 1위가 되지 않을 때만 push × 보너스 × 승률)
  - 선택: 선수별 최선안 상위 5개 중 가치^1.5 비례 무작위
  - 지목: 공개 기록 1위/2위 반반, 기대값(맞을 확률 × 3 > 틀릴 확률 × 2)이 양수일 때만
- 균형형 조정값(greed 0, risk 1)은 `scripts/equilibrium.ts`로 찾은 대칭 균형점: 최저 카드·최고 카드·더 욕심·더 신중 변형이 공정값을 넘지 못함 (4인 최대 25.1%)
