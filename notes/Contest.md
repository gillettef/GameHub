# 2027 코리아보드게임즈 공모전 검토 — Rootbound

> 2026-10-14 작성. 세 프로젝트(MagicAcademy·Rootbound·SmilePark)를 공모전 기준으로 비교한 결과 중 Rootbound 부분이다.
> **결론: 주력 응모작으로 추천(가중 점수 3.8 / 5, 셋 중 1위).** 단 온라인 자동 계산에 기대는 규칙을 오프라인용으로 고쳐야 한다.
> 이 문서는 **규칙이 아니다.** 규칙 정본은 `Rules.md`. 아래 작업으로 규칙이 바뀌면 Rules.md를 먼저 고친다.

## 1. 공모전 요약

- 공고: https://www.koreaboardgames.com/magazine/menuDetail?boardCd=news&postNo=948
- **1차 접수: 2026-10-09 ~ 12-31 24시** (이메일 또는 당일 소인 우편). 1차 결과 2027-03-08, 2차 심사(실물 프로토타입 지참) 후 최종 발표 2027년 5월.
- **1차 제출물**: 신청서(자필 서명) + **기획안(첨부 양식, A4 2쪽 이내, 2쪽에 게임 진행 사진 1~2장)** + **규칙서(분량 자유, pdf/doc/ppt/hwp)**. 1차는 기획안·규칙서만으로 심사한다.
- **선정 기준**: 순수 창작 / **지나치게 복잡하지 않고 재미있는 게임** / 규칙 허점 없고 균형 / 반복해서 할 만큼 매력적.
- 규칙서를 읽고 이해할 수 없으면 심사 불가 → **게임을 모르는 사람에게 읽혀 확인하라**고 권장.
- 시상: 우수작 상금 100만 원 + 계약금 200만 원(독점 제품화 계약 필수), 가작 30만 원. 응모 편수 제한 없음.

## 3. 오프라인 전환 위험 (최우선으로 해결)

1. **"점수가 가장 낮은 사람이 다음 선"(5절)**: 라운드마다 모든 칸의 땅을 다시 세야 한다(4인 105칸). 오프라인에서는 사실상 불가능.
   - 후보: 선을 시계방향으로 돌리기(시뮬레이터 `MARKET_MODE=R`가 예전 선 돌리기) 또는 "땅이 아니라 손쉽게 보이는 값(심은 장수 등)으로 정하기".
   - 바꾸면 덤을 다시 잰다(`garden-sim.ts`, 브랜치 `wip/garden-sim-new-flow` 마무리 필요).
2. **영향력 합산**: 칸마다 여러 식물의 뿌리 영향 + 입구 + 씨앗 − 버섯을 사람마다 더해야 한다. 플레이 중에는 "내 영향력 1 이상인 빈 칸"만 알면 되지만 **종료 점수 세기**가 무겁다.
   - 후보: 심을 때 영향 칸에 자기 색 큐브를 쌓는 방식(식물은 사라지지 않으므로 누적 가능). 버섯(−2)·담쟁이(+1)·민들레 씨앗 처리 방식을 큐브로 표현할 수 있는지 확인.
   - 대안: 영향 범위가 겹칠 때만 세면 되도록 뿌리 모양 단순화.
3. **보드 조립**: 시드 회전·대칭 배치를 사람이 하는 절차로 바꿔야 한다(조각 섞어 놓기 + 회전 규칙을 한 문장으로).
4. **덤(komi)**: 바둑 용어라 일반 플레이어에게 낯설다. "순서 보너스" 점수 토큰으로 처음에 나눠 주는 식으로 표현.
5. **카드 더미 128비트 시드·제한 시간·AI 대리** 등 온라인 전용 규칙은 규칙서에서 뺀다.
