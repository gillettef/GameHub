## WebSocket 기반 실시간 상태 동기화 (난이도: 높음)

**구현 접근**: 서버에 Socket.io를 두고 클라이언트와 양방향 연결을 유지한다. 클라이언트는 `PLACE`·`PASS`·`SURRENDER` 액션만 보내고, 서버는 룰 엔진(`shared/src/engine`)으로 검증·적용한 뒤 갱신된 전체 `GameState`를 방의 모든 소켓에 브로드캐스트한다. 손패는 플레이어별로 가려서 보낸다(본인 손패만 내용 포함, 타인은 장수만).

**추천 스택/패턴**: Node.js, Socket.io, 서버 메모리 `Map<roomId, GameState>`, 턴 종료 시 JSON 파일 스냅샷

**근거**: 한 턴에 한 액션뿐이므로 트래픽은 작고, 전체 상태 브로드캐스트가 가장 단순하고 안전하다. 클라이언트는 규칙을 계산하지 않는다.

**예상 리스크**: 재연결 시 상태 불일치. 재접속 시 서버가 최신 상태를 통째로 다시 보내는 것으로 해결한다.

## 100ms 이내 탭 전환 반응 속도 구현 (난이도: 보통)

**구현 접근**: Zustand 전역 상태에 모든 탭 데이터를 선로드하고, 탭 컴포넌트는 언마운트하지 않고 `display:none`/`visibility` 로 숨긴다. `React.memo` 와 선택자 구독으로 리렌더를 막는다. 보드 셀은 셀 단위로 memo하고, 시야·영토 오버레이는 서버가 준 파생값(또는 클라이언트에서 한 번 계산한 값)을 셀별 색으로만 그린다.

**추천 스택/패턴**: React, Zustand, CSS Modules

**근거**: 15×15 = 225 셀과 손패를 함께 그려야 하므로 DOM 재생성보다 유지가 유리하다.

**예상 리스크**: 숨겨진 탭의 DOM이 누적되어 메모리 증가. 셀 수가 고정(최대 225)이라 감당 가능하다.

## 시야·배치·전투·점수 판정 (난이도: 높음)

**구현 접근**: `shared/src/engine` 에 순수 함수로 나눈다.
- `sight.ts`: 플레이어별 시야 영역(체비쇼프 반경 합집합), 칸별 영토 소유자.
- `placement.ts`: 배치 합법성 검사(손패·비용·빈 칸·지형·시야·침투) 와 적용.
- `combat.ts`: 턴 시작 자동 공격. 대상 선택은 거리→체력→y→x 순, 피해는 스냅샷 기준 동시 적용, 파괴·탈락 정리.
- `scoring.ts`: 영토 + 마커 점수, 순위(동점 시 좌석 번호 큰 쪽, 탈락자 하위).
- `turn.ts`: 시작 단계(전투→정비→만료→수입→드로우) → 행동 → 종료 단계(정산·종료 조건·다음 생존자).
서버는 `applyAction(state, action)` 하나만 호출한다. AI 서비스의 `rules.py` 는 같은 함수를 Python으로 옮긴 사본이며 `shared/fixtures/*.json` 으로 일치를 검증한다.

**추천 스택/패턴**: TypeScript 순수 함수, Vitest, 시드 RNG

**근거**: 규칙이 전부 결정적이어야 AI 탐색과 재접속 복구가 맞아떨어진다. 시야 하나가 배치 범위와 영토를 동시에 정하므로 `sight.ts` 를 배치·점수 양쪽에서 재사용한다.

**예상 리스크**: 3~4인전에서 한 전투에 코어가 여럿 깨지는 등 순서 의존 케이스. Rules.md 13절의 정렬 규칙을 테스트로 고정한다.

## 다인전 AI 탐색 (난이도: 보통)

**구현 접근**: 2인전은 알파베타 Minimax + 반복 심화. 3~4인전은 max-n(각 노드에서 그 턴 플레이어가 자기 평가값을 최대화). 평가 함수는 `evaluate.py` 한 곳에 두고 점수(영토+마커)·에너지·수입·코어 위협도·사거리 안 적 수를 가중합한다. 분기 수를 줄이기 위해 배치 후보 칸은 시야 영역 안으로 한정하고, 같은 카드 종류는 가장 가치 높은 몇 칸만 확장한다.

**추천 스택/패턴**: Python 3.11, FastAPI, 시간 제한 2초

**근거**: 보드가 전부 공개이고 한 턴에 한 액션뿐이라 고전 탐색이 잘 맞는다.

**예상 리스크**: 15×15 4인전에서 분기 폭발. 깊이보다 시간 제한을 우선하고 마지막 완료 깊이의 수를 돌려준다.
