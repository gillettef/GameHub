## 도구 메모

- 리그: `npm run league -- [판 수] [인원] [style|smart|all]`(SEED로 운 맞추기), 격자 탐색 `npx tsx scripts/_tune-league.ts [판 수]`. 병렬로 프로세스를 너무 많이 띄우면 Windows에서 exit 255로 죽는다(4~5개까지).
- 지표: `npm run simulate:fun -- [판 수] [인원]`(`MIRROR=1`이면 모두 균형형, `BAL='{...}'`로 설정 덮어쓰기), `npm run simulate -- [판 수] [인원]`(전략별).
- 진단: `npx tsx scripts/_diag-balance.ts`(성향별 학점 출처), `npx tsx scripts/_diag-duel.ts`(겨루기, `TARGET`·`SMART`), `npx tsx scripts/_diag-skill.ts [판 수] [인원]`(실력 기울기: 균형형 vs 무작위).
- 300판은 성향 승률이 ±5%p 흔들린다. 결론은 1500판 이상으로 낸다.
- 스모크 테스트는 `BOT_SPEED=20 PORT=8099` 서버를 띄운 뒤 실행. `smoke.ts`·`smoke-bot.ts`는 `[인원] [포트]`, rejoin·leave·social·kick은 `[포트]`만 받는다. `smoke:kick`은 5분 가까이 걸린다.
