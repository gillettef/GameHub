### 1. 복잡도 줄이기 — 사용자 결정 대기 (`기획_정리.md` 60절)

- [ ] **A 묶음 채택 여부** 결정: 심화 수업 없음 · 시험 카드 처음부터 공개 · 벼락치기 없음 · 특별상 없음 · 겨루기 "같으면 도전자 승"(도전자 +1·무승부 폐지) · 귀한 생물 학점 없음 · 연구 카드 비용 없음.
  - 효과: 개념 25 → 21개. 균형 지표는 오차 안. 결정 수는 거의 그대로(44.6 → 42.5), 즉 플레이 시간은 거의 줄지 않는다.
  - 채택하면 함께 할 일: 장래희망 달성률(48%) 보정, 기본값 전환, `rules-check` 갱신(예전 검증 고정 + 새 검증), 화면·규칙 탭 문구, 졸업 목표 탭에서 특별상 표시 정리, `CLAUDE.md` 요약.
- [ ] **구조 결정**(15개까지 6개 더 줄이기) 중 무엇을 실험할지 결정. 추천은 a·b 먼저.
  - a. **대회 + 겨루기를 한 구역으로** (미실험). "4구역 = 4능력치 = 4기운 = 4부문"이 완전히 맞는다. "자율활동 5종 유지" 결정을 바꾸는 안.
  - b. **중간고사 폐지**(기말고사만, 미실험). 시험 규칙이 줄고 시험 달이 하나 빠져 시간도 준다.
  - c. 행사 카드 폐지: 2인 역전 하락, 리플레이성 감소.
  - d. 학기 덱 하나: 2학기 주문력 흐름이 약해진다(컨셉 충돌).
  - e. 공짜 주사위 1개를 굴림 상한 설명에 합치기(규칙은 그대로, 설명만).
  - f. 12개월 축소: 플레이 시간을 줄이는 유일한 큰 수단. 12개월 유지는 사용자 결정 사항.

## 도구 메모

- 지표: `npm run simulate:fun -- [판 수] [인원]`(`MIRROR=1`이면 모두 균형형, `BAL='{...}'`로 설정 덮어쓰기), `npm run simulate -- [판 수] [인원]`(전략별).
- 진단: `npx tsx scripts/_diag-balance.ts`(성향별 학점 출처), `npx tsx scripts/_diag-duel.ts`(겨루기, `TARGET`·`SMART`), `npx tsx scripts/_diag-skill.ts [판 수] [인원]`(실력 기울기: 균형형 vs 무작위).
- 300판은 성향 승률이 ±5%p 흔들린다. 결론은 1500판 이상으로 낸다.
- 스모크 테스트는 `BOT_SPEED=20 PORT=8099` 서버를 띄운 뒤 실행. `smoke:kick`은 5분 가까이 걸린다.
