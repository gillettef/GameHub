# AstralTab 카드 목록

종족 5개의 카드 전체(기본 22종 + 특수 9종)와 공용 코어를 정리한 문서다. 정본은 `notes/Rules.md`, 수치는 `shared/src/data/cards.ts` 이며 이 문서는 파생 요약이다.

- 표기: 비용 = 에너지 비용, 장수 = 기본 덱 안의 복사 수. 특수 카드는 종족 덱에 최대 2장까지 넣을 수 있지만 고정 덱에는 **★ 표시된 3장(건물·유닛·마법 각 1장)** 만 1장씩 들어간다.
- 고정 덱 = 기본 22장 + ★ 특수 3장 = 25장.

## 키워드

| 키워드 | 설명 |
|---|---|
| 침투 | 적 마커 거리 1 이내에도 배치할 수 있다 |
| 정비 | 내 턴을 끝낼 때(전투 직후) 반경 1 아군 체력 +1 |
| 은신 | 다른 적 표적이 남아 있으면 공격받지 않는다 |
| 다중 포격 | 주 표적 외에 다음 순위 적에게도 동시에 피해를 준다 |
| 과부하 | 반경 1 이내 자신의 건물 수만큼 생산이 추가된다 |

## 카드 일러스트 가이드

일러스트는 아직 코드에 연결되지 않았다. 아래는 제작·배치 기준이며, 크기 비율은 UI에 슬롯을 만들어 본 뒤 조정할 수 있는 잠정안이다.

### 폴더와 파일명

```
client/public/cards/
├── core.webp
├── coalition/extractor.webp, outpost.webp, ...
├── swarm/larva-nest.webp, ...
├── automata/
├── shade/
└── siege/
```

- 경로는 `client/public/cards/<종족id>/<카드id>.webp`, 코어는 `client/public/cards/core.webp`.
- 파일명은 `shared/src/data/cards.ts` 의 영문 `id` 를 그대로 쓴다. 코드에서 `/cards/${race}/${id}.webp` 로 조회한다.
- `client/public/` 은 Vite 가 그대로 서빙하고 `dist` 에 복사되므로 `scripts/deploy-aws.ps1` 배포에 별도 설정이 필요 없다.
- `src/assets` 에 import 하는 방식은 96장을 id 로 동적 조회하기 번거로워 쓰지 않는다.
- 일러스트가 없는 카드는 지금 UI 로 폴백해, 일부만 먼저 넣어도 깨지지 않게 한다.

### 크기·포맷

| 항목 | 기준 |
|---|---|
| 비율 | 4:3 가로형 |
| 원본 크기 | 512×384px (설명 패널 240px 폭의 2배 이상) |
| 포맷 | WebP, 품질 80 전후. 카드당 30~60KB, 96장 합계 약 3~5MB |
| 안전 영역 | 손패에서 `object-fit: cover` 로 잘릴 수 있으므로 핵심 피사체는 중앙 60% 안 |
| 텍스트 | 이름·수치·글자는 넣지 않는다 (UI 가 그린다) |

참고: 현재 `CardFace` 는 손패 카드 140×120px(컴팩트 112×96px), 설명 패널 240px 폭이다.

### 톤

- **배경**: 게임 무대가 짙은 네이비(`#0b1224`)이고 카드 바탕은 좌석 색으로 물든다. 일러스트 배경은 어둡고 채도가 낮은 심우주 톤으로 통일하고, 피사체만 림 라이트로 밝게 살린다.
- **색 금지**: 배경에 보라 계열을 쓰지 않는다(보라는 마법 카드 이름 텍스트 전용). 좌석 색(파랑·주황·청록·분홍)과 같은 원색이 배경을 차지하지 않게 한다.
- **화풍**: 플랫에 가까운 깔끔한 그래픽. `DESIGN.md` 의 플랫 방향에 맞춰 과한 광택·3D 렌더는 피한다.
- **종류 구분**: 실루엣으로 구분한다. 건물은 안정적인 가로형, 유닛은 역동적인 사선, 마법은 빛과 파동.
- **일관성**: 96장 모두 같은 조명 방향(위 왼쪽), 같은 채도·명도 범위. 생성형 AI 를 쓴다면 스타일 프롬프트를 고정하고 종족별로 배치 생성한다.
