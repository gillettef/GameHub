## 2026-10-30 큰 방향: C안(노선 압박형) 채택

### 비교한 안

| | A 카드 줄 엔진 | B 테크 웹 엔진 | C 노선 압박 |
|---|---|---|---|
| 요약 | 카드 줄이 중심, 테크 웹은 카드를 쓰게 해 주는 허가증 | 테크 웹이 중심, 카드 줄은 특수 카드만 | A + 노선 상성과 플레이어 간 압박(습격·분쟁) |
| 원작 감각 | ◎ | △ | ○ |
| 테크 웹 존재감 | ○ | ◎ | ○ |
| 모바일 플레이 시간 | △ | ◎ | △ |
| 상호작용 | ○ | △ | ◎ |
| 구현·AI 난도 | 중 | 낮음 | 높음 |

### 결정

- C안. 쓰루 디 에이지스의 침략·전쟁에 해당하는 플레이어 간 압박을 살리고, 비욘드 어스의 성향 3갈래에서 착안한 노선에 상성을 붙여 노선 선택에 무게를 싣는다.
- 원작과 달리 테크는 카드가 아니라 개인 테크 웹이고, 카드 줄에는 선구자·유산·보급만 나온다.

### C안의 약점과 v0.1 대응

| 약점 | 대응 |
|---|---|
| 3~4인 몰아치기(킹메이킹) | 같은 라운드에 이미 피해를 입은 플레이어는 대상 불가 |
| 1인 플레이 시간 증가 | 건물 5계열 + 유닛 1계열, 레벨 3단계로 압축. 압박은 차례당 1장 |
| 온라인 대기·동기화 | 반응 카드 없음. 모든 압박 카드는 자기 차례에만. 분쟁은 선포자 다음 차례에 판정 |
| AI 난도 | 습격 판정이 결정적(주사위 없음)이라 "이길 수 있는 대상 중 이득 최대"로 단순화 가능 |
| 노선 고착 | 혼합 노선(두 트랙 단계 2 이상)은 상성 영향 없음 → 섞는 선택지 |

## 2026-10-30 v0.2: TTA 규모로 확대

| 항목 | 결정 | 이유·비고 |
|---|---|---|
| 인원·시간 | 장르 원형 수준(2인 90~120분, 4인 3시간+) | 1인 15~20분 목표 폐기. AI 대전·핫시트는 매 차례 자동 저장·이어 하기 |
| 온라인 방 복구 | **하지 않음**(우선 제외) | 서버 재시작 시 방 소멸 원칙 유지. 긴 게임이라 위험은 알고 감 |
| 정치 단계 | **대외 단계**: 습격·분쟁·징후·협약 중 1개 | 원형의 침략·전쟁·사건·협정에 대응. "압박" 용어 폐기, 손패는 "방위 카드" |
| 토착 생물 | 독립 단계·덱 폐지 → **징후**의 위협 카드 + 공생 습격 "무리 몰이" | 위협 타이밍을 플레이어가 조절 → 상호작용 강화. 고리 전환 시 남은 징후 일괄 처리로 정체 방지 |
| 협약 | 도입(불가침·교역·공동 연구·보호) | v0.1에서 뺐던 것을 되살림. 응답은 즉시 수락/거절 하나뿐이라 온라인 대기 최소 |
| 정부 | 카드 없음. 행동 수는 줄기·헌장·노선, 한도는 계열별 줄기 연구 수 | 테크 웹을 "내 정부"로 읽히게 |
| 유닛 | 경비대·기동대·포대·비행대 4계열 + 편성 카드 | 원형의 유닛 다양성 대응. 기동대=공격·탐사지, 포대=방어, 비행대=궤도 연계 |
| 테크 웹 방향 | **6방향 + 줄기 이중 해금**(B) | 9방향은 작은 화면에서 빽빽함. 농업=농장+기동대, 산업=제작소+포대, 동력=발전소+비행대, 학술·문화=건물+지휘, 방위=경비대+방위 |
| 리플레이성 | 방향 순서 섞기(농업 고정) + 곁가지 풀 추첨(제약 있음) + 옆 연결선 끊기(선택, 기본 꺼짐) | 뼈대 고정으로 밸런스 기준 유지 |
