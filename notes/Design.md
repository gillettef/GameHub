## 2026-10-30 큰 방향: C안(노선 압박형) 채택

### 비교한 안

| | A 카드 줄 엔진 | B 테크 웹 엔진 | C 노선 압박 |
|---|---|---|---|
| 요약 | 카드 줄이 중심, 테크 웹은 카드를 쓰게 해 주는 허가증 | 테크 웹이 중심, 카드 줄은 특수 카드만 | A + 노선 상성과 플레이어 간 압박(습격·분쟁) |
| 원작 감각 | ◎ | △ | ○ |
| 테크 웹 존재감 | ○ | ◎ | ○ |
| 모바일 플레이 시간 | △ | ◎ | △ |
| 상호작용 | ○ | △ | ◎ |
| 구현·AI 난도 | 중 | 낮음 | 높음 |

### 결정

- C안. 쓰루 디 에이지스의 침략·전쟁에 해당하는 플레이어 간 압박을 살리고, 비욘드 어스의 성향 3갈래에서 착안한 노선에 상성을 붙여 노선 선택에 무게를 싣는다.
- 원작과 달리 테크는 카드가 아니라 개인 테크 웹이고, 카드 줄에는 후원자·유산·자원 팟만 나온다.

### C안의 약점과 v0.1 대응

| 약점 | 대응 |
|---|---|
| 3~4인 몰아치기(킹메이킹) | 같은 라운드에 이미 피해를 입은 플레이어는 대상 불가 |
| 1인 플레이 시간 증가 | 건물 5계열 + 유닛 1계열, 레벨 3단계로 압축. 압박은 차례당 1장 |
| 온라인 대기·동기화 | 반응 카드 없음. 모든 압박 카드는 자기 차례에만. 분쟁은 선포자 다음 차례에 판정 |
| AI 난도 | 습격 판정이 결정적(주사위 없음)이라 "이길 수 있는 대상 중 이득 최대"로 단순화 가능 |
| 노선 고착 | 혼합 노선(두 트랙 단계 2 이상)은 상성 영향 없음 → 섞는 선택지 |

## 2026-10-30 v0.2: TTA 규모로 확대

| 항목 | 결정 | 이유·비고 |
|---|---|---|
| 인원·시간 | 장르 원형 수준(2인 90~120분, 4인 3시간+) | 1인 15~20분 목표 폐기. AI 대전·핫시트는 매 차례 자동 저장·이어 하기 |
| 온라인 방 복구 | **하지 않음**(우선 제외) | 서버 재시작 시 방 소멸 원칙 유지. 긴 게임이라 위험은 알고 감 |
| 정치 단계 | **대외 단계**: 습격·분쟁·징후·협약 중 1개 | 원형의 침략·전쟁·사건·협정에 대응. "압박" 용어 폐기, 손패는 "방위 카드" |
| 토착 생물 | 독립 단계·덱 폐지 → **징후**의 위협 카드 + 공생 습격 "무리 몰이" | 위협 타이밍을 플레이어가 조절 → 상호작용 강화. 고리 전환 시 남은 징후 일괄 처리로 정체 방지 |
| 협약 | 도입(불가침·교역·공동 연구·보호) | v0.1에서 뺐던 것을 되살림. 응답은 즉시 수락/거절 하나뿐이라 온라인 대기 최소 |
| 정부 | 카드 없음. 행동 수는 줄기·헌장·노선, 한도는 계열별 줄기 연구 수 | 테크 웹을 "내 정부"로 읽히게 |
| 유닛 | 경비대·기동대·포대·비행대 4계열 + 편성 카드 | 원형의 유닛 다양성 대응. 기동대=공격·탐사지, 포대=방어, 비행대=궤도 연계 |
| 테크 웹 방향 | **6방향 + 줄기 이중 해금**(B) | 9방향은 작은 화면에서 빽빽함. 농업=농장+기동대, 산업=제작소+포대, 동력=발전소+비행대, 학술·문화=건물+지휘, 방위=경비대+방위 |
| 리플레이성 | 방향 순서 섞기(농업 고정) + 곁가지 풀 추첨(제약 있음) + 옆 연결선 끊기(선택, 기본 꺼짐) | 뼈대 고정으로 밸런스 기준 유지 |

## 2026-10-30 v0.3: 퀘스트 트랙·위성 시야·주둔지

| 항목 | 결정 | 이유·비고 |
|---|---|---|
| 개척 선단 | **삭제** | 시작 상태는 모두 같다. 판마다 달라지는 요소는 테크 웹 배치·퀘스트 순서·주둔지가 맡는다 |
| 군사 카드·사건 더미 | 방위 카드 덱·징후 더미 삭제 → **공용 퀘스트 트랙**(공개 2칸 + 미래 더미) | 쓰루의 군사 카드와 현재·미래 사건 더미를 하나로 합침. 퀘스트 구조(조건 → 노선별 선택지)는 비욘드 어스에서 착안했으나 카드 내용은 직접 설계 |
| 퀘스트 종류 | 판정형·위협형·경쟁형·주둔지 제안 + 종료 시대 결실 | 판정형=쓰루의 사건, 위협형=토착 생물, 경쟁형=먼저 수행한 사람이 보상, 주둔지 제안=식민지 쟁탈 |
| 플레이어 간 공격 | 습격·분쟁 **유지**, 카드 없는 기본 행동으로 | C안 정체성 유지. 손패가 없어져 AI·온라인 가림이 단순해짐. 협약·편성은 삭제, 편성 대신 방위 태세 |
| 사건 심기 | **트랙 당기기**(방위 1로 퀘스트 트랙 1칸 진행) | 쓰루의 사건 심기처럼 타이밍을 다투는 요소를 남김. 위성 시야와 맞물림 |
| 위성 | 타이머 버프 → **시야 +1** + 작은 보너스 | 더 먼 미래 퀘스트를 미리 봄. 에너지를 꾸준히 쓰는 곳이 됨 |
| 시대 전환 | 카드 줄 덱 소진 → **현재 고리 줄기 합 ≥ 인원 × 3** + 덱 소진 안전장치 | 개인 기준이면 선두가 속도를 쥠. 인원수에 맞춰 늘리는 합으로 정함 |
| 식민지 | **주둔지**(`patron`) | "스폰서"는 원작 시스템명이라 피함. 영구 보너스 + 시대마다 본국 요구. 탐사지와 역할이 겹쳐 탐사지는 삭제 |
| 건물·정착민 | 쓰루 뼈대 유지 + 건설 시 자동 배치 + **특수 시설** | 검증된 구조. 모바일 조작 감소. 특수 시설은 퀘스트 보상 |
| 승리 | **문화 점수만** | 승리 트랙 삭제. 밸런스 기준과 AI 평가 함수가 하나로 줄어듦 |
| 종료 | **결실 퀘스트**(노선별 3장)가 처음 공개되면 그 라운드 끝까지 | 원작의 노선 승리 이름은 쓰지 않음. 등장 즉시 종료는 자리 불공평이라 라운드 마무리. 하나만 무작위로 나오면 운 요소가 커서 3장 모두 정산 |
| 플레이 모드 | **로컬 AI 대전 + 온라인 대전만**. 핫시트 개발 안 함 | 가림 화면 불필요. 위성 시야가 사람마다 달라 온라인 mask 에 "본인 시야 밖 미래 퀘스트" 추가 |
| 개인 임무 | **삭제** | 쓰루에 없는 요소. v0.2에서 이어져 왔으나 쓰루 기반 원칙에 맞지 않아 뺀다. 새 요소는 쓰루에 있는 것이거나 사용자가 정한 것만 넣는다 |

## 2026-10-31 v0.4: 퀘스트 트랙이 카드 줄을 대신함

| 항목 | 결정 | 이유·비고 |
|---|---|---|
| 카드 줄 | **삭제** | 사용자 결정. 퀘스트 트랙이 쓰루의 카드 줄 자리를 맡는다 |
| 퀘스트 트랙 | 공용 5칸, **칸 1만 앞면**. 차례 첫 단계에 1장을 반드시 공짜로 골라 즉시 처리. 고르면 뒤 카드를 당기고 덱에서 칸 5를 채움 | 사용자 결정(5장·첫 장만 공개·매 차례 처음 1장 선택). 뒷면도 고를 수 있음 |
| 위성 시야 | 칸 2부터 시야만큼 뒷면 카드를 본인만 봄 | 사용자 결정. 미래 퀘스트 더미는 없어지고 덱은 아무도 못 봄 |
| 위협·주둔지 제안 | 트랙에 섞임. **고르면 카드의 대상에게 발동** | 사용자 결정. 쓰루의 사건 심기처럼 상대를 노리는 수단이 됨 |
| 후원자·유산·자원 팟 | 그 고리의 시대 퀘스트 덱에 섞음 | 사용자 결정 |
| 판정형·경쟁형 | 고른 사람만 처리 | 고른 사람에게 즉시 처리(사용자 결정)의 자연스러운 해석. 판정형은 전원 검사에서 고른 사람 검사로 |
| 트랙 당기기·라운드 시작 진행 | **삭제** | 트랙은 고를 때만 움직인다. 위협을 터뜨리는 역할은 퀘스트 선택이 맡음 |
| 종료 | 종료 묶음 카드는 고를 수 없음, 처음 칸 1에 오면 그 라운드 끝에 종료 | 고를 수 없는 카드가 칸 1에 고여 막히는 일을 없앰 |
