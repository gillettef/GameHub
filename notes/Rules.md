## 1. 한 줄 요약

**바둑처럼 번갈아 마커를 놓아 영토를 넓히는 게임.** 다만 바둑과 달리
- 아무 칸에나 놓을 수 없다. **내 마커의 시야 안**에만 놓을 수 있다.
- 돌이 모두 같지 않다. **손패의 카드를 내서** 유닛·건물·마법 중 무엇을 놓을지 정한다.
- 마커마다 **비용**이 있어 에너지가 있어야 놓을 수 있다.
- 마커는 **움직이지 않는다.** 대신 공격력이 있는 마커는 매 턴 자동으로 사거리 안의 적을 때린다.
- 승부는 **점수**(영토 + 마커)로 가리고, 상대 코어를 부수면 즉시 끝난다.

## 2. 용어

| 용어 | 뜻 |
|---|---|
| 마커 | 보드에 놓이는 것의 통칭. 유닛·건물·마법 세 종류. 칸 하나에 마커 하나. |
| 코어 | 각 플레이어의 시작 지점 마커. 게임 시작 시 맵이 정한 위치에 자동 배치. 파괴되면 탈락. |
| 카드 | 마커 한 종류에 대응하는 손패 항목. 카드를 내면 그 마커가 놓인다. |
| 종족 | 덱 빌딩에서 고르는 카드 세트(인류 연합/크릴 군락/오토마타 집정체). 기본 덱과 특수 카드 풀이 종족마다 완전히 다르다(10절). |
| 비용 | 마커를 놓기 위해 지불하는 에너지. |
| 시야 | 마커에서 몇 칸 거리까지 마커를 놓을 수 있는지. 거리는 육각 거리(6방향 1칸). |
| 시야 영역 | 플레이어의 모든 마커 시야를 합친 칸 집합. 배치 가능 범위이자 영토의 근거. |
| 영토 | 한 플레이어의 시야 영역에만 속한 칸. 점수 1점. |
| 점수 | 영토 점수 + 마커 점수. 승자를 정한다. |
| 에너지 | 단일 자원. 턴 시작 시 수입만큼 늘고, 배치 비용으로 줄어든다. 상한(20)을 넘는 수입은 버려진다. |
| 수입 | 턴 시작 시 얻는 에너지. 코어 기본 수입 + 건물 생산 합. |
| 손패 / 덱 | 손패는 지금 낼 수 있는 카드(최대 5장), 덱은 아직 뽑지 않은 카드. |

## 3. 구성

- **플레이어**: 2~4명. 사람 또는 AI. 순서는 로비의 좌석(seat) 순서.
- **보드**: 육각 타일, odd-r 오프셋. 크기는 맵이 정한다(11×11 / 13×13 / 15×15, 한 변의 칸 수). 좌표는 `(x, y)`, 왼쪽 위가 `(0, 0)`. `x`는 열, `y`는 행이고, **홀수 행은 반 칸 오른쪽으로 밀린다**(odd-r). 그림에서 인접 6칸은 같은 행의 좌우, 위·아래 두 행에서 각각 2칸(오프셋 방향에 따라 다름)이다.
  - 거리는 좌표를 큐브 좌표로 바꿔 계산한다: `q = x - floor(y/2)`, `r = y`, `s = -q - r`. 두 칸의 육각 거리는 `max(|Δq|, |Δr|, |Δs|)`. 이웃 6칸은 거리 1인 칸 전부다(방향을 따로 나열하지 않는다).
- **지형**: 칸마다 하나.
  - `빈 우주`: 기본. 배치 가능.
  - `소행성`: 배치 불가. 시야·사거리는 통과한다. 영토로 계산하지 않는다.
  - `광맥`: 배치 가능. 여기에 지은 **건물**은 생산 +1. 유닛·마법은 보너스 없음.
- **맵**: 6개 (2인용 2, 3인용 2, 4인용 2). 11절 참고. 맵은 코어 위치와 지형, 라운드 제한을 정한다.
- **종족**: 3개(인류 연합 / 크릴 군락 / 오토마타 집정체, 10절). 카드 컨셉이 완전히 다른 별개의 카드 세트다. 플레이어마다 다른 종족을 고를 수 있다(2026-09-23).
- **카드**: 고른 종족의 기본 덱 22장(그 종족 전용, 특수 카드를 고르기 전까지는 고정) + 덱 빌딩에서 고른 그 종족의 특수 카드 3장(건물·유닛·마법 각 1장) = 25장.

## 4. 준비

1. 방장이 맵을 고른다. 맵의 인원수와 로비 인원이 같아야 시작할 수 있다.
2. 각 플레이어가 종족을 하나 고르고, 그 종족의 특수 카드를 종류별로 1장씩(총 3장) 고른다.
3. 게임 시작 시 시스템이 자동으로:
   - 좌석 순서대로 코어를 맵이 정한 위치에 놓는다.
   - 각자 덱(고른 종족의 기본 22 + 그 종족 특수 3)을 시드 RNG로 섞고 손패 4장을 뽑는다.
   - 에너지를 5로 맞춘다.
4. 좌석 0번부터 좌석 번호 순으로 턴을 진행한다.

## 5. 턴 진행

턴은 한 플레이어의 것이다. 세 단계로 나뉘며 시작·종료 단계는 서버가 자동 처리한다.

### 5.1 시작 단계 (자동, 이 순서대로)

1. **전투**: 내 마커 중 공격력이 있는 것 전부가 자동 공격한다 (7절).
2. **정비**: `정비` 키워드 마커의 회복 효과.
3. **지속 마법 만료**: 내 지속형 마법 마커의 남은 턴을 1 줄이고, 0이 되면 제거한다.
4. **수입**: 에너지 += 코어 기본 수입(1) + 내 건물 생산 합(광맥 보너스, `과부하` 키워드 보너스 포함). 상한 20을 넘으면 20으로 고정하고 초과분은 버린다.
5. **드로우**: 손패가 5장 미만이고 덱이 남아 있으면 1장 뽑는다.

첫 턴에도 시작 단계를 그대로 수행한다(전투는 대상이 없어 아무 일도 없다).

### 5.2 행동 단계 (플레이어 선택)

- **배치**: 손패 카드 1장을 내고 마커를 놓는다 (6절). 카드는 버린다. **한 턴에 배치는 한 번만** 할 수 있다(2026-09-23 사용자 지시로 되돌림 — 바둑처럼 "한 턴에 하나"). 이미 배치했으면 같은 턴에는 손패의 어떤 카드도 더 낼 수 없다(`already-placed`).
- **패스 / 턴 종료**: 행동을 마치고 턴을 넘긴다. 이번 턴에 한 번도 배치하지 않고 선택하면 "패스"로 기록되어 9.2의 전원 연속 패스 판정에 들어간다. 이번 턴에 배치했다면(1회) 선택하면 이미 행동했으므로 패스로 기록되지 않는다(연속 패스 판정에서 제외). 손패에 놓을 수 있는 카드가 없거나 이미 배치했으면 이 선택만 가능하다.
- **기권**: 즉시 탈락한다.

배치 여부(`actedThisTurn`)는 턴 시작 단계(5.1)에서 매번 초기화된다 — 즉 매 턴 정확히 한 번만 배치할 기회가 있다.

### 5.3 종료 단계 (자동)

1. 파괴된 마커 정리, 탈락 처리 (7.3).
2. 점수 재계산.
3. 종료 조건 확인 (9절). 종료가 아니면 다음 생존 플레이어에게 턴을 넘긴다.

## 6. 배치 규칙

카드 `C`를 칸 `P`에 놓을 수 있는 조건. 하나라도 어긋나면 서버가 거부한다.

1. `C`가 내 손패에 있다.
2. 에너지 ≥ `C`의 비용.
3. `P`가 보드 안이고, 지형이 소행성이 아니며, 비어 있다.
4. `P`가 내 **시야 영역** 안이다. 즉 내 마커 `M` 중 `dist(M, P) ≤ M.시야` 인 것이 하나 이상 있다.
   - `침투` 키워드가 있는 카드는 4 대신 "적 마커로부터 거리 1 이내"도 허용한다.
5. 마법 카드도 같은 조건으로 빈 칸에 놓는다. 즉발형 마법은 그 칸을 중심으로 효과를 낸 뒤 사라진다. 지속형 마법은 마커로 남는다.

배치가 성립하면: 비용 차감 → 마커 생성(체력 = 최대 체력) → 마법 즉발 효과 적용 → 파괴 정리. 배치는 턴을 자동으로 끝내지 않지만, 이번 턴에 더 배치할 수는 없다(5.2) — 패스/턴 종료를 선택해야 다음 사람에게 넘어간다.

## 7. 전투

### 7.1 자동 공격

시작 단계의 전투에서, 턴 플레이어의 **공격력 > 0인 마커 각각**이 다음과 같이 공격한다.

- 대상 후보: 사거리(육각 거리) 안의 **적 마커** 전부. 코어 포함. 지속형 마법 마커 포함. 아군·소행성은 제외.
- 대상 선택 순서(결정적): 거리 오름차순 → 남은 체력 오름차순 → `y` 오름차순 → `x` 오름차순. 첫 번째 하나만 공격.
- 피해 = 공격력. 방어력 개념은 없다.
- 모든 공격은 **전투 시작 시점 상태**를 기준으로 대상을 고르고, 피해는 한꺼번에 적용한다(동시 판정).
- 피해 적용 후 체력 ≤ 0인 마커를 한꺼번에 제거한다.

턴 플레이어의 마커만 공격한다. 상대는 자기 턴 시작 때 반격한다. 따라서 마커를 놓은 직후에는 공격하지 않고, 한 바퀴 돌아 내 턴이 왔을 때 처음 공격한다.

### 7.2 즉발 마법

배치 즉시 효과를 내고 사라진다. 효과의 중심은 놓은 칸이다.

- `피해 N, 반경 R`: 중심에서 거리 ≤ R인 적 마커 전부에 N 피해.
- `회복 N, 반경 R`: 중심에서 거리 ≤ R인 아군 마커 전부 체력 +N (최대 체력까지).
- `에너지 +N`: 즉시 에너지 획득. 상한(20)을 넘으면 초과분은 버린다.

### 7.3 파괴와 탈락

- 체력 ≤ 0인 마커는 보드에서 사라진다. 그 마커의 시야·생산·점수는 **즉시** 없어진다.
- **코어**가 파괴되면 그 플레이어는 **탈락**한다. 탈락 플레이어의 남은 마커는 전부 보드에서 제거된다(칸이 비고 시야 영역이 사라진다).
- 기권도 탈락이다.
- 탈락한 플레이어는 이후 턴에서 건너뛴다.

## 8. 시야와 영토

- 플레이어의 시야 영역 = 자기 모든 마커에 대해 `dist(육각 거리) ≤ 시야` 인 칸의 합집합. 마커가 놓인 칸 자체는 시야 0이어도 포함.
- 시야는 소행성·다른 마커에 가려지지 않는다.
- **영토 판정** (칸마다):
  - 마커가 놓인 칸 → 그 마커 소유자의 영토.
  - 빈 칸이 정확히 한 플레이어의 시야 영역 안 → 그 플레이어의 영토.
  - 둘 이상의 시야 영역 안(경합) 또는 아무 시야 밖 → 누구의 영토도 아님.
  - 소행성 칸 → 누구의 영토도 아님.
- 시야 하나로 "어디에 놓을 수 있는가"와 "어디가 내 땅인가"를 같이 정한다. 시야를 넓히면 땅이 늘고, 적 시야와 겹치면 땅이 줄어든다.

## 9. 점수와 종료

### 9.1 점수

```
점수 = 영토 칸 수 × 1 + Σ(내 마커의 점수) + 덤(좌석 번호 × KOMI_PER_SEAT)
```

코어의 점수는 0. 즉발 마법은 마커로 남지 않으므로 0. **덤(komi)**: 좌석 번호가 뒤일수록(=턴이 늦게 올수록) 매 판 소소한 보너스를 받는다(12절 `KOMI_PER_SEAT`, 2026-09-23 신설) — 먼저 두는 좌석이 유리하다는 피드백을 보정한다. 탈락자는 덤을 포함해 점수가 0으로 고정된다(9.3). 점수는 매 턴 종료 단계에 재계산해 상태 탭에 항상 보여 준다.

### 9.2 종료 조건 (먼저 만족하는 것)

1. **최후 생존**: 생존 플레이어가 1명이 되면 그 플레이어의 즉시 승리.
2. **전원 패스**: 생존 플레이어 전원이 한 바퀴 연속으로 패스하면 점수 정산. 판정은 플레이어별 "패스 중" 표시로 한다: 이번 턴에 한 번도 배치하지 않고 턴을 넘기면(5.2) 그 플레이어에 표시가 붙고, 누군가 배치하면 전원 표시가 지워진다(그 배치를 한 플레이어 자신도 포함). 생존자 전원에 표시가 붙는 순간 정산한다. 탈락자의 표시는 세지 않는다(탈락자가 패스했었다는 이유로 끝나지 않는다).
3. **라운드 제한**: 맵의 라운드 제한에 도달하면 점수 정산. (라운드 = 생존 플레이어 전원이 한 번씩 턴을 마친 것.) 라운드 제한은 **마지막으로 진행되는 라운드 번호**다. 그 라운드의 생존자 전원 턴이 끝나면 정산한다 (2인 20라운드 = 최대 40턴).

카드가 모두 떨어진 플레이어는 패스만 할 수 있으므로, 전원 덱·손패 소진은 2번으로 자연히 끝난다.

### 9.3 순위

1. 생존자는 점수 내림차순(덤 포함 총점 기준).
2. 그래도 동점이면 **좌석 번호가 큰(나중 순서) 플레이어**가 위. 덤으로 대부분의 동점은 갈리지만, 정확히 같은 총점이 남을 경우의 마지막 보정이다.
3. 탈락자는 생존자 아래. 탈락자끼리는 늦게 탈락한 쪽이 위.

## 10. 카드

거리는 모두 육각 거리. `-`는 해당 없음. 2026-09-23부터 카드는 **종족** 소속이다 — 종족마다 기본 덱과
특수 카드 풀이 완전히 다르다(얕은 재색칠이 아니라 컨셉 자체가 다른 별개의 카드 세트). 플레이어는
덱 빌딩(F016)에서 종족을 하나 고른 뒤 그 종족의 특수 카드 3장(건물·유닛·마법 각 1장)을 고른다.

### 10.0 종족 3개

## 11. 맵 (6개)

기호: `.` 빈 우주, `#` 소행성, `o` 광맥, 숫자 = 그 좌석의 코어. 좌표는 `(x, y)`, 그림의 행이 `y`, 열이 `x`(odd-r 오프셋: 홀수 행은 그림에서 반 칸 오른쪽으로 밀려 보이지만, 이 문서와 데이터 파일에서는 정사각 문자 격자로 그대로 적는다. 실제 화면 렌더링만 반 칸씩 밀려 그린다).

좌석별 공정성은 대칭 모양이 아니라 **계산된 값**으로 보장한다: 코어 시야(반경 1) 안 배치 가능 칸 수, 최근접 광맥까지의 육각 거리, 코어 반경 3 안 광맥·소행성 수, 보드 경계까지의 여유, 코어 간 거리 프로필이 전부 좌석마다 같다(`data.test.ts` 의 좌석 공정성 테스트로 고정). 2인·3인 맵은 육각 격자의 180°·120° 회전이 정확한 등거리 변환이라 완전 대칭으로 만들 수 있지만, 4인 맵은 육각 격자에 정확한 90° 회전 대칭이 없어 좌표를 계산해 거리 프로필만 맞췄다.

## 13. 결정성 규칙 (엔진 구현 기준)

같은 입력에 항상 같은 결과가 나오도록 순서를 고정한다.

- 마커 순회: `y` 오름차순 → `x` 오름차순. odd-r 오프셋 좌표 그대로 비교한다(큐브 좌표로 바꾸지 않는다). (Map/Object 키 순서에 의존하지 않는다.)
- 전투 대상 선택: 거리(육각 거리) → 남은 체력 → `y` → `x` 오름차순.
- 피해는 전투 시작 시점 상태로 계산해 한꺼번에 적용.
- 파괴 정리는 피해 적용 후 한 번에.
- 탈락 처리 순서: 같은 전투에서 코어가 둘 이상 깨지면 좌석 번호 오름차순으로 탈락 기록.
- 셔플: 상태 안의 시드 RNG(`rngSeed`)만 사용. `Math.random` 금지.
- 시야·영토·점수는 상태에서 언제든 다시 계산할 수 있는 파생값이다. 저장하더라도 정본은 계산 함수다.

## 14. 설계 결정과 근거

| 결정 | 근거 |
|---|---|
| 자원을 에너지 하나로 통일 | 상태 창에 비용 하나만 보이면 되고, AI 평가와 밸런싱이 단순해진다. 건물/유닛/마법 구분은 시야·전투·즉발 효과의 차이로 표현한다. |
| 마커는 이동하지 않음 | 바둑의 "놓은 돌은 그 자리" 감각을 유지한다. 압박은 사거리 안에 새 마커를 놓는 것으로 한다. |
| 공격은 내 턴 시작 시 자동 | 놓은 직후 때리면 선공이 너무 강하다. 한 바퀴 여유를 주어 상대가 대응(제거·회복·방어탑)할 수 있게 한다. |
| 시야 = 배치 범위 = 영토 근거 | 규칙 하나로 두 역할을 맡겨 배우기 쉽게 한다. 시야가 겹치는 칸은 경합으로 비워 두어 접전 지역이 생긴다. |
| 한 턴에 배치 한 번만(2026-09-23 되돌림) | 2026-09-22 에 "한 턴에 마커 하나" 제한을 걷어내 에너지가 허락하는 한 여러 번 배치할 수 있게 했었으나, 2026-09-23 사용자 지시로 다시 "바둑처럼 한 턴에 하나"로 되돌렸다. 에너지를 여러 턴에 걸쳐 모아 쓰는 절제도, 매 턴의 선택 하나하나가 뚜렷이 보이는 리듬도 이 쪽이 낫다는 판단. |
| 덤(komi) 신설(2026-09-23) | 배치를 턴당 하나로 되돌리면서 "선턴이 유리하니 보정이 필요하다"는 지시를 받았다. 좌석 번호에 비례한 작은 점수 보너스로, 2인전뿐 아니라 3·4인전에도 똑같이 적용한다(늦은 좌석일수록 매 라운드 자기 차례를 더 오래 기다리므로). 별도 상태·액션 없이 `computeScores` 안에서만 계산해 엔진 위험이 작다. |
| 코어 기본 수입 2 | 경제가 무너져도 완전히 멈추지 않는다. 처음 1이었으나 초반 에너지 부족으로 2로 올렸다 (시작 에너지 3 → 5, 기본 덱에 에너지 결정 2장 추가와 함께). |
| 에너지 상한 20 | 최고가 카드(비용 8)를 두 번 이상 감당할 여유는 주되, 건물이 여러 채 쌓인 후반에 수입을 다 못 쓰고 의미 없이 불어나는 것은 막는다. 카드 비용을 못 넘는 손패 정체 상태를 오래 방치하면 손해가 되도록 해 배치를 유도한다. |
| 탈락자 마커 전부 제거 | 3~4인전에서 죽은 플레이어의 벽이 남으면 판이 굳는다. 빈 땅으로 돌려 남은 플레이어의 확장 여지를 만든다. |
| 안개(전장의 안개) 없음 | 바둑처럼 보드는 전부 공개. 숨기는 정보는 손패뿐. Minimax 탐색도 단순해진다. |
| 방어력 없음 | 체력 차이만으로 충분히 구분된다. 공식이 단순해 결정성 검증이 쉽다. |
| 정사각 격자 → 육각 타일 (odd-r 오프셋) | 8방향 대각선 인접이 "인접"의 직관과 어긋난다는 피드백. 육각은 이웃 6칸이 전부 같은 거리라 시야·사거리·반경이 더 명확하다. odd-r 오프셋을 택해 `(x, y)` 좌표와 `y → x` 결정성 규칙을 그대로 유지했다. |
| 코어 시야·기본 수입 2 → 1 | 육각 전환으로 반경 r이 덮는 칸이 `(2r+1)²`에서 `3r(r+1)+1`로 줄어드는 김에(시야 2는 25→19칸) 코어 개막 범위를 한 단계 더 좁혀 초반 확장 선택의 비중을 늘렸다. 코어 시야 1 기준 배치 가능 칸은 6칸(코어 자신 제외). |
| 종족마다 기본 덱을 통째로 다르게 함(2026-09-23) | 손패를 보고 초반 러쉬 vs 후반 운영을 고르는 전략성과 카드 다양성을 요청받았고, 뒤이어 "종족별 컨셉이 완전히 달라야 한다"는 지시로 특수 카드 풀만 다른 얕은 안을 기각했다. `coalition`(인류 연합)은 기존 수치를 그대로 둬 `engine.test.ts` 의 기존 검증을 깨지 않았고, `swarm`·`automata`는 전부 새 id라 기존 테스트와 충돌하지 않는다. 코어만은 좌석 공정성 때문에 종족과 무관하게 통일했다. |
| 과부하 키워드를 인접 건물 수 기반으로 설계 | 새 상태 필드나 액션 없이 `computeIncome` 안에서 기존 `정비` 키워드(턴 시작 반경 효과)와 같은 인접 스캔 패턴으로 구현할 수 있어 엔진 위험이 작다. 건물을 뭉치는 배치 자체가 "축적형 경제"라는 오토마타의 정체성을 규칙으로 직접 표현한다. |
