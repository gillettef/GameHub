# Neoterra 규칙 정본 (v0 초안, 2026-10-30)

> 이 문서가 규칙의 단일 기준이다. 코드·AI·UI가 이 문서와 다르면 이 문서가 맞다.
> v0 은 구조만 정한 초안이다. **"미정"** 표시된 수치는 시뮬레이터(`/simulate`)로 재서 확정하고, 결정 이유를 12절에 남긴다.

## 1. 개요

- 인원 2~4명, 목표 플레이 시간 1인당 15~20분(모바일 기준).
- 각자 **개척 선단** 하나를 이끌고 행성에 정착한다. 게임은 **1고리 → 2고리 → 3고리** 세 시대로 진행된다.
- 승리: (a) **노선 승리 트랙** 중 하나를 먼저 완주하거나, (b) 3고리 덱이 바닥난 뒤 **최종 점수**가 가장 높은 사람.

## 3. 구성 요소 (디지털 기준)

- 개인: 식민지 보드(자원 트랙·건물 칸), 테크 웹 보드, 노선 트랙 3개, 궤도 칸 2개(미정), 정착민 토큰.
- 공용: 카드 줄(칸 수 = 인원 + 4, 미정), 고리별 카드 덱 3개, 토착 생물 덱, 위성 덱, 임무 덱, 헌장 칩, 노선 승리 트랙.

## 4. 준비

1. 선단 카드를 무작위 2장 받고 1장을 고른다.
2. 임무 카드를 3장 받고 2장을 남긴다(비공개).
3. 테크 웹 중심 노드(`core`)를 연구한 상태로 시작한다. 웹 바깥 고리는 모듈 타일을 시드로 섞어 배치한다(5.4).
4. 시작 자원·정착민 수: 미정.
5. 1고리 덱을 섞어 카드 줄을 채운다. 시작 플레이어는 시드로 정하고, 뒤 자리일수록 시작 자원 보정(미정).

## 5. 테크 웹

### 5.1 구조

- 중심 노드 1개에서 줄기 6개 방향(미정)으로 뻗는다. 각 방향은 고리 1·2·3에 줄기 기술을 하나씩 가진다.
- 각 줄기 기술에는 곁가지 2~3개가 붙는다. 곁가지는 그 줄기와만 연결된다.
- 같은 고리의 이웃 방향 줄기끼리는 옆 연결선으로 이어진다(방향을 바꿔 이동 가능).

### 5.2 연구 규칙

- **연결 조건**: 이미 연구한 노드와 연결선으로 맞닿은 노드만 연구할 수 있다.
- **고리 제한**: 현재 시대 고리보다 바깥 노드는 연구할 수 없다(미정: 1칸 앞까지 허용할지).
- **비용** = `고리 기본 비용[ring] + floor(연구한 노드 수 / 증가 간격)` 과학. 곁가지는 기본 비용이 줄기보다 낮다. 수치 미정.
- **인접 할인**: 연구할 노드와 연결된 내 연구 노드가 2개 이상이면 비용 −1(최소 1).
- 연구는 지휘 행동 1개 + 과학 비용.

### 5.3 효과

- 줄기: 건물 종류 해금 또는 기존 건물 업그레이드, 행동 수 +1 같은 큰 효과.
- 곁가지: 노선 점수(+1~2) 와 작은 즉시 효과.

### 5.4 리플레이성

- 2·3고리 줄기와 곁가지는 모듈 타일로 묶여 있고 시드로 섞어 배치한다. 모든 플레이어의 웹 배치는 같다(공정성).

## 6. 노선

- 트랙 3개: 방주(지구에서 가져온 모습을 지킨다) · 공생(토착 생물과 섞인다) · 합성(기계로 몸과 도시를 바꾼다).
- 노선 점수는 곁가지 연구·임무·일부 카드에서 얻는다.
- 각 트랙의 단계 칸(4·8·12·16, 미정)에 도달하면 그 노선 전용 보상이 열린다.
- **혼합 노선**: 두 트랙이 동시에 단계 2 이상이면 혼합 카드를 쓸 수 있다(구체 효과 미정).
- 토착 생물 대응이 노선마다 다르다(9절).

## 7. 차례 흐름

1. **카드 줄 정리**: 맨 앞 칸(미정: 2인 2장, 3·4인 1장)을 버리고 앞으로 당긴 뒤 덱에서 채운다.
2. **행동**: 지휘 행동과 방위 행동을 쓴다. 기본 수는 선단·건물·기술로 정해진다(미정).
   - 지휘: 연구 / 카드 줄에서 카드 가져오기 / 건설·업그레이드 / 정착민 늘리기·배치 / 위성 발사 / 헌장 구매
   - 방위: 유닛 배치·업그레이드 / 토착 생물 대응 / 탐사 지역 획득
3. **생산**: 건물에서 식량·생산·에너지·과학·문화를 얻는다. 식량 소비, 에너지 보유량에 따라 포자 안개 판정, 안정도 판정.
4. **토착 생물 페이즈**: 차례 플레이어가 위협 카드 1장을 공개해 처리한다(라운드당 1장인지 차례당 1장인지 미정).
5. **궤도 정리**: 내 위성 타이머를 1씩 내리고 0이면 버린다.

## 8. 자원과 경제

| 자원 | 용도 |
|---|---|
| 식량 | 정착민 늘리기, 매 차례 소비 |
| 생산 | 건설·유닛·불가사의 |
| 에너지 | 위성 발사·카드 비용 일부. 많이 쌓으면 포자 안개 |
| 과학 | 테크 웹 연구 |
| 문화 | 헌장 구매, 최종 점수 |

- **안정도**: 정착민 수가 안정도를 넘으면 초과 정착민은 생산하지 않는다(미정: 불안 정도에 따라 추가 페널티).
- **포자 안개**: 차례 끝 에너지가 기준치(미정)를 넘으면 초과분에 비례해 안정도 −1.

## 9. 토착 생물

- 위협 카드에는 위협도·대상(군사력 최저 / 전원 / 에너지 최다 등)·보상이 있다.
- 방위력 ≥ 위협도면 막고, 노선에 따라 보상이 다르다: 방주·합성은 처치 보상(자원·노선 점수), 공생은 **공존 선택**(위협도만큼 안정도를 쓰고 공생 점수·특수 자원을 얻음).
- 막지 못하면 카드에 적힌 손실.

## 10. 궤도·임무·헌장

- **궤도**: 위성 카드는 에너지로 발사하고 타이머 토큰 n개(카드에 표시)를 올린다. 남아 있는 동안 매 생산 보너스. 칸 수 제한.
- **임무**: 비공개 2장. 달성 즉시 공개하고 보상(노선 점수·문화).
- **헌장**: 4개 분야(번영·탐구·방위·결속, 이름 미정) 각 3단계. 문화로 산다. 같은 분야를 채우면 보너스.

## 11. 승리와 종료

- **노선 승리 트랙**(각 4단계, 단계 조건 미정):
  - 방주 — "두 번째 방주": 지구 이주민을 맞이할 관문 건설
  - 공생 — "행성의 꿈": 행성 의식과 연결
  - 합성 — "강철 새벽": 기계 융합 도시 완성
  - 공통 — "심연의 신호": 행성 밖 신호 해독(노선 무관)
- 누군가 트랙 하나를 완주하면 그 라운드를 끝까지 진행하고(같은 라운드에 여럿이면 최종 점수로) 승리.
- 3고리 덱과 카드 줄이 모두 비면 마지막 라운드 후 종료. **최종 점수** = 문화 + 노선 트랙 진행 점수 + 불가사의·헌장·임무 점수(배점 미정).
- 동점: 승리 트랙 진행 합 → 남은 자원 합 → 자리 늦은 쪽.

## 13. 결정성

- 모든 난수는 `GameState.rngState` 의 시드 RNG만 쓴다. 사용 순서: 웹 모듈 배치 → 선단 → 임무 → 고리 덱 → 토착 생물 덱 → 위성 덱 → 시작 플레이어.
