## 2. 손님 말 상세

이 게임의 허점 방지는 손님 말 형태가 맡는다(D-005, D-007).

```
  옆에서 자른 모습 (가면 면 쪽이 오른쪽)

        ┌─────────────┐  26mm ← 윗면: 번호 + 방향 화살표
        │             │
        │      ┌──────┤  22mm ← 홈 지붕 (위가 막혀 있다)
        │      │╲     │
        │      │ ╲    │       문양 타일: 45도로 기울어
        │      │  ╲   │       앞쪽 위를 바라본다
        │      └───╲──┤   6mm ← 홈 바닥
        │             │
        └─────────────┘   0
               ←12mm→  홈 깊이
```

| 항목 | 치수 (가안) | 이유 |
|---|---|---|
| 몸체 | 24×24×26mm (차양 포함 앞뒤 32mm) | 칸 40mm 안에서 손으로 집기 쉽다. 생울타리(32mm)보다 낮다 |
| 가면 홈 입구 | 폭 10mm × 높이 16mm (바닥 6mm ~ 지붕 22mm) | 지붕이 22mm라서, 생울타리(32mm)에 맞닿으면 입구 전체가 덮인다 |
| 가면 홈 깊이 | 12mm | 홈 안쪽 깊이 |
| 가면 차양 | 홈 양옆과 지붕이 앞으로 8mm 더 나옴 (유효 깊이 20mm, 폭 8mm) | 문양이 보이는 좌우 범위가 정면 기준 약 ±22도로 좁아진다. 눈높이 규칙의 "가장자리에서 한 뼘"과 합치면 가장 불리한 모서리 칸도 옆 좌석에서 읽히지 않는다(D-024) |
| 문양 타일 각도 | 45도 (앞쪽 위를 향함) | 홈 지붕이 막혀 있어도, 앉아서 내려다보는 각도(30~60도)에서 문양이 보인다 |
| 문양 타일 끼우는 곳 | 바닥 쪽 슬롯 | 준비 때 타일을 바닥에서 밀어 넣는다. 게임 중 빠지지 않을 만큼 빡빡하게 |
| 윗면 | 번호(크게) + 가면 면 쪽 가장자리의 삼각 화살표 | 홈을 보지 않고도 방향을 맞출 수 있다 |
| 색 | 모든 손님 말이 같은 색 | 몸체 색으로 소속이 드러나지 않아야 한다 |

### 왜 "위가 막힌 홈 + 기울인 타일"인가

- **위가 열린 홈**은 생울타리에 붙어 있어도 생울타리 너머로 내려다보면 문양이 보인다. 그러면 일어서서 보는 플레이어를 단속해야 한다.
- **위가 막히고 타일이 수직인 홈**은 앉은 플레이어의 시선(아래로 30~60도)이 홈 지붕에 막혀, 정작 그 좌석에서도 문양이 잘 안 보인다.
- **위가 막히고 타일이 기울어진 홈**은 정면 쪽 앉은 시선에서는 잘 보이고, 생울타리에 맞닿으면 입구가 통째로 덮인다. 옆에서는 옆벽에 막힌다.

## 3. 프로토타입 제작 (2차 심사용)

| 구성물 | 제작 방법 | 예상 비용 |
|---|---|---|
| 손님 말 16 + 정자 1 + 생울타리 12 | 레진 3D 프린트(홈 정밀도 때문에 FDM보다 레진). 무광 단색 도색 | 출력 대행 기준 약 6~9만 원 |
| 정원 보드 | 3mm 폼보드에 인쇄물 부착, 생울타리 홈은 칼집 | 약 1만 원 |
| 문양 타일 | 1mm 아크릴 또는 두꺼운 종이에 인쇄 | 약 5천 원 |
| 카드·토큰·명부 | 인쇄 후 코팅·재단, 토큰은 원형 펀치 | 약 1만 원 |
| 주머니·보드마커·상자 | 시판품 | 약 1만 원 |

## 4. 양산 고려 (기획안용)

- 손님 말은 사출 플라스틱 1종 금형 하나로 16개를 찍는다. 생울타리는 같은 금형 틀에 함께 넣거나 두꺼운 종이를 접는 방식으로 대체할 수 있다.
- 정자는 두꺼운 종이 조립식으로 대체할 수 있다(기둥 + 지붕 + 난간). 난간 높이 32mm만 지키면 규칙에 영향이 없다.
- 카드 18장, 토큰 16개, 보드 1장으로 종이 구성물은 적다.

## 5. 검증 항목 (시제품이 나오면)

| # | 확인할 것 | 통과 기준 |
|---|---|---|
| 1 | 정면 좌석에서, 앉은 채로 가장 먼 칸(7칸 거리)과 가장 가까운 칸의 문양이 보이는가 | 4명 모두 색을 바로 구분 |
| 2 | 옆 좌석의 양 끝 모서리에서 옆을 향한 문양이 보이는가 | 아무도 색을 구분하지 못함 |
| 3 | 생울타리·정자 난간에 맞닿은 말의 문양이, 그 방향 좌석에서 일어서서 봐도 보이는가 | 보이지 않음 |
| 4a | 가면 면 바로 앞 칸에 다른 손님 말을 붙여 놓았을 때, 그 방향 좌석에서 일어서서 봐도 문양이 보이는가 | 보이지 않음 (룰북 6.2-2) |
| 4b | 가면 면에서 2칸 떨어진 곳에 다른 손님 말이 있을 때 문양이 보이는가 | 보임 (룰북 6.2-5) |
| 5 | 1칸 떨어진 생울타리 너머 말의 문양이 보이는가 | 보임 (룰북 6.2-5와 일치) |
| 6 | 손님 말을 감싸 쥐고 돌릴 때 옆 사람에게 문양이 비치는가 | 비치지 않음 |
| 7 | 테이블 아래에서 타일을 끼우는 데 걸리는 시간 | 4개에 1분 이내 |

4a·4b·5번이 실패하면 손님 말 높이나 홈 위치를 고치고, 규칙(6.2)은 바꾸지 않는다.
