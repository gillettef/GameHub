# 구성물 목록 (초안)

| 구성물 | 수량 | 사양 | 비고 |
|---|---|---|---|
| 접기 보드 | 1 | 패널 4장(가안 2×2), 패널마다 4×4 칸, 천 경첩 연결 | 패널 두께와 다중 접기 가능 겹 수는 시제품으로 확인 |
| 접기 선 표시 | 보드 인쇄 | 선마다 이름과 겹친 칸 대응 표시 | 패널 가운데 선 포함 여부는 열린 질문 |

| 별빛 조각 토큰 | 미정 | 소형 토큰, 고정 방식 미정 | 접을 때 떨어지지 않아야 함 |
