## 대상과 상태

대상은 5개이고, 각 대상은 상태 2개를 가진다. 시작 상태는 왼쪽 값이다.

| 대상 | 시작 상태 | 다른 상태 |
|---|---|---|
| 성 | 멀쩡 | 불탐 |
| 왕 | 건강 | 중독 |
| 금고 | 가득 | 빔 |
| 경비 | 깨어 있음 | 잠듦 |
| 성문 | 닫힘 | 열림 |

## 인물

하인, 왕비, 대신, 경비대장, 궁정 의사, 광대 (6명)

## 결말 카드

사실 10개마다 1장씩, 모두 10장이다. 준비 때 결말 카드를 섞고 위에서부터 한 장씩 공개하되, 이미 공개된 결말과 대상이 같은 카드는 버리고 다음 카드를 공개한다. 서로 다른 대상 3장이 나오면 멈춘다.

- 결말 조합 수: 대상 선택 10가지 × 상태 8가지 = **80가지**
- 결말이 시작 상태와 같을 수도 있다(예: 왕 = 건강). 그 대상의 결과 아이콘이 없어도 미해결 결말이 아니며, 결정 원인도 없다.

## 원인 카드 설계 원칙

1. **인물 대칭:** 인물마다 사실 10개에 카드가 정확히 1장씩 있다. 어떤 결말이 나와도 인물 간 유불리가 카드 구성에서 생기지 않는다.
2. **무조건 카드:** 인물마다 조건 없는 카드가 3장씩이다(전체 18장). 게임 초반에 놓을 카드를 확보한다.
3. **조건 연결:** 조건은 다른 대상의 상태를 묻는 경우가 대부분이다. 경비가 잠들면 성문이 열리고, 성문이 열리면 금고가 비는 식으로 대상끼리 인과 사슬이 생긴다.
4. **되돌리기 카드:** 상태를 시작 상태로 되돌리는 카드(진화, 해독, 기상 등)가 있다. 결말이 시작 상태와 같을 때 결정 원인이 될 수 있고, 남의 사슬을 끊는 견제 수단이 된다.
