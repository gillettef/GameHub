# LIGHTCONE 출력용 종이 프로토타입 (룰북 v0.5)

`python scripts/pnp/build_pnp.py`로 다시 만든다. 규칙이나 수량이 바뀌면 스크립트 상단 상수를 고친 뒤 다시 실행한다.

| 파일 | 내용 | 용지 | 인쇄 |
|---|---|---|---|
| `lightcone-boards.pdf` | 메인 보드 1장, 플레이어별 광선 컨베이어·파문 컨베이어 | A4 가로 5장 | 단면 |
| `lightcone-cards.pdf` | 카드 180장(플레이어당 함대 카드 69 + 행성·위장 카드 21), 40×55mm | A4 24장 | **양면, 긴 변 넘김** (앞면·뒷면 페이지가 번갈아 나온다) |
| `lightcone-card-mat-A3.pdf` | 카드 매트 2장(플레이어별) | A3 가로 | 단면 |
| `lightcone-card-mat-A4x2.pdf` | 카드 매트를 A4 2장으로 나눈 판 (이어 붙임) | A4 세로 2장 | 단면, 2부 |
| `lightcone-tokens-reference.pdf` | 잔상 말, 점령 마커, 공격 표식, 라운드 요약표 2장 | A4 3장 | 단면 |

## 만들기 순서
1. 카드는 두꺼운 종이(160g 이상)에 양면 인쇄하고 회색 칸을 따라 자른다. 양면이 어긋나면 앞면만 인쇄하고 플레이어 색 슬리브(A 파랑, B 주황)에 넣어도 된다.
2. 함대 1·2·3 카드를 구분할 수 있게 슬리브 색이나 모서리 표시를 더하면 고르기가 편하다.
3. 잔상 말은 반으로 접어 세운다. 바둑돌이나 미플로 대신해도 된다(번호만 구분되면 된다).
4. 가림막은 시판 가림막이나 세운 상자 뚜껑, 또는 두꺼운 종이 2장을 테이프로 이어 쓴다.
5. 공모전 기획안에 넣을 **게임 진행 사진**은 메인 보드, 양쪽 컨베이어, 가림막이 함께 보이도록 찍는다.
