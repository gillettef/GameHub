- **1차 발표:** 2027-03-08(월) 12시 (변경 가능)

- **심사 기준:** 순수 창작 / 지나치게 복잡하지 않고 재미있음 / 규칙에 허점이 없고 균형이 맞음 / 반복할 만큼 매력적

## 직접 해야 하는 일 (체크리스트)

- [ ] `proposal.md`의 작가명 칸을 채우고 기획안을 다시 생성한다.
- [ ] 신청서를 작성한다. **응모 분야는 "기타 게임"을 권한다.** 공지의 정의("입체적이며 특별한 기물이나 물리적 구조물을 포함한 게임")가 이 게임의 핵심과 정확히 맞는다. 차선은 "패밀리 플러스"다. "패밀리"는 어린이도 함께하는 난이도를 요구하므로 맞지 않는다.
- [ ] 신청서의 개인정보 동의에 체크하고 자필 서명한다(서명 이미지를 넣거나 서명본을 스캔한다).
- [ ] **처음 보는 사람에게 규칙서만 주고 읽게 한다.** 공지가 직접 권하는 검증이다. 막힌 곳을 `playtests/`에 기록한다.
- [ ] **실물 플레이테스트를 최소 3판 한다.** 지금까지의 검증은 가상 시뮬레이션뿐이다. 종이 시제품으로 충분하다(아래).
- [ ] 마감 며칠 전에 세 파일을 한 메일로 보내고 수신 확인을 받는다.

## 종이 시제품 (실물 테스트용, 1~2시간)

정식 3D 프린트 전에 규칙을 검증하는 용도다. 가면 홈의 물리적 시야는 검증하지 못하므로, 아래처럼 "규칙상 시야"를 그대로 흉내 낸다.

1. A3 종이에 `figures/layout_A.png`를 크게 인쇄한다(칸 약 4cm).
2. 생울타리는 접은 두꺼운 종이, 정자는 작은 상자로 만든다.
3. 손님 말은 나무 큐브 16개(또는 지우개)를 쓴다. 윗면에 번호와 화살표 스티커를 붙인다.
4. 문양은 큐브 한 옆면에 색 스티커를 붙이고, 그 위에 종이 차양(ㄷ자로 접은 종이)을 씌운다. 차양 깊이를 폭의 2.5배 정도로 하면 옆 좌석에서 잘 안 보인다.
5. 지목 카드, 초대장 토큰, 오페라 글라스, 오인 토큰은 색종이 조각이나 바둑돌로 대신한다.

## 2차 심사 프로토타입

- 사양과 제작 방법, 검증 항목은 `components/components.md`에 있다.
- 레진 3D 프린트로 손님 말 16개, 생울타리 12개, 정자를 만들고, 검증 항목 1~9를 통과하는지 확인한다.
- 1차 발표(3월 8일) 뒤에 만들어도 시간이 있지만, 가면 홈 치수 검증은 1차 접수 전에 해 두는 것이 안전하다.
