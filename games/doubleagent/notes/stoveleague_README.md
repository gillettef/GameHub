# 스토브리그 — 에이전트의 전쟁 (웹 애플리케이션)

## 개요
선수 에이전트가 되어 5라운드 동안 구단과 계약을 중개하고, 수수료(억 원)를 가장 많이 번 사람이 이기는 멀티플레이 카드게임.

## 기능
- 아이디(닉네임) 등록: 2~12자, 중복 불가, 계정에 저장
- 게임 생성 / 5자리 초대 코드로 참가 (사람 + AI 최대 4명)
- 계정별 전적 저장: 플레이 수, 승리 수, 누적 수수료, 최근 게임
- 우측 상단 "게임 규칙" 버튼

## 게임 규칙 요약
- 매 라운드: 선수 1명 + 구단 1곳 + 연봉 + 수수료율 카드 + (선택) 전략 카드를 제출, 모두 제출하면 동시 공개
- 연봉: 선수 최소 연봉 이상, 구단 예산 이하 (단위: 억)
- 매력도 = 연봉 + 포지션 일치(+2) + 구단 선호 특성(+1) + 전략 카드 + 이벤트 보너스
- 같은 선수 경쟁: 매력도 높은 쪽 승 → 동률이면 수수료율 낮은 쪽 → 무작위
- 수수료 = 연봉 × 수수료율 + 선수 계약 보너스 ± 카드/이벤트 효과 (억)
- 수수료율 카드: 5/10/15/20% 각 2장(총 8장), 제출 시 소멸
- 전략 카드: 4종 중 무작위 3장, 라운드당 1장, 재사용 불가
- 이벤트: 공격수 품귀 / 구단 긴축 / 유망주 열풍 / 빅딜 시즌(최고 연봉 계약 +0.5억)

## 기술 구조
- 단일 HTML 파일 (HTML + CSS + JS)
- Claude 게시 페이지의 런타임 기능 사용: `claude.use("db")`(공유 DB), `claude.use("user")`(사용자 ID)
- DB 구조
  - `games/{CODE}` : 방 상태(참가자, 라운드, 시장, 점수, 카드, 로그)
  - `games/{CODE}/offers/{uid}` : 라운드별 협상 제출
  - `ids/{hex(nick)}` : 아이디 중복 방지
  - `data/users/{uid}/profile` : 계정별 전적
- 라운드 정산은 방장 브라우저가 수행

## 실행 시 주의
이 파일은 Claude에 게시(Publish)된 환경에서만 DB/로그인 기능이 동작합니다.
다른 서버에 배포하려면 `claude.use(...)` 부분을 자체 백엔드(Firebase 등)로 교체해야 합니다.
