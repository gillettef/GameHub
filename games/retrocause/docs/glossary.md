# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

| 용어 | 영문 | 정의 |
|---|---|---|
| 결말 카드 | Ending Card | 게임 시작 시 공개되는 카드. 하나의 사실을 게임 끝까지 고정한다. |
| 결말 대상 | Ending Subject | 결말 카드가 고정하는 대상. 매 게임 3개다. |
| 대상 | Subject | 게임이 상태를 추적하는 사건 요소(성, 왕, 금고, 경비, 성문). |
| 상태 | State | 대상이 가질 수 있는 두 값 중 하나(예: 성의 상태는 멀쩡 또는 불탐). |
| 시작 상태 | Initial State | 시간선의 어떤 원인 카드보다도 앞선 시점에 각 대상이 가지는 상태. |
| 사실 | Fact | 대상과 상태의 조합(예: 성 = 불탐). 결말 카드와 원인 카드의 결과 아이콘이 사실을 만든다. |
| 시간선 | Timeline | 원인 카드를 놓는 칸의 줄. 왼쪽이 과거이고, 결말 카드에 가까운 오른쪽이 나중 시점이다. |
| 칸 | Slot | 시간선에서 원인 카드 1장을 놓는 자리. 왼쪽부터 칸 1, 칸 2…로 센다. |
| 원인 카드 | Cause Card | 플레이어가 시간선에 놓는 카드. 조건 아이콘 0~1개, 결과 아이콘 1개, 인물 아이콘 1개를 가진다. |
| 조건 아이콘 | Condition Icon | 원인 카드가 놓인 칸에서 참이어야 하는 사실. 그 칸의 상태는 그 칸보다 왼쪽의 카드로 정한다. |
| 결과 아이콘 | Effect Icon | 원인 카드가 놓인 칸의 다음 칸부터 오른쪽으로 참으로 만드는 사실. |
| 인물 | Figure | 사건에 등장하는 6명(하인, 왕비, 대신, 경비대장, 궁정 의사, 광대). 인물 아이콘과 비밀 목표 카드가 가리킨다. |
| 인물 아이콘 | Figure Icon | 원인 카드마다 1개씩 있는, 그 원인을 일으킨 인물 표시. |
| 인과 사슬 | Causal Chain | 조건 아이콘과 결과 아이콘으로 연결된 원인 카드들의 연속. |
| 왼쪽 최근 사실 규칙 | Nearest-Left Rule | 어느 칸에서 한 대상의 상태는 그 칸보다 왼쪽에서 가장 가까운, 그 대상에 대한 결과 아이콘을 따른다는 판정 규칙. 그런 결과 아이콘이 없으면 시작 상태다. |
| 모순 | Contradiction | 조건 모순과 결말 모순을 함께 이르는 말. |
| 조건 모순 | Condition Contradiction | 원인 카드의 조건 아이콘이 그 카드의 칸에서 참이 아닌 상태. |
| 결말 모순 | Ending Contradiction | 결말 대상에 대해 시간선에서 가장 오른쪽 결과 아이콘이 결말 카드의 사실과 다른 상태. |
| 모순 카드 | Contradicted Card | 시간선에 놓인 원인 카드 중 조건 모순이나 결말 모순에 해당하는 카드. 연쇄 정리로 버려진다. |
| 연쇄 정리 | Cascade | 가장 왼쪽 모순 카드부터 하나씩 버리고 다시 판정하기를 모순 카드가 없어질 때까지 반복하는 절차. |
| 금지 배치 | Illegal Placement | 놓는 카드 자체가 조건 모순이나 결말 모순이 되는 배치. 허용되지 않는다. |
| 패러독스 토큰 | Paradox Token | 벌점 토큰. 연쇄 정리로 카드가 버려지면 활성 플레이어가 받고, 미해결 결말이 있으면 모든 플레이어가 받는다. |
| 결정 원인 | Decisive Cause | 결과 아이콘이 결말 카드의 사실과 같고 조건 아이콘이 있는 원인 카드 중 시간선에서 가장 오른쪽 카드. 결말 카드마다 최대 1장이다. |
| 미해결 결말 | Unresolved Ending | 게임 종료 시 시간선에 결과 아이콘이 하나도 없고, 시작 상태가 결말 카드의 사실과 다른 결말 대상. |
| 비밀 목표 카드 | Secret Motive Card | 각 플레이어가 비공개로 가지는 카드. 인물 하나를 가리킨다. |
| 비밀 목표 인물 | Secret Motive Figure | 자기 비밀 목표 카드가 가리키는 인물. 플레이어가 몰래 밀어주는 인물이다. |
| 추리 | Deduction | 게임 종료 후 다른 플레이어의 비밀 목표 인물을 몰래 적어 맞히는 절차. |
| 시간 기록관 | Chronicler | 플레이어를 가리키는 테마상의 이름. |
| 시작 상태 카드 | Initial State Card | 대상들의 시작 상태를 표시하는 참조 카드. 칸 1의 왼쪽에 둔다. |
| 활성 플레이어 | Active Player | 지금 차례를 진행하는 플레이어. |
| 놓기 | Place | 원인 카드 1장을 시간선의 빈 칸에 놓고, 연쇄 정리 후 원인 카드 덱에서 1장을 가져오는 차례 행동. |
| 교체 | Exchange | 원인 카드 1장을 버림 더미에 버리고 원인 카드 덱에서 1장을 가져오는 차례 행동. |
| 패스 | Pass | 아무 행동 없이 차례를 마치는 행동. 시간선에 빈 칸이 없거나 원인 카드 덱이 비어 있을 때만 할 수 있다. |
| 원인 카드 덱 | Cause Deck | 뒷면이 위로 쌓인 원인 카드 더미. 놓기와 교체 때 여기서 카드를 가져온다. |
| 버림 더미 | Discard Pile | 교체나 연쇄 정리로 버린 원인 카드를 앞면이 위로 쌓는 더미. 다시 섞지 않는다. |
| 시작 플레이어 | Start Player | 첫 차례를 하는 플레이어. 종료 라운드의 끝을 정하는 기준이다. |
| 라운드 | Round | 시작 플레이어부터 시계 방향으로 모든 플레이어가 차례를 한 번씩 하는 단위. |
| 종료 라운드 | Final Round | 종료 조건이 처음 만족된 라운드. 이 라운드가 끝나면 게임이 끝난다. |
