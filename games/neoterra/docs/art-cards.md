# 카드 일러스트 스타일 가이드

카드마다 한 장씩 그리는 일러스트의 공통 규칙이다. 여러 작업자가 나눠 그려도 한 벌처럼 보여야 한다. 아트 키트 전체는 `docs/art.md`.

## 파일

- 경로: `src/client/assets/art/<카드 id>.svg` (id 는 `src/engine/data/*` 의 정의 id 그대로. 예: `p1a.svg`, `q2t3.svg`, `pa5.svg`, `sa10.svg`, `f_beacon.svg`, `e_ark.svg`)
- **viewBox `0 0 222 122`** (카드 프레임의 그림 창 x14–236, y66–188 과 같은 비율 1.82:1). `width`/`height` 속성은 넣지 않는다.
- 그림은 viewBox 전체를 채운다(바깥 여백 없음). 화면이 창 모양(후원자·유산은 아치형)으로 잘라 쓰므로 **중요한 형체는 가운데 70% 안**에 둔다.
- 한 파일 **6KB 이하**. 래스터·외부 참조·`<script>`·`<foreignObject>`·`<text>` 금지.
- `id` 는 파일마다 겹치지 않게 **`a-<카드 id>-` 접두어**(예: `a-p1a-sky`). 한 화면에 여러 장이 인라인될 수 있다.
- 색은 SVG 안에 HEX 로 직접 쓴다(아트 파일은 토큰 규칙 예외). CSS 변수에 의존하지 않는다.

## 화풍

- **평면 벡터 + 2~3단 명암**(그라데이션은 하늘·빛 번짐 정도만). 실루엣이 또렷하게, 작은 크기(카드 폭 88~150px)에서도 무엇인지 읽혀야 한다.
- 구도: 원경(하늘·고리 행성·별) → 중경(지형·도시) → 근경(주제 실루엣). 주제는 하나.
- 세계관: 지구를 떠난 개척민이 정착한 낯선 행성. 밤하늘 남색, 고리 행성, 두 개의 위성, 생물발광 숲, 포자 안개, 기계 도시. 사람은 작은 실루엣이나 뒷모습(얼굴 묘사 없음).
- **오리지널**: 문명 비욘드 어스 등 기존 게임·영화의 디자인·로고·캐릭터를 닮게 그리지 않는다.

## 팔레트 (`src/client/styles/tokens.css` 와 맞춤)

| 쓰임 | 색 |
|---|---|
| 밤하늘 | `#0a0f1f` `#10172b` `#161f38` `#1f2a48` |
| 별·빛 | `#e9edf8` `#f4c56a`(별빛 호박) |
| 방주(지구·질서·금속) | `#9cc2ff` `#dfe9ff` |
| 공생(토착 생물·생물발광) | `#3fe3b8` `#b6ff7a` |
| 합성(기계·회로) | `#ff6cb0` `#ff9a4a` |
| 위협·위험 | `#ff7a7a` |
| 자원 | 식량 `#a3e06c` · 생산 `#e7a768` · 에너지 `#ffe36b` · 과학 `#74bdff` · 문화 `#e595ff` |

- 카드의 성격에 맞는 강조색 1~2개 + 밤하늘 바탕. 노선 성향이 있는 카드(후원자, 퀘스트 보상 등)는 그 노선색을 강조색으로.
- 위협형 퀘스트는 빨강 계열 강조, 판정형은 하늘, 경쟁형은 주황, 주둔지 제안은 보라(`#b996ff`), 결실·종료는 금(`#ffd67a`).
