# 2027 코리아보드게임즈 공모전 검토 — SmilePark

> 2026-10-14 작성. 세 프로젝트(MagicAcademy·Rootbound·SmilePark)를 공모전 기준으로 비교한 결과 중 SmilePark 부분이다.
> **결론: 이번 공모전에는 비추천(가중 점수 2.7 / 5, 셋 중 2위지만 준비도가 가장 낮음).** 오프라인 설계 원칙은 가장 탄탄하지만 핵심 수치가 미확정이고 장르가 붐빈다. 다음 공모전을 목표로 계속 다듬는다.
> 이 문서는 **규칙이 아니다.** 현재 구현 룰은 `design-v1.md`, 할 일 우선순위는 `CLAUDE.md` "다음 작업 최우선 과제".

## 1. 공모전 요약

- 공고: https://www.koreaboardgames.com/magazine/menuDetail?boardCd=news&postNo=948
- **1차 접수: 2026-10-09 ~ 12-31 24시** (이메일 또는 당일 소인 우편). 1차 결과 2027-03-08, 2차 심사(실물 프로토타입 지참) 후 최종 발표 2027년 5월.
- **1차 제출물**: 신청서(자필 서명) + **기획안(첨부 양식, A4 2쪽 이내, 2쪽에 게임 진행 사진 1~2장)** + **규칙서(분량 자유, pdf/doc/ppt/hwp)**. 1차는 기획안·규칙서만으로 심사한다.
- **선정 기준**: 순수 창작 / **지나치게 복잡하지 않고 재미있는 게임** / 규칙 허점 없고 균형 / 반복해서 할 만큼 매력적.
- 규칙서를 읽고 이해할 수 없으면 심사 불가 → **게임을 모르는 사람에게 읽혀 확인하라**고 권장.
- 시상: 우수작 상금 100만 원 + 계약금 200만 원(독점 제품화 계약 필수), 가작 30만 원. 응모 편수 제한 없음.

## 2. 평가 (5점 만점, 가중치는 공모전 기준에서 임의 설정)

| 기준 (가중치) | 점수 | 근거 |
|---|---|---|
| 복잡도·진입 장벽 (25%) | 2.5 | 5단계 라운드(준비·건설·홍보·운영·관리), 비공개 입찰, 그룹 배치·정원, 수리·쓰레기 토큰, 인력 5종 Lv 트랙 |
| 규칙 완성도·밸런스 (20%) | 2 | design-v1 13절 수치·관객 그룹 28장·특수효과가 **모두 임시값(사용자 미확정)**. 점수 150~170점, 잔액 $25~30, 약한/강한 카드, 연구원·건설 AI 약함(balance-report) |
| 재미·리플레이성 (20%) | 3 | 입찰 심리전·배치 고민이 핵심이나 사람 테스트 0회 |

| 독창성 (10%) | 2 | 놀이공원 경영 장르가 붐빈다. 특히 **Meeple Land**(관객 그룹을 놀이기구에 배치), Unfair, Coaster Park 등과 구조가 겹쳐 차별점 설명이 필요 |
| 상품성 (10%) | 3 | 가족 친화 테마. 시설 50 + 그룹 28 + 운영 16장 + 돈·토큰·개인 보드로 구성물이 많다 |
| **가중 합계** | **2.7** | Rootbound 3.8, MagicAcademy 2.6 |

## 3. 핵심 문제

1. **수치 미확정**: 규칙서를 쓰려면 CLAUDE.md 과제 1(사용자 확정)이 먼저다.
2. **점수 규모**: 150~170점은 오프라인 토큰 계산에 부적합(과제 2).
3. **경제 구조**: 후반 돈이 남아 의미 있는 선택이 줄어든다(과제 3).
4. **차별점**: 기존 놀이공원 게임과 다른 핵심 재미 한 줄이 없다. 기획안 2쪽 안에서 설득하기 어렵다.
5. **준비 기간**: 커밋 12개, v1 규칙이 2026-10-07에 막 들어왔다. 사람 테스트가 없다.
6. 플레이 시간 60~90분(v1)은 "지나치게 복잡하지 않은" 기준에 불리하다.
