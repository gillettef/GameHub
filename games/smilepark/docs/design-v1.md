# 구현 룰 v1 (오프라인 보드게임 기준)

v0을 **"테이블에서 종이·토큰만으로 막힘없이 플레이할 수 있는가"**를 기준으로 다시 설계한 규칙이다. 앱은 같은 규칙을 자동으로 처리할 뿐이다. 규칙의 정의는 이 문서 한 곳에 둔다(`docs/cards.md`는 카드 목록, `docs/balance-report.md`는 수치 근거).

- 진실의 원천은 코드다. 룰 상수는 `src/engine/engine.ts`의 `CFG`, 카드 인쇄값 변환은 `src/engine/data/cards.ts`의 `PRINT`·`EFFECTS`, 관객 그룹은 `data/groups.ts`, 운영카드는 `data/events.ts`. 괄호 안 영문이 해당 키다.
- 시설 원본 수치(`notes/놀이공원_v1.xlsx`)는 수정하지 않는다. 원본을 **카드에 인쇄되는 값**으로 한 번 변환해 쓴다.

## 0. 설계 원칙
1. **카드에 적힌 숫자를 그대로 쓴다.** 나눗셈·환산 공식이 없다.
2. **계산은 한 자리 덧셈과 작은 곱셈까지.** 한 사람의 라운드 정산이 1분 안에 끝난다.
3. **확률 판정이 없다.** 고장·쓰레기는 조건이 맞으면 토큰을 올려놓는다.
4. **따로 적어 둘 숨은 값이 없다.** 모든 상태가 테이블 위 카드·토큰으로 보인다.
5. **단계마다 의미 있는 결정이 하나씩 있다.** 놀이기구는 만족도, 상점은 돈, 부대시설은 매 라운드 효과로 역할이 나뉜다.

## 1. 개요
- 인원: 2~5인. 디지털은 사람·AI를 섞어 2~5인(`minPlayers`·`maxPlayers`). 한 기기 돌려 하기·온라인 대전 가능(2026-11-25). 사람이 여럿이면 입찰·운영·관리는 각자 동시에 한다.
- **8라운드**(`rounds`). **만족도**(점수)가 가장 높은 공원이 이긴다. v0의 "만족도 → VP 환산"은 없앴다. 만족도 토큰이 곧 점수다.

## 2. 구성요소
| 구성 | 수량 | 내용 |
|---|---|---|
| 시설카드 | 50장 | 놀이기구 30 · 상점 5 · 부대시설 15. 인쇄값은 3절 |
| 관객 그룹 카드 | 28장 | 그룹 이름, 어린이 수, 성인 수, 지불 한도($1~$3), 취향(놀이기구 7유형). 취향마다 4장 |
| 운영카드 | 16장 | 라운드마다 1장 적용, 다음 라운드 카드도 공개 |
| 개인 보드 | 인원수 | 부지 6칸(`slots`), 인력 트랙 5종(Lv 0~3), 입장료 다이얼($0~$3) |
| 토큰 | - | 돈 $1/$2/$5, 만족도 1/5(점수 트랙으로 대체 가능), 수리 토큰, 쓰레기 토큰, 선 플레이어 마커 |

## 3. 카드에 인쇄되는 값
변환 규칙은 데이터를 만들 때 한 번만 적용한다. 플레이어는 결과 숫자만 본다. 카드별 값은 `docs/cards.md`에 있다.

| 카드 | 인쇄값 | 변환 규칙 (`PRINT`) |
|---|---|---|
| 공통 | 건설비, 유지비 | 건설비 = 원본(최소 $2), 유지비 = 원본 |
| **놀이기구** | **정원**(명), **대상**(어린이 / 성인 / 모두), **1명당 만족도**, 야외/실내, 특수효과 | 정원: 원본 건설비 7↑ 4명, 3↑ 3명, 그 외 2명. 대상: 원본 어린이·성인 만족도 차이가 3 이상이면 그쪽 전용. 1명당 만족도: 전용 3, 모두 2 |
| **상점** | 입장 그룹 1개당 수익 **$2**, 특수효과 | - |
| **부대시설** | 매 라운드 효과 1줄 | 원본 문구 재해석(`EFFECTS`) |

- 야외 = 스릴형·패밀리형·어드벤처형·물놀이형·놀이형, 실내 = 공포형·교육형.

## 4. 준비
1. 각자 개인 보드, 인력 모두 Lv 0, 입장료 다이얼 $2.
2. 1라운드 선 플레이어를 무작위로 정한다. **시작 자금은 선 플레이어 $10, 시계 방향으로 한 자리마다 +$1**(`startMoney` 10, `seatMoney` 1).
3. 시설 덱, 관객 그룹 덱, 운영카드 덱을 각각 섞는다.

## 5. 라운드 진행
라운드는 **준비 → 건설 → 홍보 → 운영 → 관리** 순서다. 선 플레이어는 라운드마다 시계 방향으로 한 칸씩 넘어간다.

### 5.0 준비
- 운영카드를 넘겨 **이번 라운드 카드**로 놓고, 1장을 더 펼쳐 **다음 라운드 카드**로 공개한다. 다음 라운드에는 그 카드가 이번 라운드 카드가 된다.
- 지난 라운드 시장에 남은 시설 카드를 버리고, **(인원 + 2)장**(`marketExtra` 2)을 새로 깐다. 시설 덱이 비면 지어지지 않은 카드를 모두 섞어 새 덱으로 쓴다.
- 운영카드가 **정전**이면, 각 공원의 정원이 가장 큰 놀이기구 1곳(같으면 왼쪽 칸)에 수리 토큰을 놓는다.

### 5.1 건설
선 플레이어부터 시계 방향으로 차례마다 **시설 1장을 짓거나 "건설 마치기"**를 한다.
- 라운드당 최대 **2장**(`buildsPerRound`)까지 짓는다. 2장을 지었거나 마친 플레이어는 이번 라운드 건설에서 빠진다.
- 건설비를 내고 부지 1칸에 놓는다. 이미 시설이 있는 칸에 지으면 기존 시설은 환불 없이 철거된다.

### 5.2 홍보
1. **관객 줄 공개**: 관객 그룹 카드를 **인원 × 3장**(`rowPerPlayer`) 앞면으로 깐다. 그룹 덱이 비면 줄에 없는 카드를 모두 섞어 새 덱으로 쓴다.
2. **비공개 입찰**: 관객 줄을 보고 각자 낼 홍보비를 손에 쥐고 동시에 공개한다. 낸 돈은 은행으로 간다($0도 가능).
3. **모집**: 홍보비를 많이 낸 순서로 1장씩 번갈아 그룹을 가져간다.
   - 동점이면 **선 플레이어에서 먼 공원부터** 가져간다. 건설을 늦게 한 쪽에 주는 보상이다(`bidTieLate`).
   - 가져올 수 있는 수는 **2그룹**(`baseGroups`) + 마케팅 전문가 Lv + 이벤트 보정이다.
   - 그만 가져와도 된다. 남은 카드는 라운드가 끝나면 버린다.

### 5.3 운영
1. **입장료**: 입장료 다이얼을 1인 기준 **$0~$3**(`maxFee`)로 맞춘다. 지불 한도가 입장료보다 낮은 그룹은 입장하지 않는다(카드를 버린다).
2. **배치**: 입장한 그룹 카드를 놀이기구 카드 위에 올린다.
   - 놀이기구 1곳에는 **그룹 1개만** 올린다.
   - **그룹 인원이 정원보다 많으면 올릴 수 없다.** 안내 직원 Lv(또는 정보 안내 센터)만큼 "정원 +1명" 배치를 쓸 수 있다.
   - 수리 토큰이 있는 놀이기구에는 올릴 수 없다.
3. **만족도**(놀이기구 1곳마다 계산)
   > 만족도 = **1명당 만족도 × 대상 인원** + **취향 일치 2**(`favBonus`, 그룹의 취향 = 놀이기구 유형) + 특수효과 + 운영카드 보정
   - 대상 인원: "모두"면 그룹 전체, "어린이"면 어린이 수, "성인"이면 성인 수.
   - 놀이기구에 올리지 못한 입장 그룹 1개당 **만족도 −1**(`unplacedSat`).
   - 부대시설의 매 라운드 만족도와 연구원 보너스를 더한다.
   - 합계만큼 만족도 토큰을 받는다.
4. **돈**
   > 돈 = **입장료 × 입장 인원** + **상점마다 $2 × 입장 그룹 수** + 부대시설 수익 − **모든 시설의 유지비**
   - 유지비를 다 내지 못하면 모자란 $1마다 만족도 −1을 하고 돈은 $0이 된다.
5. **토큰 놓기**(확률 없음)
   - **그룹 인원이 정원과 같은(꽉 찬) 놀이기구에 수리 토큰 1개.** 정원 +1명 배치도 꽉 찬 것으로 본다.
   - **돈을 번 상점마다 쓰레기 토큰 1개**, 그리고 운영카드의 추가 쓰레기를 놓는다.

### 5.4 관리
1. **무료 처리**: 엔지니어 Lv + 부대시설만큼 수리 토큰을 떼고, 환경 미화원 Lv × 2 + 부대시설만큼 쓰레기 토큰을 치운다.
2. **유료 처리**: 수리 토큰 1개당 **$2**(`repairCost`), 쓰레기 1개당 **$1**(`cleanCost`). 원하는 만큼 한다.
3. **인력 고용**: 라운드당 **1명**, 해당 인력 Lv을 1 올린다. 고용비는 모든 인력이 같다(`hireCosts`): Lv1 $3 · Lv2 $5 · Lv3 $7.
4. **라운드 종료**: 남은 쓰레기 토큰 1개당 **만족도 −1**. 치우지 않은 쓰레기는 남아서 다음 라운드에도 감점된다.

## 6. 인력 (Lv당, 최대 Lv 3)
| 인력 | 효과 |
|---|---|
| 마케팅 전문가 | 관객 모집 +1그룹 |
| 안내 직원 | 정원 +1명 배치 1회 |
| 엔지니어 | 관리 단계에 수리 토큰 1개 무료 제거 |
| 환경 미화원 | 관리 단계에 쓰레기 2개 무료 청소 |
| 연구원 | 매 라운드 만족도 +1(`researchSat`) |

## 7. 운영카드와 특수효과
### 7.1 운영카드 16장
효과는 "아이콘 하나 + 숫자 하나" 수준이다. 놀이기구 보정은 **그룹 1개 배치마다** 적용한다.

| 종류 | 카드 |
|---|---|
| 날씨 | 맑은 날씨(야외 +1) · 비 오는 날(야외 −1, 실내 +1) · 눈 오는 날(야외 −1, 상점 +$1) |
| 유형 테마(+2) | 가족의 날(패밀리) · 할로윈 축제(공포) · 여름 물놀이 축제(물놀이) · 불꽃놀이 야간 개장(스릴) · 탐험 주간(어드벤처) · 과학의 날(교육) · 어린이날(놀이) |
| 전체 | 봄 축제(모든 놀이기구 +1) · 가수 공연(상점마다 +$2) |
| 관객 | 인플루언서 방문(모집 +1) · 할인 쿠폰(모집 +1, 입장료 최대 $1) |
| 사고 | 정전(정원이 가장 큰 놀이기구에 수리 토큰) · 쓰레기 대란(운영 후 쓰레기 +2) |

카드의 **아이콘**(맑음·악천후·야간·축제·가족·할로윈·여름·탐험·학습·어린이날)에 시설 특수효과가 반응한다. 카드별 아이콘은 `docs/cards.md`에 있다.

### 7.2 시설 특수효과
| 종류 | 적용 | 예 |
|---|---|---|
| 아이콘 반응 | 놀이기구: 배치마다 / 상점: 매 라운드 | 바이킹 "야간 때 만족도 +2", 편의점 "야간 때 수익 +$2" |
| 취향 보너스 추가 | 취향 일치 그룹 배치 시 | 자이로드롭 "취향 일치 보너스 +2 추가" |
| 그룹 구성 | 어린이·성인이 함께 / 어린이가 있는 그룹 | 미니 기차 "어린이·성인이 함께 온 그룹 +2" |
| 수리 면제 | 수리 토큰을 받지 않음 | 스윙 세트 |
| 부대시설 고정 효과 | 매 라운드(수리 토큰과 무관) | 멋진 조형물 "만족도 +2", 넓은 주차장 "입장 그룹 1개당 $1", 깨끗한 화장실 "쓰레기 2개 무료 청소" |

## 8. 종료와 승리
- 8라운드 관리 단계가 끝나면 끝난다.
- **남은 돈 $5마다 만족도 +1**(`moneyPerVp`). $5 화폐 1개가 만족도 1이다.
- 만족도가 가장 높은 공원이 이긴다. 같으면 남은 돈이 많은 쪽, 그것도 같으면 공동 승리.

## 9. 예시: 한 공원의 운영
상황
- 운영카드: **맑은 날씨**(야외 놀이기구 +1)
- 내 부지: 바이킹(스릴형·야외, 정원 3, 성인 3, 유지 $2), 회전목마(패밀리형·야외, 정원 3, 어린이 3, 유지 $1), 빠른 스낵바(상점, 그룹당 $2, 유지 $1). 인력 없음.
- 데려온 그룹: 커플(성인 2, $3, 스릴형), 가족(어린이 2·성인 2, $2, 패밀리형), 형제자매(어린이 2, $2, 놀이형)

진행
1. 입장료 $2 → 세 그룹 모두 입장(지불 한도 3·2·2). 입장 인원 8명 → **$16**.
2. 배치
   - 커플 → 바이킹: 3 × 성인 2 + 취향 2 + 맑음 1 = **9**. 2명 < 정원 3이라 수리 토큰 없음.
   - 형제자매 → 회전목마: 3 × 어린이 2 + 맑음 1 = **7**.
   - 가족(4명)은 정원 4인 놀이기구가 없어 못 탄다 → **−1**.
3. 상점: 입장 3그룹 × $2 = **$6**, 쓰레기 토큰 1개.
4. 정산: 돈 16 + 6 − 유지비 4 = **+$18**. 만족도 9 + 7 − 1 = **+15**.
5. 관리: 쓰레기 1개를 $1로 치우거나, 남겨서 만족도 −1.

생각해 볼 점: 다음에는 정원 4 놀이기구를 짓거나 안내 직원을 고용하면 가족도 태울 수 있다. 단, 가족을 정원 4에 태우면 꽉 차서 수리 토큰을 받는다.

## 10. 단계별 핵심 결정
| 단계 | 고민 |
|---|---|
| 준비 | 다음 라운드 운영카드를 보고 미리 대비할지 |
| 건설 | 남이 노리는 카드를 먼저 살지, 내 공원 구성(정원·대상·유형)을 맞출지, 2장째를 지을지 아낄지 |
| 홍보 | 관객 줄을 보고 얼마를 쥘지. 상대 수를 읽는 심리전, 동점 순서 |
| 운영 | 입장료를 올려 돈을 벌지, 낮춰 그룹을 더 들일지(상점 수익). 정원을 꽉 채워 만족도를 올릴지, 여유를 둬 수리 토큰을 피할지 |
| 관리 | 고칠지, 치울지, 사람을 뽑을지(라운드당 1명) |

## 11. FAQ
- **그룹 일부만 놀이기구에 태울 수 있나?** 없다. 그룹은 나뉘지 않는다.
- **입장하지 않은 그룹은?** 입장료도, 감점도 없다. 카드를 버린다.
- **수리 토큰이 있는 놀이기구도 유지비를 내나?** 낸다. 부대시설 효과는 수리 토큰과 무관하다(부대시설은 수리 토큰을 받지 않는다).
- **상점에도 수리 토큰이 놓이나?** 아니다. 상점은 쓰레기 토큰만 만든다.
- **마지막 라운드에 수리할 필요가 있나?** 없다. 쓰레기는 종료 감점이 있으니 치우는 것이 낫다.
- **만족도가 음수가 될 수 있나?** 있다(쓰레기·미배치·유지비 부족).

## 12. v0 → v1 바뀐 점
| v0 | v1 |
|---|---|
| 건설 단계에서 시설·인력·축제를 1행동씩 | 건설 = 시설만(라운드당 2장), 인력 = 관리 단계(라운드당 1명), 축제 삭제 |
| 관객 1명 카드, 놀이기구 2곳 + 상점 1곳 자동 동선(선택 점수 공식) | 관객 **그룹** 카드, 놀이기구 1곳에 1그룹 **직접 배치** |
| 수익 ÷2.5 올림, 건설비로 정하는 수용 구간, 시설 가치 공식 | 카드 인쇄값 그대로(정원·대상·1명당 만족도, 상점 그룹당 $2) |
| 고장 20%·쓰레기 50% 확률 | 정원 만석 → 수리 토큰, 상점 → 쓰레기 토큰 |
| 만족도 8 = VP 1, 풀 이월, 0 하한 | 만족도 = 점수 |
| 선 순서 고르기, 인원별 좌석 자금 표 | **비공개 입찰** 순서 고르기(동점은 늦은 순서 우선), 좌석마다 +$1 |
| 이벤트 태그 13종, 매 라운드 1장 | 아이콘 10종, 다음 라운드 카드 미리 공개 |
| 쓰레기 2개마다 VP −1, 적자 $2마다 VP −1, 잔액 $6마다 VP +1 | 쓰레기 1개마다 −1, 모자란 $1마다 −1, 잔액 $5마다 +1 |

## 13. 사용자 확인이 필요한 임시 결정
- 수치: 라운드 8, 시작 $10 + 좌석당 $1, 건설 라운드당 2장, 관객 줄 인원 × 3, 기본 모집 2그룹, 입장료 최대 $3, 취향 일치 +2, 미배치 −1, 수리 $2, 청소 $1, 고용비 $3/$5/$7, 연구원 +1, 잔액 $5 = 1.
