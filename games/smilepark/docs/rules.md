# 룰 정리 (개정 pptx 기준, 최신)

> 출처: `notes/놀이공원.pptx`(저장소에서 삭제, git 이력에 있음). **슬라이드 9~14(준비/진행/종료)에는 단계 이름만 있고 상세 규칙 텍스트가 없다.**
> 빈 부분은 현재 구현 룰 `docs/design-v1.md`가 채웠다(오프라인 보드게임 기준으로 v0을 재설계). 이 문서는 pptx 원문 정리와 "pptx 항목 → 현재 구현" 대응만 담고, 규칙의 정의는 design-v1.md 한 곳에 둔다.

## 1. 개요
- **2~5인** 경영 보드게임. 가장 많은 VP(현재 구현: 만족도)를 얻는 것이 목표 (v1: 60~90분).
- 디지털 구현: 사람 0~1명 + AI, 전체 2~5인. 한 기기 다인(핫시트) 미지원.

## 2. 구성요소 (슬라이드 4~8)
- 메인 보드, 개인 보드(관객·시설·운영 3구역)
- 관객카드(덱), 시설카드, 운영카드
- 토큰: 수리 토큰, 쓰레기 토큰
- 돈: $1 / $2 / $5, VP: 1 / 5
- **관객 트랙**: 입구 → $0 $1 $2 $3 $4 칸, 관객카드가 칸에 배치됨(덱에서 보충)
- **인력 트랙**: 엔지니어 / 마케팅 전문가 / 환경 미화원 / 안내 직원 / 연구원 (메인보드에도 존재)
- 시설카드 예시: 롤러코스터 — 건설비 10, 유지비 3, 수익 3/7(어린이/성인), 만족도 1/7, 특수효과 "날씨 나쁠 때 유지비 +2"

## 3. 진행
- 턴: **건설 → 홍보 → 운영 → 관리** (pptx는 단계 이름만 있음). 현재 구현은 design-v1.md 5절.

## 4. pptx 항목 → 현재 구현 (design-v1)
pptx만으로는 정해지지 않아 정한 값이다. **모두 사용자 확정 필요**(design-v1.md 13절).

| # | pptx 항목 | 현재 구현 (design-v1.md) |
|---|---|---|
| 1 | 관객카드 | **관객 그룹 카드** 28장(어린이·성인 수, 지불 한도 $1~$3, 취향). 2절 |
| 2 | 관객 트랙 $0~$4 | 관객 줄(공개) + **비공개 입찰**로 모집 순서 결정, 1인 입장료 다이얼 $0~$3. 5.2·5.3절 |
| 3 | 개인 보드 관객·시설·운영 | 부지 6칸에 시설, 놀이기구 위에 그룹 카드를 직접 배치. 5.3절 |
| 4 | 인력 트랙 | Lv 0~3 개인 트랙, 관리 단계에 라운드당 1명 고용, 고용비 $3/$5/$7. 6절 |
| 5 | 수리/쓰레기 토큰 | 정원을 꽉 채운 놀이기구 → 수리 토큰(운영 불가), 돈을 번 상점 → 쓰레기 토큰(남으면 1개당 −1). 확률 없음 |
| 6 | 운영카드 | 공용 이벤트 16장, 다음 라운드 카드 미리 공개. 7절 |
| 7 | VP 1/5 토큰 | **만족도 토큰 = 점수**(VP와 같은 것), 종료 시 잔액 $5마다 +1. 8절 |
