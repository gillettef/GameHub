# 디자인 결정 기록

## 절차
1. `docs/decisions.md`를 읽고 마지막 결정 번호를 확인한다.
2. 같은 주제의 기존 결정이 있는지 찾는다.
   - 있으면 기존 항목은 지우지 않는다. 상태를 `폐기`로 바꾸고 `→ D-0XX로 대체`를 덧붙인다.
3. 다음 번호로 새 항목을 맨 아래에 추가한다.
4. 결정이 용어를 새로 만들면 `docs/glossary.md`에도 추가한다.
5. 결정이 `docs/concept.md`의 열린 질문을 해결하면 해당 체크박스를 `[x]`로 바꾸고 결정 번호를 적는다.

## 항목 형식
```
## D-0XX 짧은 제목
- **날짜:** YYYY-MM-DD
- **상태:** 확정 | 가안 | 폐기
- **결정:** 무엇을 정했는지 한두 문장
- **이유:** 왜 그렇게 정했는지
- **대안:** 검토했지만 고르지 않은 선택지 (있으면)
- **근거:** 플레이테스트 기록이나 분석 링크 (있으면)
```

## 상태 기준
- **확정:** 사용자가 명시적으로 동의한 결정
- **가안:** 일단 진행하지만 플레이테스트로 검증이 필요한 결정
- **폐기:** 대체되었거나 철회된 결정

사용자 동의 없이 `확정`으로 기록하지 않는다.
