# 검은 왕관 — 비주얼 디자인

2026-11-26. 규칙은 `../docs/design.md`, 화면 배치 기준은 `docs/refactor-plan.md` 4·5절(iPhone 17 Pro 402×874, ①~⑤).

## 방향

**흑요석 탁자 위의 양피지 카드.** 이 게임의 중심은 "지금은 내 힘, 결말에는 마왕의 힘"이라는 이중성이다. 그래서 재질 두 가지로 화면 전체를 나눈다.

| | 빛 면 | 어둠 면 |
|---|---|---|
| 재질 | 양피지(결 있는 미색 종이) + 금박 | 흑요석(비스듬한 반사 한 줄) + 보랏빛 먹 |
| 쓰는 곳 | 운명 카드, 아이템 빛 면, 주 버튼, 명성 | 그림자 카드, 아이템 어둠 면, 마왕의 묘지, 그림자 값, 마왕 |
| 빛 | 촛불(행동 토큰, 내 차례, 갈 수 있는 칸) | 보라 번짐(그림자를 얻는 선택지) |

- 판·바탕은 흑요석, 손에 쥐는 것(카드·아이템)은 양피지. 손패에서 **그림자 카드만 검다.** 어둠을 손에 쥐었다는 것이 한눈에 보인다.
- 금박과 보라가 같은 화면에 나란히 설 때가 선택의 순간이다. 전투 시트의 족보 목록에서 금박 줄(삼연)과 보라 줄(그림자로 만든 사방)이 붙어 있는 것이 대표 예.
- 마왕의 묘지는 어느 화면에서나 보라색 숫자로 늘 보인다. 큰 족보를 쓸 때마다 이 숫자가 커진다.
- 대관식에서 이 대비가 뒤집힌다: 화면이 한 박자 양피지빛으로 밝아졌다가(빛의 절정), 왕관이 떨어진 자리에서 흑요석이 번진다.

흉내 내지 않은 것: 포커 문양(♠♥♦♣), 특정 게임의 외형, 유리질감·네온. 문양 4종은 직접 그린 SVG 다(방패는 왼쪽이 비고 오른쪽이 찬 반반 무늬로 빛/어둠을 담았다).

## 색

`tokens.css` 에 모두 있다. 1부는 공통 UI 가 읽는 `--gh-*` 덮어쓰기, 2부는 게임 전용 `--bc-*`.

- 바탕: `--bc-obsidian` → `--bc-basalt`(상태바·손패·행동 줄) → `--bc-slate`(눌림) → `--bc-seam`(선).
- 양피지: `--bc-vellum`, `--bc-vellum-2`, 글자는 `--bc-ink`.
- 금박: `--bc-gilt`(선), `--bc-gilt-hi`(어두운 바탕 위 강조 글자), `--bc-gilt-leaf`(주 버튼·전설 카드 테두리 그라데이션).
- 촛불: `--bc-candle` — 행동 토큰과 "내 차례/갈 수 있음"에만 쓴다. 다른 곳에 쓰지 않아야 촛불이 신호로 읽힌다.
- 그림자: `--bc-umbra`, `--bc-umbra-hi`(글자), `--bc-umbra-deep`(바탕). 어둠 면 효과의 핵심어는 `--bc-ember`.
- 문양: 어두운 바탕 위 `--bc-blade/ward/lantern/coin`, 양피지 위 `--bc-*-ink`(대비 4.5:1 이상). 컴포넌트에서는 `.bc-suit--blade` 같은 클래스가 `--suit`(양피지 위)·`--suit-lit`(어두운 바탕 위)를 정해 준다.
- 상태색: 연합 체력은 빨강(`--bc-hp`), **마왕 체력은 보라**(`.bc-hpbar--demon`). 두 막대가 섞이면 안 된다.
- 자리 색 5개는 `components.css` 의 `--bc-seat-1..5`.
- 테마는 어두운 한 가지뿐이다(공통 `theme.css` 가 `color-scheme: dark`).

## 글자

외부 폰트를 쓰지 않는다(서버 상대경로 규칙·오프라인).

- `--bc-font-display`: 구식 세리프(Iowan Old Style → Palatino → Georgia → 한글 명조). 카드 숫자, 족보 이름, 제목, 점수.
- `--bc-font-body`: 공통 고딕 스택. 그 밖의 모든 글자.
- iOS 에는 기본 한글 명조가 없어서 한글 제목은 고딕으로 떨어진다. 숫자·로마자만 세리프가 되는데, 카드 숫자가 핵심이라 이것으로 충분하다. 한글 제목까지 명조로 하고 싶으면 OFL 폰트(예: Noto Serif KR)를 쓰는 글자만 woff2 로 잘라 `public/` 에 넣고 **상대경로**로 `@font-face` 를 건다.
- 크기: 본문 14 이상(`--bc-text-sm`). 12px(`--bc-text-xs`)은 카드 위 보조 표기와 자리 칩 숫자에만.
- 숫자가 줄 맞춰 바뀌는 곳(체력, 골드, 점수)은 `font-variant-numeric: tabular-nums`(`.bc-num`).

## 간격·모양

- 4px 격자(`--bc-space-1..5`). 화면 좌우 여백 12~16.
- 반경은 역할마다 다르다: 돌판 타일 3, 종이 카드 7, 버튼 10, 아래 시트 22. 모든 것에 같은 둥근 모서리를 주지 않는다.
- 누르는 대상은 44×44 이상. 보드는 육각 판 지도(`src/client/Board.tsx`)라 칸이 작게 그려지는 화면(휴대폰)에서는 미니맵으로 보이고, 누르면 그 자리를 확대한다(칸 지름 약 32px, 누르면 가장 가까운 칸). 확대 중엔 끌어서 옮기고 '전체 보기'로 돌아간다. 넓은 화면(폭 960px 이상)은 두 칸 배치: 왼쪽에 보드를 화면 높이 전체로, 오른쪽 440px 에 ①②④⑤(`game.css` 맨 끝).
- 카드 크기는 `--bc-card-w` 하나로 정하고 안쪽은 em 비례다(손패 54~62, 시트 56~64, 상세 112). 아이템도 `--bc-item-w` 하나(본문이 14px 가 되는 168 권장).

## 모션

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--bc-dur-tap` | 120ms | 버튼 누름 |
| `--bc-dur-move` | 260ms | 카드 들기, 말 이동, 시트 열기 |
| `--bc-dur-flip` | 560ms | 아이템 빛→어둠 뒤집기 |
| `--bc-dur-bot` | 600ms | 봇 행동 간격(design.md 18절) |
| `--bc-dur-crown` | 2400ms | 왕관 맴돌기 |

- 늘 움직이는 것은 행동 토큰 촛불의 흔들림(`bc-flicker`) 하나뿐이다. 그 밖의 움직임은 모두 사람의 행동이나 상태 변화에 대한 답이다.
- 오래 보여 주는 연출은 대관식 하나다(약 13초, `05-coronation.html`). "건너뛰기"를 늘 둔다.
- `prefers-reduced-motion: reduce` 이면 토큰 길이가 1ms 가 되고 흔들림·왕관·번짐 애니메이션이 꺼진다.

## 구현할 때 지킬 것

1. **불러오는 순서**: `@gamehub/ui` 의 `theme.css` → `design/tokens.css` → `design/components.css`. Tailwind 유틸리티와 함께 써도 된다(`bc-` 접두어라 충돌 없음). 클라이언트로 옮길 때는 이 두 CSS 를 `src/client/` 아래로 복사하거나 상대경로로 import 한다.
2. **스프라이트는 문서 안에 한 번 넣는다.** `<use href="emblems.svg#id">` 처럼 외부 파일을 가리키면 경로 접두어(`/blackcrown/`)와 file:// 에서 깨진다. Vite 라면 `import sprite from '../../design/emblems.svg?raw'` 를 앱 뿌리에서 `<div hidden dangerouslySetInnerHTML={{ __html: sprite }} />` 로 한 번 넣고, 아이콘은 `<svg className="bc-ico"><use href="#bc-suit-blade" /></svg>`.
3. **절대경로 금지.** CSS 안 텍스처는 data URI 라 경로가 없다. 폰트를 추가한다면 상대경로로.
4. **비공개 정보 표시**: 내 그림자 값은 점선 보라 상자 + "나만" 글자. 남의 그림자는 어디에도 그리지 않는다(기도 횟수만). 그림자 망토 어둠 면이 켜지면 마왕 체력 숫자를 "??"로, 막대를 빗금으로.
5. **묘지행 표시**: 족보가 쌍격 이상이면 고른 카드에 `is-to-grave`, 족보 줄에 `bc-combo__grave` 꼬리표, 계산 상자 마지막 줄에 묘지 경고. 일격만 버림 더미로 돌아온다.
6. **그림자를 얻는 선택**(그림자 카드 쓰기, 제단 기도, 저주 유물)은 항상 보라(`bc-btn--umbra`, `bc-combo--umbra` 같은 보라 테)로. 금박 버튼에 섞지 않는다.
7. **아이템 빛 면에는 어둠 면 효과가 늘 비친다**(`bc-item__peek`). 어둠 면은 처음부터 공개 정보다.
8. **검은 왕 본인 화면**: 대관식 뒤 손패 카드에 `is-cursed`, 주 버튼은 `bc-btn--umbra`, 장비 칸은 `bc-gear is-dark`.
9. **대관식 순서와 시각**은 `05-coronation.html` 의 프레임 캡션을 따른다. 점수 기둥은 `--n` 에 점수 칸 수를 넣으면 `height` 전환으로 오른다. 번짐은 `.bc-flood` 에 `--x`, `--y`(왕관 쓴 말의 화면 좌표)를 주고 붙인다.
10. `color-mix()` 를 타일·말 음영에 쓴다(iOS Safari 16.2+). 목업의 `zoom` 은 스토리보드 축소용일 뿐 클라이언트에서 쓰지 않는다.
11. 한 화면 안에서 세로 스크롤이 생기지 않게 ③ 이 남는 높이를 갖는다. 보드 칸 크기는 ③ 높이에서 계산해 `--bc-tile` 로 넣는다(01 목업 기준 48).
