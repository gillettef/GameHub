# 용어집

룰북과 모든 문서는 이 표기를 따른다. 새 용어는 여기에 먼저 추가한다.

## 보드와 접기

| 용어 | 영문 | 정의 |
|---|---|---|
| 접기 보드 | Fold Board | 경첩으로 이어진 패널 7장으로 이루어진 9열 × 5행 게임 보드. 실제로 접고 펼 수 있다. |
| 패널 | Panel | 접기 보드를 이루는 한 장의 판. 날개 패널 6장과 중앙 패널 1장이 있다. |
| 날개 패널 | Wing Panel | A·B·C열과 G·H·I열의 패널. 한 장이 한 열(5칸)이다. 앞면과 뒷면에 같은 좌표의 칸이 인쇄되어 있다. A·I열 패널에는 앞뒷면 모두 닻 칸 표시가 인쇄되어 있다. |
| 중앙 패널 | Center Panel | D·E·F열을 이루는 한 장의 패널. 뒤집히지 않는다. |
| 칸 | Cell | 말과 토큰이 놓이는 최소 단위. 열 글자와 행 숫자로 부른다(예: A1, E3). |
| 앞면 / 뒷면 | Front / Back | 패널의 두 면. 펼친 상태에서 위를 향한 면이 앞면이다. 날개 패널 뒷면의 각 칸은 바로 뒤 앞면 칸과 좌표가 같다. 별빛 조각의 두 면은 '별 면 / 빈 면'으로 부른다. |
| 접기 선 | Crease Line | 보드를 접을 수 있는 경첩 선. 왼쪽 1선(A│B), 왼쪽 2선(B│C), 왼쪽 3선(C│D), 오른쪽 1선(H│I), 오른쪽 2선(G│H), 오른쪽 3선(F│G)의 6개다. |
| 접기 | Fold | 접기 선 하나를 기준으로 보드 끝부분을 안쪽 위로 넘겨 포개는 행동. |
| 펼치기 | Unfold | 접힌 날개를 원래대로 펴는 행동. |
| 날개 | Flap | 접기로 넘겨진 보드 끝부분. 뒷면이 위를 향한다. 왼쪽 날개와 오른쪽 날개가 있다. |
| 접기 폭 | Fold Width | 날개를 이루는 열의 수. 1, 2, 3 중 하나다. 왼쪽 n선으로 접으면 접기 폭은 n이다. |
| 접힘 상태 | Fold State | 왼쪽 날개와 오른쪽 날개의 접기 폭. 펼쳐진 쪽은 0이다. |
| 이음 | Seam | 접힌 날개의 A열(또는 I열)과 그 옆에 드러난 열이 맞닿은 곳. 이음을 사이에 둔 같은 행의 두 칸은 이웃한 칸이다. |
| 같은 좌표 | Same Coordinate | 인쇄된 좌표가 같은 칸. 앞면 B2와 뒷면 B2는 같은 좌표다. 날개를 타고 넘어가는 구성물은 같은 좌표로 옮긴다. |
| 같은 자리 | Same Spot | 탁자 위에서 위아래로 포개진 위치. 겹친 칸의 두 칸은 같은 자리다. 날개 아래에 깔리는 구성물은 같은 자리로 옮긴다. |
| 가려진 칸 | Covered Cell | 날개 아래에 깔려 보이지 않는 칸. |
| 겹친 칸 | Paired Cells | 날개의 칸과 그 바로 아래 가려진 칸 한 쌍. 탁자 위의 같은 자리에 포개져 있다. |
| 부재 | Absent | 가려진 칸에 있는 길잡이와 별빛 조각의 상태. 부재인 길잡이는 눕히고, 부재인 조각은 빈 면이 위로 오게 겹친 칸의 날개 쪽 칸 위에 둔다. 펼치면 풀린다. |
| 이웃한 칸 | Adjacent Cell | 위에서 볼 때 변을 맞대고 있는 보이는 칸. 같은 열의 위아래 칸, 그리고 좌우로 맞닿은 칸(이음 포함)이다. |

## 플레이

| 용어 | 영문 | 정의 |
|---|---|---|
| 길잡이 | Pathfinder | 플레이어가 움직이는 자기 색 말. |
| 시작 플레이어 | Start Player | 첫 차례를 진행하는 플레이어. |
| 활성 플레이어 | Active Player | 지금 차례를 진행하는 플레이어. |
| 라운드 | Round | 모든 플레이어가 차례 순서대로 한 차례씩 진행하는 단위. 동점 결승 라운드는 예외다. |
| 동점 결승 라운드 | Tiebreak Round | 게임 끝에 1위가 동점일 때 동점인 플레이어만 한 차례씩 더 진행하는 라운드. 최대 3번. |
| 날개 터뜨리기 | Flap Burst | 별똥별 카드가 가려진 칸을 가리켜, 그 칸을 가린 날개를 펼치는 일. 행동 횟수에 포함되지 않는다. |
| 공급처 | Supply | 판과 플레이어 카드에 놓이지 않은 별빛 조각을 모아 둔 곳. 비면 게임 종료 조건이 된다. |
| 버린 카드 더미 | Discard Pile | 뒤집은 별똥별 카드를 모아 두는 곳. 별똥별 카드 더미가 비면 섞어서 다시 쓴다. |
| 눕힘 구역 | Lying Zone | 모든 칸의 아래쪽 절반에 인쇄된 구역. 부재인 길잡이와 조각을 둔다. |
| 걸음 | Step | 길잡이를 이웃한 칸으로 한 칸 옮기는 것. |
| 별빛 조각 | Starshard | 칸에 놓이는 득점용 토큰. 한 면은 별 면, 다른 면은 빈 면이다. |
| 별 면 / 빈 면 | Star Side / Blank Side | 별빛 조각의 두 면. 보이는 칸의 조각은 별 면, 부재인 조각과 점수 더미의 조각은 빈 면이 위를 향한다. |
| 들고 있는 조각 | Carried Shard | 플레이어가 주워서 자기 플레이어 카드에 놓은 별빛 조각. 최대 2개. |
| 점수 더미 | Score Pile | 득점한 별빛 조각을 모아 둔 곳. 조각 1개가 1점이다. |
| 닻 칸 | Anchor Cell | 각 플레이어가 조각을 가져와 득점하는 자기 전용 칸. 길잡이의 시작 칸이기도 하다. A열 또는 I열에 있다. |
| 플레이어 카드 | Player Card | 차례 번호 1~4가 적힌 개인 카드. 들고 있는 조각 칸 2개, 점수 더미 칸, 인원별 닻 칸 좌표가 있다. |
| 별똥별 카드 | Shooting Star Card | 별빛 조각이 떨어질 칸을 알려 주는 카드. B~H열의 칸마다 1장씩 35장이다. 더미가 비면 버린 카드 더미를 섞어 다시 쓴다. |
| 목표 점수 | Target Score | 게임 종료를 일으키는 점수. 인원에 따라 다르다. |
