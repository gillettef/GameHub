# 2027 코리아보드게임즈 보드게임 공모전 제출 준비

- 요강: https://www.koreaboardgames.com/magazine/menuDetail?boardCd=news&postNo=948
- **접수 마감: 2026-12-31(수) 24시** (이메일 game@koreaboardgames.com 또는 12-31 소인 우편)
- 1차 결과 발표: 2027-03-08(월) 12시 / 2차 오프라인 심사(프로토타입 지참): 추후 공지 / 최종 발표: 2027년 5월
- 응모 분야: **패밀리 플러스 게임** (플레이 90분 이하. 패밀리 게임은 40분 이하라 해당 없음)

## 심사 기준(요강 원문 4항목)과 대응

| 심사 기준 | HEARSAY의 대응 | 근거 문서 |
|---|---|---|
| 순수 창작물 | "기록이 물리적으로 사라지고 다수 증언이 역사가 된다"는 핵심 메커니즘은 독자 설계. 기존 게임 이름·문구 차용 없음 | docs/decisions.md D-001 |
| 지나치게 복잡하지 않고 재미있는 게임 | 매 계절 할 일은 "카드 한 장 고르기"와 "토큰 하나 쥐기" 두 가지 | rules/rulebook.md 1장 흐름표 |
| 규칙에 허점이 없고 균형이 잘 맞는 게임 | 룰 검수·가상 플레이·몬테카를로 분석을 반복해 정보 누수와 좌석 불균형을 제거 | playtests/, decisions.md D-013~ |
| 반복해서 할 만큼 매력적인 게임 | 매 판 다른 사람들과 다른 "가짜 역사"가 만들어짐. 동시 점유·질문 칸 선택으로 매번 다른 전개 | |

## 제출물 체크리스트

### 1차 (서류) — 2026-12-31까지
- [ ] **공모전 신청서** (공식 양식 docx) — 작가 개인정보·서명은 **작가 본인이 직접** 작성. 이메일 접수 시 자필 서명 스캔/촬영 첨부
  - 게임 제목: HEARSAY (히어세이)
  - 응모 분야: ☑ 패밀리 플러스 게임
- [ ] **게임 기획안** (공식 양식 docx, **A4 2쪽 이내**) — 공식 양식에 채운 파일: `contest/HEARSAY_기획안.docx` (작가명 칸과 2쪽 사진만 채우면 됨). 긴 원고: `contest/proposal.md`. 다시 만들기: `python contest/tools/fill_plan.py <공식양식.docx> contest/HEARSAY_기획안.docx`
  - [ ] 2쪽에 **게임 진행 사진 1~2장 필수** (프로토타입이 없으면 손그림·구성물 그림으로 대체 가능)
- [ ] **규칙서** (.pdf/.doc/.ppt/.hwp, 분량 자유) — `python rules/build_pdf.py`로 `contest/HEARSAY_규칙서.pdf` 생성(표지·도해 포함)
  - [ ] 요강 권고: 게임을 모르는 사람에게 규칙서만 읽혀 이해되는지 확인

### 2차 (현장 심사) — 1차 통과 시
- [ ] 게임 진행이 가능한 프로토타입(심사 후 제출, 최종 발표 후 반환)

## 작가가 직접 해야 하는 일
1. 프린트 앤 플레이 구성물(`components/print-and-play.html`)로 **실물 플레이**를 최소 2~3회 하고 사진 촬영(기획안 필수 사진). 측정 항목은 `playtests/real-test-guide.md`
2. 실제 플레이 후기를 `/playtest-report`로 기록 → 룰 최종 조정
3. 신청서 개인정보 작성·서명
4. 이메일 발송
