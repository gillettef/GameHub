## 1. 육각 칸과 좌표

- 칸 모양: **pointy-top 육각**(꼭짓점이 위·아래). 같은 줄의 칸은 좌우로 맞닿고, 윗줄·아랫줄은 반 칸씩 엇갈린다.
- 좌표: 축 좌표 `(q, r)`. 화면 위치(반지름 1 기준)는 `x = √3·(q + r/2)`, `y = 1.5·r`. `r` 이 작을수록 화면 위쪽이다.
- 이웃 6방향(방향 번호 0~5): `0:(+1,0)` 오른쪽, `1:(+1,−1)` 오른쪽 위, `2:(0,−1)` 왼쪽 위, `3:(−1,0)` 왼쪽, `4:(−1,+1)` 왼쪽 아래, `5:(0,+1)` 오른쪽 아래.
- 거리: `(|Δq| + |Δr| + |Δq+Δr|) / 2`. 거리 1 = 맞닿은 6칸, 거리 2 = 그 바깥 12칸, "별 모양 거리 2" = 거리 2 중 6방향 직선 위 6칸(고사리).
- **축 좌표는 화면에 표시하지 않는다.** 사람에게는 **칸 이름**(`C4`, 아래)을 쓴다. 게임 기록·칸 정보·스크린리더 라벨은 칸 이름이고, 보드 위에는 "칸 이름" 토글을 켰을 때만 칸 위쪽에 작게 보인다.

### 칸 이름 (2026-10-18, Rules.md 2절)

게임 기록·화면("칸 이름" 토글)·실물 보드 테두리에서 칸을 가리키는 사람용 좌표. 줄 = 위에서부터 A, B, C …, 번호 = 보드 왼쪽 끝부터 센 열(반 칸 단위 가로 위치 `2q + r` 를 2로 나눔). 같은 줄은 오른쪽으로 1씩 커지고, 위·아래 줄은 반 칸 엇갈린다. 파인 곳은 번호를 건너뛴다. 윤곽이 인원마다 고정이라 이름도 인원마다 고정이다. `[n]` = n번 자리 입구. 다시 그리기: `npx tsx tools/board-labels.ts`.

## 3. 정원 조각 = 화면 용어 "구역" (7칸)

- 조각 하나는 꽃 모양 7칸: 가운데 칸(번호 0) + 둘레 6칸(번호 1~6 = 방향 0~5 쪽).
- 아래 표에 없는 칸은 빈 땅.

**일반 조각 12장** (`TILE_LIBRARY`)

| # | 구성 | 빈 땅 / 기름진 땅 / 연못 / 바위 |
|---|---|---|
| 1 | 1 연못 | 6 / 0 / 1 / 0 |
| 2 | 1 연못, 2 연못 (붙어 있음) | 5 / 0 / 2 / 0 |
| 3 | 1 바위 | 6 / 0 / 0 / 1 |
| 4 | 0(가운데) 연못 | 6 / 0 / 1 / 0 |
| 5 | 1 기름진 땅 | 6 / 1 / 0 / 0 |
| 6 | 1·4 기름진 땅 (마주 봄) | 5 / 2 / 0 / 0 |
| 7 | 1 연못, 4 기름진 땅 (마주 봄) | 5 / 1 / 1 / 0 |
| 8 | 1 바위, 3 기름진 땅 | 5 / 1 / 0 / 1 |
| 9 | 1·2 연못, 5 기름진 땅 | 4 / 1 / 2 / 0 |
| 10 | 0(가운데) 기름진 땅, 3 바위 | 5 / 1 / 0 / 1 |
| 11 | 2 연못, 5 바위 (마주 봄) | 5 / 0 / 1 / 1 |
| 12 | 모두 빈 땅 | 7 / 0 / 0 / 0 |

합계: 기름진 땅 7, 연못 8, 바위 4 (연못·바위 합 12칸 → 조각당 평균 1칸이 막힘).

**입구 조각** (자리마다 1장): 가운데 칸이 그 자리의 입구, 둘레 1번 칸 하나가 기름진 땅, 나머지 5칸은 빈 땅.

**회전**: 모든 조각(입구 조각 포함)은 판마다 시드로 0~5칸(60° 단위) 회전한다. 가운데 칸은 그대로, 둘레 지형만 돈다. 그래서 입구 옆 기름진 땅의 방향도 판마다 다르다.

**배치**: 입구가 아닌 자리에는 일반 12장을 시드로 섞어 앞에서부터 놓는다. 2인은 5장, 3인 10장만 쓰므로 판마다 지형 구성이 달라진다. 4인은 모두 빈 땅인 4인 전용 13번 조각을 더해 13장을 모두 쓰므로 지형 개수는 같고 배치만 바뀐다(2026-11-27).

## 4. 보드 조립과 인원별 모양

- 조각 중심은 격자 `a·(2,1) + b·(−1,3)` 위에 놓인다(꽃 모양 조각이 빈틈없이 깔리는 격자).
- 원점 조각 = **가운데 조각**(고리 0, 목표 "중앙 광장"의 기준). 원점과의 거리가 같은 조각끼리 고리 1, 2, 3 … (각 6조각).
- 조각 배치(윤곽)와 입구 위치는 **인원마다 고정**이다. 판마다 바뀌는 것은 일반 조각의 순서·회전(= 지형 배치)뿐이다.
- 자리 번호는 입구 조각을 원점 기준 각도 순으로 붙인다.

| 인원 | 조각 | 칸 | 쓰는 조각 | 입구 | 대칭 | 입구 사이 거리 |
|---|---|---|---|---|---|---|
| 2인 | 7 | 49 | 고리 0~1 | 고리 1의 마주 보는 두 조각 | 180° 회전 대칭 | 6 |
| 3인 | 13 | 91 | 고리 0~2 | 고리 2의 120° 간격 세 조각 | 120° 회전 대칭 | 9, 9, 9 |
| 4인 | 17 | 119 | 고리 0~2 + 고리 3의 네 조각 (가로 직사각형) | 네 모서리 조각 | 180° 회전 대칭 | 이웃 7·8 / 대각 10·12 (아래) |

대칭은 **윤곽과 입구 위치**만이다. 지형은 무작위라 대칭이 아니다.

### 윤곽 그림

`buildBoard` 를 실제로 돌려 칸 좌표로 그린 그림이다. 한 글자 = 한 칸, 줄 = 같은 `r`(위가 r 작음), 줄마다 반 칸씩 엇갈린다(화면의 pointy-top 배치와 같음). 빈 자리는 보드 밖(칸 없음) — 3·4인은 바깥 테두리에 오목하게 파인 곳이 있다.

## 5. 보드 위에 올라가는 요소 (현재 렌더)

그리는 순서(아래 → 위): 테두리·줄눈·지형 타일·구역 경계선 → 땅 주인색 → 지형 장식(새싹·물결·돌) → 미리보기 뒤집힘 → 합법 칸 → 입구 → 식물 → 씨앗 → 고른 칸 → 영향력 숫자.
크기는 모두 칸 반지름 1 기준 단위다.

| 요소 | 의미 | 현재 표시 |
|---|---|---|
| 땅 (내 땅/상대 땅) | 그 칸 영향력 엄격한 1등 = 주인 | 칸 전체에 주인 자리색 **38%** 덮기 + 자리색 안쪽 테(0.07) |
| 입구 | 자리별 시작 칸(영향력: 자기 3, 둘레 1) | 자리색 **집 모양**(오각형, 폭 0.84) + **자리 번호**(디스플레이 폰트 900), 테두리 `--board-ink` `#1f2a1c` |
| 식물 | 심은 카드 1장 = 1칸, 움직이지 않음 | **카드 그림 썸네일**(`public/cards/plants/art/<종 id>.webp` 을 원형으로 자름, 반지름 0.58) + 자리색 **고리**(바깥 반지름 0.7). 심을 때 튀어나오는 애니메이션(340ms) |
| 씨앗 | 민들레가 거리 2 이내 빈 칸에 남김 | 칸 아래쪽 작은 자리색 점(반지름 0.12), 여러 개면 옆으로 나란히 |
| 합법 칸 (카드 고른 뒤) | 지금 카드로 심을 수 있는 칸 | 안쪽 육각(반지름 0.8)에 Moonlight Cream `#fff3b7` 18% 채움 + 테두리, 1.6초 깜빡임 |

## 6. 디자인 제약

- **모바일 폭 고정**: 앱 폭 최대 480px(`--app-max-width`), 폭 분기 없음. 보드는 "목표 칩 → 보드(남는 높이 전부) → 심기 바·내 카드·마켓" 사이에서 **스크롤 없이** 남는 높이를 다 쓴다. 4인 105칸(13줄, 한 줄 최대 12칸)이 이 폭에 들어가야 하므로 칸 하나가 매우 작다 — 무늬·글자는 작은 크기에서 읽혀야 한다.
- **최소 글자 12px**(`--text-micro`). 보드 안 글자(식물 첫 글자, 영향력 숫자)도 이 하한을 따른다.
- **좌표를 화면에 보여 주지 않는다.**
- **연못과 1번 자리 파랑 땅을 구분**한다(연못은 어둡게 + 물결). 지형은 색 외에 모양으로도 구분한다.
- **플랫**: `box-shadow` 금지(SVG 그림자·블러 효과도 피한다). 구분은 색 블록과 여백.
- **색은 토큰 변수로만**: `src/client/styles/tokens.css` 의 CSS 변수(`--color-soil`, `--color-pond`, `--color-rock`, `--color-fertile`, `--color-grid`, `--color-seat-0~3`, `--color-accent` …). 컴포넌트 CSS에 HEX 직접 기입 금지. 새 색이 필요하면 토큰을 추가한다. 보라색 계열은 쓰지 않는다.
- **위험 색** Danger Red `#e5484d` 는 돌이킬 수 없는 동작·경고 전용이라 보드 장식에 쓰지 않는다.
- **화면 용어**: 정원 조각 → **구역**, 비옥토 → **기름진 땅**, 돌밭 → **바위**, seat(코드) → **자리**(번호 +1), 둘레 → 옆 칸. 그림 안 라벨·범례도 이 말을 쓴다.
- 땅 주인 표시는 자리색 38% 덮기라, 지형 무늬(새싹·물결·돌)는 그 위에서도 보여야 한다. 식물은 그림 썸네일 + 자리색 고리, 입구는 자리색 꽉 채움이라 땅 덮기와 구별된다.
- 모션: 120 / 220 / 340ms 토큰(`--motion-fast/standard/slow`) 안에서.
