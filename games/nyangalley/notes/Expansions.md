# Rootbound 확장판 아이디어 (메모)

> 2026-10-08 작성. **아이디어 메모일 뿐 규칙이 아니다.** 지금은 오리지널을 다듬는 데 집중한다.
> 규칙 정본은 `notes/Rules.md` 다. 여기 있는 내용은 구현하지 않았고, 채택할 때는 Rules.md 를 먼저 고친 뒤 시뮬레이터(`tools/lab`)로 재고 들어간다.

## 1. 큰 그림

- **오리지널** = 한국 식물 12종(잔디·참나무·소나무·칡·고사리·민들레·유채·연꽃·담쟁이·대나무·버섯·무궁화)과 지형 4종(빈 땅·기름진 땅·연못·바위).
- **확장판** = 지역별 식물 묶음 + 그 지역 지형. 예: 동남아, 아마존, 사막, 지중해, 북미, 툰드라.
- 판을 시작할 때 **이번 판 식물**을 고른다(지금 규칙: 2인 6종 / 3·4인 8종). 확장판이 생기면 여러 묶음을 섞어 고를 수 있다.
  - 예: "오리지널 5종 + 아마존 3종", 또는 "아마존만".
- 지금의 라운드 공용 마켓 구조가 확장판과 잘 맞는다. 판마다 식물 조합만 바꾸면 되고, 드래프트처럼 12종을 다 비교할 필요가 없다.

## 3. 확장판별 아이디어

식물 능력은 지금 엔진에 있는 부품으로 만들 수 있는 것부터 적는다. 부품은 자기 칸(`self`), 옆 칸(`ring1`), 한 칸 건너뛴 6칸(`star2`), 직선(`line`), 씨앗(`seed`), 연못 옆 심기(`pondPlanting`), 담쟁이식 가산(`ivy`), 군집(`cluster`), 상대 빼기(`wither`), 기름진 땅 보너스(`fertileRing`), 끝날 때 점수(`bloomBonus`)다. **새 부품**이 필요한 것은 따로 표시했다.

### 동남아
- 지형: **논**(물을 댄 기름진 땅), **맹그로브 갯벌**(연못과 땅의 중간).
- 식물 후보
  - **벼**: 논에서만 강함(논 버전 `fertileRing`).
  - **맹그로브**: 갯벌·연못 옆에 심을 수 있음(`pondPlanting` 변형).
  - **바나나**: 군집(`cluster`) + 넓은 잎(`ring1` 큼).
  - **라플레시아**: 끝날 때 점수 큼, 대신 영향력 약함(`bloomBonus` 큼).
  - **두리안**: **새 부품** — 옆 칸 상대 식물의 끝 점수 깎기.

### 아마존
- 지형: **강**(연못이 길게 이어진 것, 직선 뻗기 식물과 상호작용), **밀림**(심을 때 옆 칸 영향력이 줄어드는 칸).
- 식물 후보
  - **케이폭 나무**(거목): 자기 칸 아주 큼 + 옆 칸 큼, 대신 카드 장수 적게.
  - **스트랭글러 무화과**: **새 부품** — 상대 식물 칸 위에 겹쳐 심기(남의 식물을 대체).
  - **빅토리아 수련**: 강·연못 위에 직접 심기(**새 부품**: 연못 칸 점유).
  - **브로멜리아드**: 다른 식물에 붙어 자람(`ivy` 강화형).
  - **덩굴 야자**: 긴 직선(`line` 길이 3).

### 사막
- 지형: **모래**(영향력 −1 칸), **오아시스**(주변이 기름진 땅이 되는 연못).
- 식물 후보
  - **선인장**(오리지널에서 뺀 이름 재사용, 능력은 다르게): 모래에서도 손해 없음.
  - **회전초**: **새 부품** — 심은 뒤 다음 라운드에 한 칸 굴러감.
  - **용설란**: 오래 버팀(끝날 때 남아 있으면 점수).

### 지중해
- 지형: **절벽**(바위의 변형, 옆 칸에 보너스), **해안**(보드 가장자리 특수 칸).
- 식물 후보
  - **장미**(뺀 이름 재사용): 끝 점수 계열.
  - **올리브**: 늦게 심을수록 강함(**새 부품**: 라운드 수 비례).
  - **라벤더**: 꽃밭 목표와 연계, 옆 꽃 식물 강화.

### 북미 / 툰드라 (메모만)
- 북미: **해바라기**(뺀 이름 재사용), 세쿼이아(거목), 옥수수(군집).
- 툰드라: 이끼(영향력 약하지만 바위 위에도 심기), **영구동토**(지형: 심기 늦어지는 칸).

## 4. 오리지널 분석에서 나온 빈자리

- **방어 역할이 없다**: 버섯(상대 −2)이나 담쟁이를 막는 종이 없어서, 견제를 받으면 "더 쌓기"밖에 대응할 수단이 없다.
  - 확장판에서 "옆 칸 빼기 무효", "내 칸 영향력 하한 1" 같은 방어 식물을 넣어 볼 수 있다.
- 2026-10-08 마켓 전환 뒤 **4인 땅 뺏기가 55 → 71칸**으로 늘었다. 확장판에 견제 식물을 더 넣으면 더 늘어날 수 있으니, 방어 식물과 함께 넣는다.

## 5. 확장판을 넣기 전에 구조에서 준비할 것 (지금은 하지 않음)

1. **지형을 데이터로**: 지금 `Terrain = 'empty' | 'fertile' | 'pond' | 'rock'` 은 닫힌 목록이다. 지형도 식물처럼 데이터(심기 가능 여부, 영향력 보정, 소유 가능 여부)로 정의해야 새 지형을 코드 수정 없이 넣을 수 있다.
2. **카드 묶음 표시**: 식물·목표·지형·정원 구역에 `pack`(오리지널 / 동남아 …) 표시를 단다. 판을 만들 때 쓸 묶음을 고르는 단계(대기실)가 필요하다.
3. **이번 판 식물 고르기 일반화**: 지금 `pickGarden` 은 12종 중에서 고른다. 여러 묶음의 식물 풀에서 묶음별 몇 종씩 고르는 규칙이 필요하다.
4. **종 연계 목표 일반화**: 지금 "보호구역" 목표 6장은 특정 종에 묶여 있다. 종이 늘면 "이번 판 식물 중 하나를 지정하는 보호구역"처럼 목표를 판마다 만들어야 한다.
5. **새 부품**: 위 아이디어 중 새 부품이 필요한 것(겹쳐 심기, 굴러감, 라운드 비례, 연못 칸 점유 등)은 엔진·AI(`src/ai/search.ts`, 엔진 함수를 부르므로 보통 평가만)·시뮬레이터를 함께 고쳐야 한다(CLAUDE.md 필수 작업 규칙 7).
6. **카드 그림**: `public/cards/` 에 묶음별 폴더를 둔다.

## 6. 밸런스 확인 순서 (채택할 때)

1. 새 식물마다 영향력 총량을 기존 종과 비슷하게 맞춘다(Rules.md 12절 설계 결정 "종마다 영향력 총량을 맞춤").
2. 시뮬레이터에 새 식물을 넣고 종 승률·자리 승률·땅 뺏기 횟수를 오리지널 단독 판과 비교한다.
3. 묶음을 섞은 판에서 특정 묶음이 늘 이기지 않는지 본다.
4. 결과와 결정 이유를 Rules.md 12절에 남긴다.
